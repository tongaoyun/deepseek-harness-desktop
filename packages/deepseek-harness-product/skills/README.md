# 技能

## 概述

随产品桌面固定装配，产品 UI 在左侧“扩展能力”直接挂载页面，不另行安装功能插件，不提供设置重复页或独立更新。技能通过官方 Skill Provider 发现和读取，管理操作遵守源文件声明的调用权限。页面统一为“市场／我的”：市场直接展示审核发布的公司技能，不提供创建、导入或个人分类管理；在“我的”创建、导入技能，保留本机技能、项目技能、发现技能和回收站。个人内容可提交发布，审核通过后全公司可用。空市场显示发布提示，搜索无结果另行提示。

## 装配与维护

Host 模块通过产品 profile 固定装配，普通 ESM 客户端模块合入产品 UI 的浏览器产物；不声明独立安装包。根目录 `pnpm run build:artifacts` 完成构建，本目录 `tsconfig.json` 检查源码与测试，包构建同步执行该类型检查。 CI 通过 `pnpm exec vitest run --config packages/deepseek-harness-product/skills/vitest.config.ts` 同时执行源码和页面行为测试。官方 profile 不加载产品模块。界面直接使用原生 UI 组件及其 TypeScript 声明，不维护替代类型。弹窗与来源菜单的 Escape 层级、输入法保护、快捷键修饰键判断、Tab 遍历和焦点恢复由原生 Modal／Menu 管理；产品封装仅提供内容与样式，不额外注册全局键盘监听。仓库发现页直接使用原生 Button 及其类型，危险态通过产品样式表达；来源和仓库折叠箭头共用同一绘制函数。

原始来源摘要见 [upstream.json](upstream.json)，保留 [Apache-2.0 许可](LICENSE)。代码由本仓库维护，社区更新选择性合入，不整包替换。团队内容的格式和发布入口见[公司内容说明](../../../apps/product-desktop/docs/company-content.md)。

管理器与原生文件提供方共用 YAML、调用策略及技能名校验，拒绝重复键、损坏 YAML、旧调用字段和非法开关值。条目仍可在管理页查看诊断；读取正文时重新检查当前文件权限，不沿用目录缓存中的旧许可。目录解析复用原生 home-paths，支持 `~`、绝对路径规范化及空白环境变量回退。分类名称使用原生输入事件，回车可提交，输入法组词期间不提交。

技能的 `SKILL.md` 声明名遵循原生英文小写字母、数字和连字符格式；目录名可以使用中文。包含中文等非 ASCII 字符的声明名保留原文并展示修复提示，不截断为其他技能名，也不向模型注册。已登记的启用权限可在文件损坏或丢失后撤销，修复文件不会自动重新启用。客户端通过 Harness 原生 Remote 调用技能管理服务，复用连接、身份校验、输入输出校验和取消信号，支持带路径前缀的反向代理。管理方法仅允许宿主所有者调用。

技能导入的文件及文件夹选择复用浏览器文件输入，通过实际选择或取消事件结束等待；选择器打开期间不因窗口聚焦或固定时间到期而提前允许重复打开。打开失败时保留导入表单并提示重试或拖拽，关闭导入页释放监听。所选文件大小复用原生 `fileSizeText`，按体积显示字节、KB、MB 或 GB。

市场、本机、项目和发现技能的详情共用正文阅读与复制操作。详情宽度随窗口收缩，正文使用 16 行等宽阅读区，可调整高度；复制保留完整空白和换行，剪贴板拒绝时保留正文并提示手动复制。切换正文或关闭详情后，较早的复制回执不会改变当前提示。发现技能的仓库详情、目录详情、更新预览和恢复预览共用只读弹窗请求，直接传递原生 Remote 取消信号，读取不占用安装写锁；加载中可关闭，切换来源、离开页签或卸载会取消当前详情，迟到的成功与失败不重新打开弹窗、不覆盖其他表单。更新和恢复预览完成前不显示写入确认按钮，也不额外刷新整个仓库列表；确认只使用当前预览的校验令牌。安装、卸载和确认更新等文件写入仍保持互斥，写入期间来源切换和关闭操作不移除确认界面；确认后解除只读请求归属，离开视图不取消已开始的文件事务。

目录按“全部、已启用、已停用”筛选和统计调用开关；同名技能的来源优先级、内容加载错误在对应条目中说明，不作为独立启用状态。已启用不代表内容一定可加载，实际调用继续遵守官方技能解析和权限检查。

首次读取使用原生加载指示，未知统计显示“—”，读取失败不显示空目录。工作区目录直接使用原生注册表的规范路径；服务未装配时保持无项目目标，已装配但读取失败时保留错误原因并显示重试提示，不当作空列表或未登记工作区。本机技能创建不依赖项目登记读取成功。刷新项目技能时保留当前项目已读取的列表或空结果；发现技能页在仓库读取完成后才显示空仓库提示。

<a id="dev-note"></a>
### 开发备注

源码从固定社区版本移入产品包，已有断言按原始语法指纹移入仓库检查基线，禁止增加新断言。原社区实现保留原 lint 范围，由独立严格类型检查（拒绝未使用的变量和参数）及行为测试验证；新增装配、配置读取和提交出口仍执行仓库 lint。仅接受当前产品状态，不读取旧插件设置备份，不自动补齐旧来源或推测安装位置。仓库状态采用 version 2，每个安装副本必须带位置、内容摘要和确认状态；格式不支持时保留原文件并报错，不迁移、不重置。技能文件与官方 Session 不变。安装位置解析统一返回 `SkillRoot`，新安装也保留完整类型检查；更新、回滚与来源匹配共用工作区校验。路径失效时明确失败，不回退到用户目录。

Host 方法和核心操作返回值通过原生 Typert 编译器生成 Remote 元数据与客户端类型；运行 `pnpm generate:remote` 更新，`pnpm verify:remote` 拒绝漂移。排队写入在开始前检查取消，已经开始的文件事务完成后再释放；插件卸载取消市场和仓库下载并等待活动操作结束。仓库刷新将原生调用取消、插件生命周期与下载超时传递到网络请求，提交缓存和目录前重新检查取消；取消不覆盖上次完整快照，也不写入扫描失败诊断。状态文件与仓库归档缓存复用原生 atomic-write，以私有权限原子替换并处理 Windows 临时占用；目录更新通过原生 `skills/change` 刷新菜单，不发送专家切换事件。Agent 级技能注册直接使用当前原生注册、枚举和释放接口，以原生 Agent ID 记录其生命周期，不探测旧方法或静默跳过缺失方法。

市场文档和仓库归档共用完整响应体的字节上限检查，不截断安装内容。下载通过原生 deadline 管理超时并在结束时释放计时器；原生调用取消和插件卸载同样取消正在等待的响应体读取。HTTP 失败、响应超限和取消都发起响应体清理并释放读取锁，连接清理失败不覆盖原操作的错误码或取消原因。

<a id="model-experience"></a>
## 模型体验

### 原生能力

#### 模型看到的内容

模型通过官方技能发现读取 `SKILL.md` 和资源文件，继续遵守模型调用和用户调用限制。公司内容按 Session 固定版本，输入记录沿用原生日志。

#### Token 影响

技能摘要和按需读取的正文占用上下文。页面整合不新增模型输入。

#### KV Cache 影响

不管理模型缓存；内容变化由官方请求组装处理。
