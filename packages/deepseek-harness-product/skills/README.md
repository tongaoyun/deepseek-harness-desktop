# 技能

## Summary

在“市场”使用公司审核的技能，在“我的”创建、导入和管理本机、项目及发现的技能，也可恢复回收站内容。个人技能可提交公司审核。技能由原生 Skill Provider 发现和读取，遵守源文件调用权限，模块随桌面统一更新。

<a id="assembly"></a>
## 装配与维护

Host 模块通过产品 profile 固定装配，普通 ESM 客户端模块合入产品 UI 的浏览器产物；不声明独立安装包。根目录 `pnpm run build:artifacts` 完成构建，本目录 `pnpm run typecheck` 分别检查 Host 和 Client，根 `tsconfig.json` 仅聚合两个编译入口，Remote 生成器只分析 Host 入口，构建与 CI 都执行两端类型检查；原生 Session 类型只进入 Client 编译，避免与 Host 服务声明混用。客户端仍由产品 UI 固定挂载，不声明自动加载插件。官方 profile 不加载产品模块。

代码按当前产品版本维护，许可证见 [LICENSE](LICENSE)。公司内容的格式和发布入口见[公司内容说明](../../../apps/product-desktop/docs/company-content.md)。

<a id="content-and-permissions"></a>
## 内容与权限

技能的 `SKILL.md` 声明名遵循原生英文小写字母、数字和连字符格式；目录名可以使用中文。包含中文等非 ASCII 字符的声明名保留原文并展示修复提示，不截断为其他技能名，也不向模型注册。已登记的启用权限可在文件损坏或丢失后撤销，修复文件不会自动重新启用。元数据和调用权限使用原生 Skill filesystem 解析器，目录及原子写入由 Harness 模块负责；加载正文时重新检查当前文件声明和管理开关。

<a id="operations"></a>
## 管理操作与取消

管理服务使用原生调用身份判断限制本机所有者权限。管理页面通过原生 Remote 调用 Host，Typert 从实际服务方法生成类型和元数据，不维护 HTTP 路由或手写宿主类型；Session 选择使用原生 UI Session 快照与 Hook 类型。

语言、请求与页面状态由各挂载实例持有；目录、技能详情、工作区列表和工作区内容读取均传递原生 Remote 取消信号；刷新会取消被替代的同项读取。关闭详情、切换来源或离开页面会取消对应读取并释放详情忙碌状态，旧成功或失败均不能覆盖当前列表或关闭新表单。

技能导入在上传展开、检查和临时复制期间接受取消，清理暂存内容并停止后续技能；单个技能开始重命名替换后完整结束，保留已提交技能并刷新原生目录缓存。其他已开始的本地写入仍完成；调用取消后不返回成功结果，页面释放后不再发起后续写入或刷新。

导入默认跳过已有同名普通目录、文件及文件链接，包括目标暂时不可用的文件链接；明确覆盖文件链接时只替换链接本身，不修改链接目标。目录链接拒绝覆盖。冲突检查无法读取目录状态时停止导入，保留原文件。

等待公司目录和解析写入目标时沿用原生调用及管理服务的取消信号，取消后不再进入技能写入。创建提交后及导入文件读取至写入完成期间，表单禁止编辑、重复提交和关闭；本地文件读取失败展示原因并保留所选内容供重试。

创建、上传和市场安装分别声明所需请求字段，由原生 Typert 剥离未声明的参数。上传只接收内容，不接收宿主路径或预览参数。文件夹和 ZIP 内的路径统一拒绝 Windows 禁用字符、控制字符、保留设备名及尾随点或空格，保留中文和隐藏资源文件。本地导入通过文件选择或拖拽上传 ZIP、技能文件夹或 SKILL.md，上传文件使用 Harness 原生字节编码工具。替换或移除所选内容、关闭导入弹窗会取消待完成的拖拽读取，旧成功或失败不影响当前选择。

外部目录响应在 JSON 解析处校验字段，详情和下载共用已校验的数据。下载使用 Harness 原生截止时间，正文通过产品包的共用限流读取器和 Node 原生取消订阅读取；截止时间覆盖响应正文，超限或取消时立即释放读取器。其他监听器阻断取消事件、传输清理不结束时，均不能让读取继续等待；取消后不返回部分内容。

个人技能提交前的导出将原生取消信号传入文件读取；调用取消或管理服务卸载时停止遍历并关闭当前文件，不返回部分内容，源文件保持不变。

管理器作为原生必需 Skill Provider 注册，统一提供停用策略和同名副本选择。来源、文档或已有策略文件读取失败时，当前技能目录及调用查询明确失败，不缓存部分结果、不回退到可能绕过停用策略的原生副本；恢复后下一次查询重新发现。这会暂时影响其他正常技能的查询。已缓存的管理器候选加载失败也不回退。策略文件尚未创建时使用初始空策略；可选目录不存在、失效链接和无效元数据继续按原规则跳过。

目录按“全部、已启用、已停用”筛选和统计调用开关；同名技能的来源优先级、内容加载错误在对应条目中说明，不作为独立启用状态。已启用不代表内容一定可加载，实际调用继续遵守官方技能解析和权限检查。

<a id="discovery"></a>
## 发现与工作区

发现技能页直接使用原生 Remote 生成的目录结果类型；外部响应的身份、显示字段和统计值由 Host 校验。ClawHub 与 skills.sh 搜索分别由当前请求的取消控制器管理；替换查询、切换来源或离开页面会取消读取，旧结果、错误和完成回调不改写新搜索。ClawHub 榜单最多累计显示 100 条。

GitHub 仓库检查更新沿用技能页面的取消信号；关闭页面或切换 Session 会取消当前下载，停止后续仓库检查与列表回读。已提交的仓库登记及完成的扫描保留，关闭后不再开始新增仓库的扫描；重新打开页面可再次检查。已开始的本地安装、更新和恢复事务仍完整结束。

仓库安装、卸载、更新和回退按写入回执报告结果。写入成功后列表刷新失败时保留成功提示，明确要求刷新列表，避免重复操作。

仓库列表和更新预览可能恢复未确认的安装；恢复与启停、分类写入串行执行，操作结束后刷新原生技能目录，即使恢复已提交但后续预览失败。

仓库技能每个安装副本保留一份可回退版本；连续更新或回退提交后，清理被替代且未被其他安装记录引用的旧备份。“我的”移入回收站与仓库卸载使用同一来源记录事务，仅移动选定用户目录或项目中的安装副本；恢复保留来源及回退能力，永久删除成功后移除对应记录并清理无引用备份。提交或删除失败保留原有记录和备份；旧备份清理失败记入管理诊断，不改变已提交结果。

分类按来源和技能名称保存。同源同名技能或其他回收条目仍存在、来源无法核验时，永久删除旧条目保留分类及排序；最后一个副本删除后才清理。分类清理或诊断写入失败不改变已完成的删除结果。

项目技能通过原生工作目录服务读取所选 Session 的当前目录，跟随已记录的目录切换和会话恢复；未选择或无法找到 Session 时不读取其他会话的项目。显式选择已登记的工作区时按该工作区显示。目录重叠检查使用原生路径规范化；目录无法核验时提示不可用并阻止项目写入，修复后可重新读取。

创建、导入及发现技能安装共用目标选择器。工作区列表读取失败时显示原因并提供原位重试，保留表单及目标范围；成功读取前不显示空工作区结论。本机用户目录仍可使用，重试沿用页面取消信号。

<a id="ui-state"></a>
## 界面状态

输入、按钮、启停开关、加载指示、菜单和通用操作图标直接使用 Harness 原生组件，多行输入使用标准 textarea 属性。启停写入期间禁用操作，成功后重新读取状态，失败时保留原状态并展示本地化提示。筛选和操作菜单在控件禁用时关闭，恢复启用后需重新打开。首次读取使用原生加载指示，未知统计显示“—”，读取失败不显示空目录。刷新项目技能时保留当前项目已读取的列表或空结果；发现技能页在仓库读取完成后才显示空仓库提示。

分类名称输入沿用 Harness 原生输入法组合生命周期，仅独立且非重复的 Enter 提交；输入法组合及结束组合的 Enter、带修饰键的 Enter 均不触发写入。关闭表单时释放组合事件监听，重新打开使用新的输入状态。

<a id="model-experience"></a>
## Model Experience

### Native capabilities

#### What the model sees

模型通过官方技能发现读取 `SKILL.md` 和资源文件，继续遵守模型调用和用户调用限制。公司内容按 Session 固定版本，输入记录沿用原生日志。

#### Token effect

技能摘要和按需读取的正文占用上下文。页面整合不新增模型输入。

#### KV Cache effect

不管理模型缓存；内容变化由官方请求组装处理。

## Known Limitations and Deferred Work

- 仅随产品桌面装配和更新，不作为社区插件独立发布。

<a id="dev-note"></a>
### Dev Note

Remote 结果类型使用相对源码导入，Windows 与 macOS 校验同一份生成文件。挂载后注入 `remote.skillsManager`，卸载时先释放页面再移除 Remote。
