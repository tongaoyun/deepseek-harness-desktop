# 技能

## 概述

随产品桌面固定装配，产品 UI 在左侧“扩展能力”直接挂载页面，不另行安装功能插件，不提供设置重复页或独立更新。技能通过官方 Skill Provider 发现和读取，管理操作遵守源文件声明的调用权限。页面统一为“市场／我的”：市场直接展示审核发布的公司技能，不提供创建、导入或个人分类管理；在“我的”创建、导入技能，保留本机技能、项目技能、发现技能和回收站。个人内容可提交发布，审核通过后全公司可用。空市场显示发布提示，搜索无结果另行提示。

## 装配与维护

Host 模块通过产品 profile 固定装配，普通 ESM 客户端模块合入产品 UI 的浏览器产物；不声明独立安装包。根目录 `pnpm run build:artifacts` 完成构建，本目录 `tsconfig.json` 检查源码。 CI 通过 `pnpm exec vitest run --config packages/deepseek-harness-product/skills/vitest.config.ts` 同时执行源码和页面行为测试。官方 profile 不加载产品模块。

原始来源摘要见 [upstream.json](upstream.json)，保留 [Apache-2.0 许可](LICENSE)。代码由本仓库维护，社区更新选择性合入，不整包替换。团队内容的格式和发布入口见[公司内容说明](../../../apps/product-desktop/docs/company-content.md)。

技能的 `SKILL.md` 声明名遵循原生英文小写字母、数字和连字符格式；目录名可以使用中文。包含中文等非 ASCII 字符的声明名保留原文并展示修复提示，不截断为其他技能名，也不向模型注册。已登记的启用权限可在文件损坏或丢失后撤销，修复文件不会自动重新启用。浏览器请求按页面基址解析，支持带路径前缀的反向代理。

目录按“全部、已启用、已停用”筛选和统计调用开关；同名技能的来源优先级、内容加载错误在对应条目中说明，不作为独立启用状态。已启用不代表内容一定可加载，实际调用继续遵守官方技能解析和权限检查。

首次读取使用原生加载指示，未知统计显示“—”，读取失败不显示空目录。刷新项目技能时保留当前项目已读取的列表或空结果；发现技能页在仓库读取完成后才显示空仓库提示。

<a id="dev-note"></a>
### 开发备注

源码从固定社区版本移入产品包，已有断言按原始语法指纹移入仓库检查基线，禁止增加新断言。原社区实现保留原 lint 范围，由独立严格类型检查（拒绝未使用的变量和参数）及行为测试验证；新增装配、配置读取和提交出口仍执行仓库 lint。仅接受当前产品状态，不读取旧插件设置备份，不自动补齐旧来源或推测安装位置。仓库状态采用 version 2，每个安装副本必须带位置、内容摘要和确认状态；格式不支持时保留原文件并报错，不迁移、不重置。技能文件与官方 Session 不变。

<a id="model-experience"></a>
## 模型体验

### 原生能力

#### 模型看到的内容

模型通过官方技能发现读取 `SKILL.md` 和资源文件，继续遵守模型调用和用户调用限制。公司内容按 Session 固定版本，输入记录沿用原生日志。

#### Token 影响

技能摘要和按需读取的正文占用上下文。页面整合不新增模型输入。

#### KV Cache 影响

不管理模型缓存；内容变化由官方请求组装处理。
