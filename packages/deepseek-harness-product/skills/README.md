# 技能

## Summary

随产品桌面固定装配，产品 UI 在左侧“扩展能力”直接挂载页面，不另行安装功能插件，不提供设置重复页或独立更新。技能通过官方 Skill Provider 发现和读取，管理操作遵守源文件声明的调用权限。页面统一为“市场／我的”：市场直接展示审核发布的公司技能，不提供创建、导入或个人分类管理；在“我的”创建、导入技能，保留本机技能、项目技能、发现技能和回收站。个人内容可提交发布，审核通过后全公司可用。空市场显示发布提示，搜索无结果另行提示。

## 装配与维护

Host 模块通过产品 profile 固定装配，普通 ESM 客户端模块合入产品 UI 的浏览器产物；不声明独立安装包。根目录 `pnpm run build:artifacts` 完成构建，本目录 `pnpm run typecheck` 分别检查 Host 和 Client，根 `tsconfig.json` 仅聚合两个编译入口，Remote 生成器只分析 Host 入口，构建与 CI 都执行两端类型检查；原生 Session 类型只进入 Client 编译，避免与 Host 服务声明混用。客户端仍由产品 UI 固定挂载，不声明自动加载插件。官方 profile 不加载产品模块。

代码按当前产品版本维护，许可证见 [LICENSE](LICENSE)。团队内容的格式和发布入口见[公司内容说明](../../../apps/product-desktop/docs/company-content.md)。

技能的 `SKILL.md` 声明名遵循原生英文小写字母、数字和连字符格式；目录名可以使用中文。包含中文等非 ASCII 字符的声明名保留原文并展示修复提示，不截断为其他技能名，也不向模型注册。已登记的启用权限可在文件损坏或丢失后撤销，修复文件不会自动重新启用。元数据和调用权限使用原生 Skill filesystem 解析器，目录及原子写入由 Harness 模块负责；加载正文时重新检查当前文件声明和管理开关。

管理服务使用原生调用身份判断限制本机所有者权限。管理页面通过原生 Remote 调用 Host，Typert 从实际服务方法生成类型和元数据，不维护 HTTP 路由或手写宿主类型；Session 选择直接使用原生 UI Session 提供的快照与 Hook 类型，不保留旧快照适配。语言、请求与页面状态由各挂载实例持有；目录、技能详情、工作区列表和工作区内容读取均传递原生 Remote 取消信号；刷新会取消被替代的同项读取。关闭详情、切换来源或离开页面会取消对应读取并释放详情忙碌状态，旧成功或失败均不能覆盖当前列表或关闭新表单。已开始的写入仍完成，页面释放后不再发起后续写入或刷新。等待公司目录和解析写入目标时沿用原生调用及管理服务的取消信号，取消后不再进入技能写入；已开始的文件写入完成后才允许关闭操作窗口。上传文件使用 Harness 原生字节编码工具。下载截止时间覆盖响应正文，超限或取消时释放读取器。

目录按“全部、已启用、已停用”筛选和统计调用开关；同名技能的来源优先级、内容加载错误在对应条目中说明，不作为独立启用状态。已启用不代表内容一定可加载，实际调用继续遵守官方技能解析和权限检查。

项目技能通过原生工作目录服务读取所选 Session 的当前目录，跟随已记录的目录切换和会话恢复；未选择或无法找到 Session 时不读取其他会话的项目。显式选择已登记的工作区时按该工作区显示。

首次读取使用原生加载指示，未知统计显示“—”，读取失败不显示空目录。刷新项目技能时保留当前项目已读取的列表或空结果；发现技能页在仓库读取完成后才显示空仓库提示。

<a id="model-experience"></a>
## Model Experience

### Native capabilities

#### What the model sees

模型通过官方技能发现读取 `SKILL.md` 和资源文件，继续遵守模型调用和用户调用限制。公司内容按 Session 固定版本，输入记录沿用原生日志。

#### Token effect

技能摘要和按需读取的正文占用上下文。页面整合不新增模型输入。

#### KV Cache effect

不管理模型缓存；内容变化由官方请求组装处理。
