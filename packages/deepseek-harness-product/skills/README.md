# 技能

<a id="summary"></a>
## 概述

在“市场”使用公司审核的技能；点击“创建技能”使用原生新会话入口，向已有草稿追加创建需求，由 AI 生成完整技能、选择分类并通过原生审批保存。在“我的”导入和管理本机、项目及发现的技能，也可恢复回收站内容。个人技能可提交公司审核。技能由原生 Skill Provider 发现和读取，遵守源文件调用权限，模块随桌面统一更新。

<a id="assembly"></a>
## 装配与维护

Host 由产品 profile 装配，Client 合入产品 UI 的浏览器产物；官方 profile 不加载产品模块，也不提供独立安装包。根目录 `pnpm run build:artifacts` 构建，本目录 `pnpm run typecheck` 检查 Host 与 Client。编译入口规则见[开发指南](../../../docs/development.md#typescript-project-layout)。

许可证见 [LICENSE](LICENSE)，包格式与公司发布操作见[公司内容说明](../../../apps/product-desktop/docs/company-content.md)。

<a id="content-and-permissions"></a>
## 内容与权限

技能的 `SKILL.md` 声明名遵循原生英文小写字母、数字和连字符格式；目录名可以使用中文。包含中文等非 ASCII 字符的声明名保留原文并展示修复提示，不截断为其他技能名，也不向模型注册。已登记的启用权限可在文件损坏或丢失后撤销，修复文件不会自动重新启用。元数据和调用权限使用原生 Skill filesystem 解析器，目录及原子写入由 Harness 模块负责；加载正文时重新检查当前文件声明和管理开关。

<a id="operations"></a>
## 管理操作与取消

管理服务使用原生调用身份判断限制本机所有者权限。管理页面通过原生 Remote 调用 Host，Typert 从实际服务方法生成类型和元数据，不维护 HTTP 路由或手写宿主类型；Session 选择使用原生 UI Session 快照与 Hook 类型。

管理操作重试保留当前页的错误提示和控件外观，确认成功后清除；请求发起时锁定重复提交。导入、删除及仓库写入弹窗预留固定反馈区，等待、失败和重试不改变操作按钮位置；重试保留原错误，长错误可滚动并通过键盘阅读。安装、导入的工作区重试成功后，原按钮的焦点进入工作区选择器，列表为空时进入范围选择器；不滚动页面，也不抢占其他控件焦点。启停成功直接由开关反映，不增加成功横幅。

语言、请求与页面状态由各挂载实例持有；目录、技能详情、工作区列表和工作区内容读取均传递原生 Remote 取消信号；刷新会取消被替代的同项读取。关闭详情、切换来源或离开页面会取消对应读取并释放详情忙碌状态，旧成功或失败均不能覆盖当前列表或关闭新表单。

等待公司目录、解析目标及导入展开、检查、临时复制期间均可取消；取消清理暂存内容，停止后续技能和写入。单个技能开始重命名替换后完整结束，保留已提交技能并刷新原生目录缓存。其他已开始的本地写入仍完成；调用取消后不返回成功结果，页面释放后不再发起后续写入或刷新。

导入默认跳过已有同名普通目录、文件及文件链接，包括目标暂时不可用的文件链接；明确覆盖文件链接时只替换链接本身，不修改链接目标。目录链接拒绝覆盖。冲突检查无法读取目录状态时停止导入，保留原文件。

回收恢复前校验元数据、文件归属、条目类型和完整目录，拒绝回收目录及元数据链接；任何同名目标均阻止恢复。损坏条目保留文件并记录位置诊断，目录读取失败不显示为空回收站。恢复失败时回滚已移动的文件；回滚未完成会明确提示检查原位置与回收目录，不报告成功。

导入读取至写入完成期间，表单禁止编辑、重复提交和关闭；文件逐个读取，页面卸载后停止后续读取和编码。读取失败、部分或全部条目导入失败时保留所选内容，分别展示已导入、已跳过和失败项及原因；修复后可重试，已导入内容保留。输入无效或来源不可读通过原生 Remote 返回操作错误，已处理的条目始终保留完整结果，不压成通用错误。

拖入文件夹时逐批、逐项遍历，最多读取 1000 个文件和 1000 个目录；路径最多 64 层、512 字符，单文件最多 32 MiB，总计 64 MiB。超限或取消即停止后续读取，不上传部分选择，可重新选择后重试。

创建、上传和市场安装分别声明所需请求字段，由原生 Typert 剥离未声明的参数。上传只接收内容，不接收宿主路径或预览参数。文件夹和 ZIP 内的路径统一拒绝 Windows 禁用字符、控制字符、保留设备名及尾随点或空格，保留中文和隐藏资源文件。写入前检查整批路径，拒绝重复条目、目录大小写别名及文件与目录冲突；ZIP 解压结果必须包含全部选定文件，缺失时拒绝导入并保留现有技能。本地导入通过文件选择或拖拽上传 ZIP、技能文件夹或 SKILL.md，上传文件使用 Harness 原生字节编码工具。替换或移除所选内容、关闭导入弹窗会取消待完成的拖拽读取，旧成功或失败不影响当前选择。

外部目录响应在 JSON 解析处校验字段，详情和下载共用已校验的数据。下载使用 Harness 原生截止时间，并复用产品包的[限流读取器](../product/README.md#streaming)，截止时间覆盖完整正文；超限或取消时不返回部分内容。

个人技能提交前的导出将原生取消信号传入文件读取；调用取消或管理服务卸载时停止遍历并关闭当前文件，不返回部分内容，源文件保持不变。

管理器作为原生必需 Skill Provider 注册，统一提供停用策略和同名副本选择。来源、文档或已有策略文件读取失败时，当前技能目录及调用查询明确失败，不缓存部分结果、不回退到可能绕过停用策略的原生副本；恢复后下一次查询重新发现。这会暂时影响其他正常技能的查询。已缓存的管理器候选加载失败也不回退。策略文件尚未创建时使用初始空策略；可选目录不存在、失效链接和无效元数据继续按原规则跳过。

目录按“全部、已启用、已停用”筛选和统计调用开关；同名技能的来源优先级、内容加载错误在对应条目中说明，不作为独立启用状态。已启用不代表内容一定可加载，实际调用继续遵守官方技能解析和权限检查。

<a id="discovery"></a>
## 发现与工作区

发现技能页直接使用原生 Remote 生成的目录结果类型；外部响应的身份、显示字段和统计值由 Host 校验。ClawHub 与 skills.sh 搜索分别由当前请求的取消控制器管理；替换查询、切换来源或离开页面会取消读取，旧结果、错误和完成回调不改写新搜索。ClawHub 榜单最多累计显示 100 条。

仓库列表随发现页读取，离开页签、关闭页面或切换 Session 会取消读取；重新进入立即发起新读取，旧结果、错误和完成回调不覆盖新列表或解除新操作的忙碌状态。目录读取期间可切换技能来源，写入期间仍阻止来源切换和冲突操作。

GitHub 仓库检查更新沿用技能页面的取消信号；关闭页面或切换 Session 会取消当前下载，停止后续仓库检查与列表回读。已提交的仓库登记及完成的扫描保留，关闭后不再开始新增仓库的扫描；重新打开页面可再次检查。已开始的本地安装、更新和恢复事务仍完整结束，写入后的列表回读仍受页面取消信号约束。

仓库 ZIP、本地技能导入及专家包导入复用产品包的 `content-paths` 冲突检查，包含显式目录及隐式父目录，拒绝目录大小写别名和文件／目录冲突。检查失败保留上次完整仓库版本及已安装文件，阻止该次更新；修正归档后重新检查。

仓库添加、移除、安装、卸载、更新和回退按写入回执报告结果。写入成功后列表刷新失败时保留已确认的结果，提示重新读取，避免重复操作。添加后的扫描失败保留仓库登记，关闭添加表单，可在管理仓库中重新检查更新；移除成功后立即收起该仓库，已安装技能保留。

更新或回退失败时恢复原目录，临时文件清理失败仅记录保留位置，不掩盖原始错误。自动恢复未完成时保留原目录、备份及暂存文件，明确提示检查位置、勿重复操作；诊断保留替换与恢复的两项原因。

仓库列表和更新预览可能恢复未确认的安装；恢复与启停、分类写入串行执行，操作结束后刷新原生技能目录，即使恢复已提交但后续预览失败。

更新预览、替换前复核及回退副本检查使用[受限文件读取](../product/README.md#company-content)，按实际字节累计限制。文件在读取中变化时拒绝生成预览或开始替换，保留文件与安装记录，编辑完成后可重新预览。

安装记录、仓库缓存及恢复凭据也使用受限读取。安装记录经结构及来源校验，读取失败时停止操作并保留原文件；缓存损坏要求重新检查更新。恢复凭据与回收条目共用元数据校验，无效凭据不能确认恢复；修复后下次读取可重新确认。恢复成功后的日志写入或凭据清理失败不改变成功结果；清理失败记录保留位置，残留凭据不重新应用到已确认的安装。管理日志写入失败时通过控制台保留诊断，后续日志仍可继续写入。

仓库技能每个安装副本保留一份可回退版本；连续更新或回退提交后，清理被替代且未被其他安装记录引用的旧备份。“我的”移入回收站与仓库卸载使用同一来源记录事务，仅移动选定用户目录或项目中的安装副本；恢复保留来源及回退能力，永久删除成功后移除对应记录并清理无引用备份。提交或删除失败保留原有记录和备份；旧备份清理失败记入管理诊断，不改变已提交结果。

市场、我的和项目技能使用[共用业务分类](../product/README.md#catalogs-and-tasks)，空目录也可选择。来源下直接显示技能条目，不按原始分类嵌套文件夹。AI 创建和条目归类菜单使用相同预设，宿主校验创建时的分类名称和归类时的分类 ID；原始包文件及本地归属记录保留。技能包通过标准 `SKILL.md` 的 `metadata.category` 携带默认分类，名称为最多 24 字符的非空单行文字；未声明时在技能卡片上显示“其他”。本地分类调整按来源和技能名称保存，优先于包内默认值；提交发布时将当前分类写入导出的技能包，不改动源文件。同源同名技能或其他回收条目仍存在、来源无法核验时，永久删除旧条目保留分类及排序；最后一个副本删除后才清理。分类清理或诊断写入失败不改变已完成的删除结果。

提交公司发布保留中文文件名、空格及二进制资源，拒绝符号链接和非跨平台路径。仅包根目录的 `SKILL.md` 作为技能入口，资料与模板中的同名文件保持原样。导出包复用公司内容校验，最多 2048 个文件、32 MiB，完整资源路径最多 240 字符，入口文档最多 128 KiB；超限或无效内容在导出时拒绝。资源使用[受限文件读取](../product/README.md#company-content)；检测到大小变化或取消时不返回部分包，原文件保留，可在编辑完成后重试。

项目技能通过原生工作目录服务读取所选 Session 的当前目录，跟随已记录的目录切换和会话恢复；未选择或无法找到 Session 时不读取其他会话的项目。显式选择已登记的工作区时按该工作区显示。目录重叠检查使用原生路径规范化；目录无法核验时提示不可用并阻止项目写入，修复后可重新读取。

AI 创建的个人技能保存在 DSH_HOME/skills，交给现有原生 Skill Provider。导入及发现技能安装共用目标选择器。工作区列表读取失败时显示原因并提供原位重试，保留表单及目标范围；成功读取前不显示空工作区结论。本机用户目录仍可使用，重试沿用页面取消信号。导入与发现页的连续工作区重试只发起一次读取；刷新仓库目录会取消并替换旧的工作区读取，旧结果、错误及完成回调不改写新请求。关闭页面同时取消读取。

<a id="ui-state"></a>
## 界面状态

页面标题和说明遵循[统一资源页规范](../../extensions/ui-deepseek-harness-product/DESIGN.md#布局与操作)，独立空目录和首次读取使用[统一状态容器](../../extensions/ui-deepseek-harness-product/DESIGN.md#状态与焦点)。

读取诊断、操作结果和导入明细按当前界面语言显示；切换语言保留页签、筛选和所选文件，不重发读取或写入。分类名称直接使用共用分类数据，中文界面显示中文，其他语言沿用英文；分类操作的提示与分类名称同步更新。详情及操作弹窗关闭后使用原生返回焦点；原按钮因同步、筛选或卸载消失或不可用时，回到当前搜索框，无搜索框时回到列表区域。仓库管理弹窗内切换内容移除了当前控件时，焦点回到关闭按钮。保留查询、筛选和文字选区，不抢占其他可用控件的焦点。

输入、按钮、启停开关、加载指示、菜单和通用操作图标直接使用 Harness 原生组件，多行输入使用标准 textarea 属性。启停写入期间仅锁定冲突的写入入口并保留外观，创建会话、刷新目录和查看详情保持可用；详情读取和取消不影响写入锁。成功后回读状态并由开关反映结果，不插入通用成功横幅；失败时保留原状态并展示本地化提示。操作结束后恢复因临时禁用丢失的开关焦点；条目被筛选移除时回到当前搜索框，保留查询、筛选和用户已移到其他控件的焦点。筛选和操作菜单在控件禁用时关闭，恢复启用后需重新打开。首次读取使用原生加载指示，未知统计显示“—”，读取失败不显示空目录。刷新保留当前已读取的列表或空结果；项目技能后台读取失败保留已确认的工作区、技能卡片和筛选，在列表下显示错误，重试保留原提示及控件；发现技能页在仓库读取完成后才显示空仓库提示。

窄窗口中筛选、搜索及操作分行排列，子页签按文字换行自适应高度，保留完整控件和横向边界。页面及仓库刷新保留按钮图标、尺寸、名称和外观，通过忙碌标记及进度说明反馈；批量刷新覆盖全部仓库。技能目录的刷新和读取重试保留键盘焦点，等待时重复触发不重新读取。发现页的安装、卸载、更新、回退及仓库增删保留当前弹窗，重试期间保留错误和表单，成功后清除；错误和执行进度只在当前弹窗显示，背景不重复播报或插入通用加载行。导入、安装和卸载使用原生弹窗页脚，正文滚动或反馈增加时保持操作可见；安装和卸载按钮按普通与进度文案预留宽度。导入入口在写入期间保留节点和外观，阻止重复打开；弹窗关闭后由原生机制返回焦点。导入、回收站和仓库操作的确认按钮在等待及失败重试时保留键盘焦点与外观，使用无障碍状态报告暂不可用；其他冲突操作保持锁定；快速连续点击、取消和关闭均不能切走正在执行的操作。安装目标选择器在读取或写入等待时保留已选位置、路径和控件外观，关闭菜单并阻止重复选择；工作区重试保留原错误和重试按钮，成功后清除。目录缺失或读取失败仍显示禁用状态。

市场、本机、项目、仓库与第三方技能详情，以及更新和回退预览读取失败时保留当前弹窗，提供原位重试；重试保留错误区、按钮外观和键盘焦点，不重新插入加载占位，关闭时取消读取并清除该弹窗的错误。重试使用原技能及其来源、工作区，连续点击只发起一次读取。成功移除重试入口时，详情聚焦正文，更新及回退预览聚焦变更内容，目录与搜索聚焦当前搜索框，无搜索框时聚焦当前列表区域；不滚动页面，不抢占已移到其他控件的焦点。连接异常显示本地化服务提示，技能诊断保留具体原因。ClawHub 榜单、ClawHub 与 skills.sh 搜索、安装位置重试和仓库刷新同样保持焦点，等待时不能重复操作。

ClawHub 与 skills.sh 搜索从输入有效查询起报告读取状态，等待输入停止期间不显示空结果；清空查询立即取消搜索。仅首尾空格变化保留当前请求、结果和错误，不重复读取。重新进入发现页或切回来源时，后台回读保留同一查询的已确认结果，失败和重试不清空列表；成功更新移除当前聚焦条目时返回搜索框，保留其他控件的焦点。仅首次读取显示加载占位，空结果在搜索完成后显示。

ClawHub 分页保留加载按钮、已有条目和键盘焦点，连续点击只读取一次；失败后在原按钮重试。重叠页按技能标识合并并更新内容。最后一页加载完成后，键盘焦点移至首个新增技能的详情入口；没有新增可见条目时返回搜索框。滚动加载、已移走的焦点或已取消的读取不触发焦点转移。

技能正文复制保留按钮名称、外观和键盘焦点，原生备用复制同步归还原控件的焦点并保留正文选区与滚动位置，独立显示复制结果；等待期间阻止重复写入剪贴板，重试保留原失败提示。关闭详情或替换正文后，旧回执不显示在当前内容中。

导入时移除所选文件或文件夹，仅在移除按钮持有焦点时将焦点交回对应选择入口；保留其他控件焦点，不打开系统选择器，也不执行安装。

本地技能导入、移入回收站和永久删除保留确认按钮的名称与外观，执行期间锁定重复提交、取消和关闭。失败及部分导入的提示保留在当前弹窗，重试不清空；导入结果在目录回读前原位更新，保留提示区滚动位置。成功后关闭弹窗并在原页显示结果。移入回收站、恢复或永久删除移除原操作按钮时，焦点返回当前搜索框，无搜索框时返回列表区域；保留其他控件的焦点、草稿及文字选区。打开另一确认框不沿用此前操作的提示。

技能目录读取失败时收起市场、本机及回收站的失效条目，统计显示“—”，提供原位重试；独立读取的工作区和发现页保留自身结果。已完成的写入保留成功提示，重试只读取状态，不重复恢复、删除或导入。重新读取期间保留错误区、原按钮及其外观，不额外插入加载行；页签与筛选保持不变，连续重试只发起一次读取，成功后恢复列表和操作。进入回收站触发的目录重读同样标记忙碌，完成前阻止重复重试。项目工作区列表及技能读取失败也保留各自错误，刷新成功后清除。

目录及工作区刷新移除当前聚焦条目时，焦点返回当前搜索框；回收站返回列表区域。后台公司同步使用相同处理，保留搜索文字、筛选和已移到其他控件的焦点，不恢复已切换页签中的旧控件。

发现技能的仓库及工作区回读移除或禁用当前聚焦控件时，焦点返回仓库搜索框；管理仓库弹窗内返回关闭按钮。回读保留仍可用的控件、查询及文字选区，不抢占其他控件焦点，也不恢复已离开的页面。每个不可用副本只展示一处原因；工作区读取失败显示对应错误，不提示重新登记项目。

## 模型体验

### 原生能力

#### 模型看到的内容

模型通过官方技能发现读取 `SKILL.md` 和资源文件，继续遵守模型调用和用户调用限制。公司内容按 Session 固定版本，输入记录沿用原生日志。

#### Token 影响

技能摘要和按需读取的正文占用上下文。页面整合不新增模型输入。

#### KV Cache 影响

不管理模型缓存；内容变化由官方请求组装处理。
