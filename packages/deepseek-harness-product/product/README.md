# 企业产品协议

<a id="summary"></a>
## 概述

通过已认证员工会话访问公司连接器、知识库和内容发布服务，校验请求与回执。凭据由主进程持有，失败保留编辑内容；协议实现不依赖 Harness 或 Electron。

<a id="authentication"></a>
## 认证与请求

主进程通过命名空间桥校验 `protocol` 白名单，员工令牌和连接器私密配置不会返回渲染进程。认证入口统一检查会话有效期、绑定员工和调用者取消信号，并在返回前拒绝账户切换后的迟到结果；业务分发沿用该信号。托管连接器通过原生 `Headers.set` 覆盖员工认证与版本头，不受目录字段大小写影响。`connector-draft` 出口提供连接器表单、配置模板、连接目标比较、重连结果及写入回执校验。保存、删除和审核只在回执身份与版本匹配后更新界面；失败保留编辑内容。

连接器表单与本机配置共用私密字段校验：HTTP Header 使用原生 `Headers` 检查名称和值，拒绝大小写重复的名称；STDIO 环境变量拒绝名称中的等号及名称或值中的空字符。可执行文件与参数拒绝空字符，表单和 MCP JSON 导入使用相同规则。校验失败不进行工具发现或写入，界面保留输入并提示对应字段。

启动登录、显式刷新及业务请求共享同一次员工会话刷新。仅带令牌启动时，首次刷新补全员工身份并保留该次登录与刷新的等待。取消调用立即结束等待，不中断已发起的令牌轮换；即使所有调用者取消，当前员工仍接纳并保存轮换后的会话。员工切换和释放会取消旧身份的等待与刷新，释放仍等待已发起的刷新请求实际结束。

设备上报与反馈由主进程使用 Harness 原生匿名 ID 派生的设备 UUID。原始匿名 ID 不暴露给服务端或页面，语义见[设备与反馈](../desktop/README.md#device-and-feedback)。

<a id="catalogs-and-tasks"></a>
## 目录与任务

技能、专家和专家团选人共用 `content-categories` 的固定业务分类。分类标识及中英文名称映射到同一分类，空值与其他名称归入“其他”；导入内容不生成额外筛选项，也不改写原始元数据。

`catalog` 出口统一校验公开目录与工具元数据。目录项必须有服务端 ID 和名称，重复 ID、损坏条目或未知工具读写权限均报错，不返回部分列表；工具没有展示名时使用原名。主进程沿用同一工具校验，不隐藏无效工具声明。

`knowledge.destinations.list` 通过员工认证调用服务端可写知识库查询，仅传搜索词及分页，不接受客户端身份或权限声明；保存目标与任务检索目录分别读取，不改变任务范围。

`knowledge.bases.get/update` 读取最新名称、简介及版本，并通过员工权限、稳定操作 ID 和期望版本保存修改；只供员工界面使用，不向模型注册。更新后使目录缓存失效，正文仍由 WeKnora 管理。

`protocol` 提供共用的知识文档元数据解析器，员工页面和模型保存工具使用同一字段及类型检查，只读取声明的字段。调用方分别核对文档、知识库及操作目标；原文件预览继续校验独立的大小限制和内容版本。

`knowledge.documents.processing` 按库及文档 ID 读取经过校验的处理阶段、耗时和摘要；`knowledge.documents.summary.refresh` 使用稳定操作 ID 提交摘要重生成并核对文档回执。两项仅供员工界面使用，不注册为模型工具；原始引擎诊断和服务端凭据不跨越 IPC。

`tasks.capabilities.read/prepare` 仅处理执行模式和任务知识库 ID，跨进程请求、读取结果及准备回执共用 `protocol` 的运行时校验和推导类型，拒绝过时字段及损坏回执。准备回执须与显式选择一致，且每个知识库都通过依赖检查；显式恢复可移除失效知识库。校验失败不切换任务、不清空草稿；已开始任务的选择变更通过官方 Session 边界创建新任务。未选择知识库时不注册检索工具，不能扩大为空范围检索。

连接器和知识库目录读取始终查询服务端，后台快照仅检测目录变化；刷新或会话续期失败及恢复也通知页面重新读取，重复故障不重复通知。直接传递服务端状态，不生成额外的可用性状态。工具执行重新检查服务端权限；连接器调用按 ID 查询当前配置，不遍历全目录。目录重置、员工切换和释放会取消即时读取及后台刷新，迟到结果不能返回或写入快照。连接器运行时查询与本机配置、工具发现共用同一目录生命周期；提交配置时立即使旧查询失效，完成设备连接清理后通知刷新。已建立的 MCP 业务请求不属于目录读取。释放等待所有请求实际结束，释放后拒绝读取。

<a id="company-content"></a>
## 公司内容

`content-files` 为技能与专家包提供宿主侧受限文件读取，限制实际读取量，拒绝符号链接、打开前被替换的文件及读取字节数与初始大小不一致的文件。成功、失败和取消均关闭文件句柄，错误码由调用模块本地化。

公司内容通过 `content.submissions.inspect/submit` 校验并提交单个原生资源，身份和取消信号由主进程持有，不接收所有者声明。审核状态同时核对文件摘要和目录元数据修订号，改名、分类或头像变化不会复用其他申请的状态；查询只读取摘要，完整内容通过详情读取。内容校验在落盘前拒绝 Windows 非法字符、末尾点或空格、保留设备名、文件与目录路径冲突、同一父目录的大小写别名，以及独立专家与专家团实际成员的 ID 冲突；中文名和名称中间的空格可用。认证 API 不跟随重定向、不自动重发写请求。

`content-paths` 为技能和专家包提供不依赖 Node 的路径冲突检查，统一处理显式目录、隐式父目录、重复条目和大小写别名；路径格式与数量限制由各导入入口校验。

目录展示信息参与发布索引与修订摘要。读取时保留原文，不通过去除首尾空白改变已发布摘要；纯空白名称或分类无效。

公司技能使用原生 YAML 1.2 元数据规则，名称和简介必须是非空单行字符串，名称须与目录一致，简介最多 2,000 字符。拒绝损坏或重复字段、未知标签、别名、超过 64 层的嵌套及无效技能调用声明；包含冒号的文本和看似布尔值或数字的字符串须用引号包裹。AI 发布工具分发包含 YAML 实现与许可证的独立校验产物，无需安装依赖。

公司目录源提供目录读取、刷新、会话版本检查及个人团队固定专家版本读取，均可接收调用者的取消信号；精确版本读取不切换目录或会话绑定。目录刷新只释放该调用者的等待，主进程继续管理共享同步。

<a id="streaming"></a>
## 流式读取

知识库原文件、下载错误响应和技能归档复用 `streamResponseBody` 的严格字节限制与完整读取。原生取消订阅不受其他监听器阻断；取消、超限或写入失败会释放读取锁并发起流取消，不等待上游清理完成，也不以清理错误替换原始失败。同步或异步顺序写入完成后才能释放读取器。

<a id="model-experience"></a>
## 模型体验

### 企业能力

#### 模型看到的内容

本包不直接组装模型输入；运行时负责记录 `MCP` 连接器工具和知识库检索结果。

#### Token 影响

协议和界面本身不增加模型 Token。

#### KV Cache 影响

不管理模型缓存；工具及检索内容的变化由官方模型请求组装处理。

## 已知限制与延期工作
<a id="known-limitations-and-deferred-work"></a>

- 企业服务需要有效员工身份及可访问的组织服务；第三方专家和技能插件使用其自身的管理入口。
