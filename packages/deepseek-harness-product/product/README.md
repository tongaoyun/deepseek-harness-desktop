# 企业产品协议

<a id="summary"></a>
## 概述

通过已认证员工会话访问公司连接器、资料库和内容发布服务，校验请求与回执。凭据由主进程持有，失败保留编辑内容；协议实现不依赖 Harness 或 Electron。

<a id="authentication"></a>
## 认证与请求

`auth-screen` 出口提供启动页和工作区整窗登录共用的文案与展示样式，不持有认证状态。

主进程通过命名空间桥校验 `protocol` 白名单，员工令牌和连接器私密配置不会返回渲染进程。认证入口统一检查会话有效期、绑定员工和调用者取消信号，并在返回前拒绝账户切换后的迟到结果；业务分发沿用该信号。托管连接器通过原生 `Headers.set` 覆盖员工认证与版本头，不受目录字段大小写影响。`connector-draft` 出口提供连接器表单、配置模板、连接目标比较、重连结果及写入回执校验。保存、删除和审核只在回执身份与版本匹配后更新界面；失败保留编辑内容。

连接器表单与本机配置共用私密字段校验：HTTP Header 使用原生 `Headers` 检查名称和值，拒绝大小写重复的名称；STDIO 环境变量拒绝名称中的等号及名称或值中的空字符。可执行文件与参数拒绝空字符，表单和 MCP JSON 导入使用相同规则。校验失败不进行工具发现或写入，界面保留输入并提示对应字段。

访问令牌默认有效 30 分钟，独立的长期登录凭据有效 30 天，正常使用时延长。启动、休眠恢复、显式刷新和业务请求共享续期；取消等待不取消已发起的续期，旧身份回执不得覆盖新员工。网络、组织服务暂时故障和短期令牌过期保留长期凭据；长期凭据被撤销、到期或员工停用后重新登录。业务写入不会因续期自动重发。主动退出撤销整次设备登录及其全部访问令牌；失败保留登录，允许重试。

设备上报与反馈由主进程使用 Harness 原生匿名 ID 派生的设备 UUID。原始匿名 ID 不暴露给服务端或页面，语义见[设备与反馈](../desktop/README.md#device-and-feedback)。

<a id="catalogs-and-tasks"></a>
## 目录与资料库

连接器目录提供经过校验的产品元数据。资料库使用 `library.*` 方法读取服务端分页、创建个人库、管理文件夹、重命名、移动及删除；文件读写通过主进程专用传输完成。

`library` 出口提供库、文件、文件夹、分页和上传选择的校验与推导类型，以及资料选择与原生附件准入共用的数量和大小限制；字段及方法见[资料库数据与接口](../../../docs/subsystems/deepseek-harness-product.md#资料库数据与接口)。创建库和文件夹使用幂等键，修改和删除使用期望版本；回执的资源标识、归属、分页及更新版本必须匹配请求。校验失败不返回部分列表，也不更新本地内容。

`catalog` 出口校验连接器目录及工具元数据，拒绝重复标识、损坏条目和未知工具读写权限。技能与专家分类由 `content-categories` 提供固定业务分类及本地化名称，未知值归入“其他”，不改写导入元数据。

IPC 只允许固定方法与校验后的标识、版本和操作键。员工身份来自主进程会话；服务端实时决定可见性及管理权限。文件内容以不可变摘要定位，客户端不接收 MinIO 凭据、对象地址或服务端路径。

<a id="company-content"></a>
## 公司内容

`content-files` 为技能与专家包提供宿主侧受限文件读取，限制实际读取量，拒绝符号链接、打开前被替换的文件，以及读取期间大小、修改时间或状态变更时间变化的文件。成功、失败和取消均关闭文件句柄，错误码由调用模块本地化。

公司内容通过 `content.submissions.inspect/submit` 校验并提交单个原生资源，身份和取消信号由主进程持有，不接收所有者声明。审核状态同时核对文件摘要和目录元数据修订号，改名、分类或头像变化不会复用其他申请的状态；查询只读取摘要，完整内容通过详情读取。内容校验在落盘前拒绝 Windows 非法字符、末尾点或空格、保留设备名、文件与目录路径冲突、同一父目录的大小写别名，以及独立专家与专家团实际成员的 ID 冲突；中文名和名称中间的空格可用。认证 API 不跟随重定向、不自动重发写请求。

`content-paths` 为技能、专家包及公司内容提供不依赖 Node 的路径冲突检查，统一处理显式目录、隐式父目录、重复条目、大小写和 Unicode 等价名称；比较时使用 NFC，不改写原始文件名或内容摘要。路径格式与数量限制由各导入入口校验。

目录展示信息参与发布索引与修订摘要。读取时保留原文，不通过去除首尾空白改变已发布摘要；纯空白名称或分类无效。

公司技能使用原生 YAML 1.2 元数据规则，名称和简介必须是非空单行字符串，名称须与目录一致，简介最多 2,000 字符。拒绝损坏或重复字段、未知标签、别名、超过 64 层的嵌套及无效技能调用声明；包含冒号的文本和看似布尔值或数字的字符串须用引号包裹。AI 发布工具分发包含 YAML 实现与许可证的独立校验产物，无需安装依赖。

公司目录源提供目录读取、刷新、会话版本检查及个人团队固定专家版本读取，均可接收调用者的取消信号；精确版本读取不切换目录或会话绑定。目录刷新只释放该调用者的等待，主进程继续管理共享同步。

<a id="streaming"></a>
## 流式读取

资料库原文件、下载错误响应和技能归档复用 `streamResponseBody` 的严格字节限制与完整读取。原生取消订阅不受其他监听器阻断；取消、超限或写入失败会释放读取锁并发起流取消，不等待上游清理完成，也不以清理错误替换原始失败。同步或异步顺序写入完成后才能释放读取器。

<a id="model-experience"></a>
## 模型体验

### 企业能力

#### 模型看到的内容

本包不直接组装模型输入；`MCP` 工具结果和资料附件由 Harness 原生 Session 记录。

#### Token 影响

协议和界面本身不增加模型 Token。

#### KV Cache 影响

不管理模型缓存；工具结果和资料附件由原生模型请求组装处理。

## 已知限制与延期工作
<a id="known-limitations-and-deferred-work"></a>

- 企业服务需要有效员工身份及可访问的组织服务；第三方专家和技能插件使用其自身的管理入口。

<a id="dev-note"></a>
### 开发备注

在仓库根目录运行 `pnpm run build:product` 生成声明及 `exports` 对应的运行文件；仅执行本包的 TypeScript 构建不能用于桌面启动。构建后使用普通 Node 导入公开入口，检查实际产物及依赖解析。
