# 企业产品协议

## Summary

通过已认证员工会话访问公司连接器、知识库和内容发布服务，校验请求与回执。凭据由主进程持有，失败保留编辑内容；协议实现不依赖 Harness 或 Electron。

<a id="authentication"></a>
## 认证与请求

主进程通过命名空间桥校验 `protocol` 白名单，员工令牌和连接器私密配置不会返回渲染进程。认证入口统一检查会话有效期、绑定员工和调用者取消信号，并在返回前拒绝账户切换后的迟到结果；业务分发沿用该信号。托管连接器通过原生 `Headers.set` 覆盖员工认证与版本头，不受目录字段大小写影响。`connector-draft` 出口提供连接器表单、配置模板、重连结果及写入回执校验。保存、删除和审核只在回执身份与版本匹配后更新界面；失败保留编辑内容。

业务请求共享临期会话刷新；取消调用立即结束等待，不中断共享刷新。员工切换和释放会取消旧身份的等待与刷新，释放仍等待已发起的刷新请求实际结束。

产品桥接不提供 `native.*` 方法；安装标识与健康检查仅供主进程设备上报和反馈使用。原始安装标识不暴露给页面，格式见 [sidecar 协议](../../../native/deepseek-harness/README.zh.md)。

<a id="catalogs-and-tasks"></a>
## 目录与任务

`catalog` 出口统一校验公开目录与工具元数据。目录项必须有服务端 ID 和名称，重复 ID、损坏条目或未知工具读写权限均报错，不返回部分列表；工具没有展示名时使用原名。主进程沿用同一工具校验，不隐藏无效工具声明。

`tasks.capabilities.read/prepare` 仅处理执行模式和任务知识库 ID，跨进程请求、读取结果及准备回执共用 `protocol` 的运行时校验和推导类型，拒绝过时字段及损坏回执。准备回执须与显式选择一致，且每个知识库都通过依赖检查；显式恢复可移除失效知识库。校验失败不切换任务、不清空草稿；已开始任务的选择变更通过官方 Session 边界创建新任务。未选择知识库时不注册检索工具，不能扩大为空范围检索。

连接器和知识库目录读取始终查询服务端，后台快照仅检测目录变化；直接传递服务端状态，不生成额外的可用性状态。工具执行重新检查服务端权限；连接器调用按 ID 查询当前配置，不遍历全目录。目录重置、员工切换和释放会取消即时读取及后台刷新，迟到结果不能返回或写入快照；释放等待所有请求实际结束，释放后拒绝读取。

<a id="company-content"></a>
## 公司内容

公司内容通过 `content.submissions.inspect/submit` 校验并提交单个原生资源，身份和取消信号由主进程持有，不接收所有者声明。审核状态只读取摘要，完整内容通过详情读取。内容校验在落盘前拒绝文件与目录路径冲突、同一父目录的大小写别名，以及独立专家与专家团实际成员的 ID 冲突；认证 API 不跟随重定向、不自动重发写请求。

公司技能和专家使用原生 YAML 1.2 元数据规则，名称和简介必须是非空单行字符串，技能名称还须与目录一致。拒绝损坏或重复字段、未知标签、别名、超过 64 层的嵌套及无效技能调用声明；包含冒号的文本和看似布尔值或数字的字符串须用引号包裹。AI 发布工具分发包含 YAML 实现与许可证的独立校验产物，无需安装依赖。

公司目录源的读取、刷新和会话版本检查均可接收调用者的取消信号；目录刷新只释放该调用者的等待，主进程继续管理共享同步。

<a id="streaming"></a>
## 流式读取

知识库原文件、下载错误响应和技能归档复用 `streamResponseBody` 的严格字节限制与完整读取。原生取消订阅不受其他监听器阻断；取消、超限或写入失败会释放读取锁并发起流取消，不等待上游清理完成，也不以清理错误替换原始失败。同步或异步顺序写入完成后才能释放读取器。

<a id="model-experience"></a>
## Model Experience

### Enterprise capabilities

#### What the model sees

本包不直接组装模型输入；运行时负责记录 `MCP` 连接器工具和知识库检索结果。

#### Token effect

协议和界面本身不增加模型 Token。

#### KV Cache effect

不管理模型缓存；工具及检索内容的变化由官方模型请求组装处理。

## Known Limitations and Deferred Work
<a id="known-limitations-and-deferred-work"></a>

- 企业服务需要有效员工身份及可访问的组织服务；第三方专家和技能插件使用其自身的管理入口。
