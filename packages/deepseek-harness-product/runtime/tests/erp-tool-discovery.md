# 连接器工具按需发现回归

产品运行时已启用后台目录和会话按需发现。沿用官方 MCP、Agent、审批与 JSONL，不修改官方执行循环。

在桌面仓库根目录执行，无需员工账号、模型密钥或真实 ERP：

```sh
pnpm exec vitest run packages/deepseek-harness-product/runtime/tests/erp-tool-discovery.spec.ts
```

[用例](erp-tool-discovery.spec.ts)通过真实文件 profile、Loader、原生 MCP 客户端、审批、Session Projection 和 JSONL 装配。ERP HTTP 服务、产品目录和模型输出受控模拟；PTC 在 Agent 作用域挂载原生 PTC Executor，使用官方 Node 运行时，真实启动子进程。

覆盖 300 个已声明工具、未声明工具拒绝、中文业务查询、模型提供的同义／翻译查询及日志重放、仅连接器名不命中、英文词内片段不误匹配、精确原名引用及同名连接器隔离、引用缺失／失权／版本变化、混用参数／重复／数量超限拒绝、整批校验失败不加载部分工具、会话与子 Agent 隔离、连续创建和关闭会话后释放全部直属作用域、原生工具过滤、写入拒绝／单次同意／再次拒绝、刷新期间拦截与相同定义重连、刷新后富内容仍由原生处理、目录新增工具不自动暴露、MCP 资源读取与服务说明、原生与 PTC 精确引用恢复及恢复后真实执行、PTC 缺失和损坏元数据拒绝执行、发现后请求前中断、取消及卸载等待、完整 UTF-8 结果超限、策略拒绝后清理、坏记录隔离且直接调用无法绕过、传输凭据不进入日志。

[无密钥快照](expected/erp-tool-discovery.json)比较工具定义的 UTF-8 JSON 字节：完整 300 项为 91,399 字节，搜索入口加 2 个匹配项为 2,100 字节。数字不包括其他工具、历史、提示词和结果，不代表 tokens 或实际延迟。

脚本模型验证执行链路，尚未验收真实模型选工具准确率、真实 ERP 业务权限或网络延迟。[搜索排序测试](connector-search.spec.ts)补充原名优先、驼峰拆词、全角归一、词频权重和重复词去重。搜索仍为词匹配，同义表达由模型显式提交，不包含固定业务同义词表或向量检索服务。自动断线重连继续由官方 MCP 客户端负责，本用例验证产品刷新重建及定义固定。
