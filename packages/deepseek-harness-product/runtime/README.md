# 企业运行时

## Summary

按会话发现企业连接器工具，并在选定知识库中检索和读取资料。执行、审批和持久化沿用 Harness 原生 Agent、Session、Preset 与 MCP；技能由原生 Skill Provider 和 `skill` 工具加载。

## 连接器

产品插件在 Host 加载时读取可用连接器，由官方 MCP 客户端建连。完整工具目录使用 Cordis 独立服务保存，不进入普通 Agent 的工具列表；会话与子 Agent 各自通过 `connector_search_tools` 搜索业务关键词，加载匹配的原生定义。新建对话不等待重新建连，也不继承其他会话发现过的工具。原生工具权限过滤可限制发现入口；MCP 资源工具和服务说明继续沿用官方行为。

发现时重新检查目录，执行及资源读取时按 ID 检查版本和访问状态。READ 放行，WRITE 交由官方审批，未声明或尚未发现的业务工具拒绝调用。搜索不执行业务操作，不使用统一的业务执行代理。连接器仍以一个系统入口展示，无需拆成数百个目录项。

连接器页的刷新按钮通过可取消的 `connectors.refresh` 串行重载目录与客户端。刷新期间阻止旧工具执行；完成后，相同版本及定义使用新连接，富内容结果由实际执行该调用的原生定义处理，变化的定义阻止对应会话继续执行，用户需新建对话。连接失败只影响相关能力，普通对话可继续；提示词记录故障。每个 Agent 直接持有运行时创建的原生 `createScope`；关闭 Agent 释放该作用域及其工具和监听器，不保留额外的会话插件。卸载取消并等待发现、刷新和 MCP 连接释放，移除会话注册，不会恢复为全量工具暴露。

工具选择的连接器 ID、版本和定义哈希记录在官方工具结果中，由 Session Projection 增量恢复；普通调用读取 `tool/result`，PTC 子调用读取原生 `tool/ptc-dispatch`，均只接受成功结果。实际定义和服务说明由官方请求日志记录。普通模式与 PTC 均可恢复，包括发现结果已提交、下一次请求尚未生成的中断；投影缓存版本变化时由原生投影服务重新计算。损坏或缺少选择记录仅阻止对应会话执行，直接工具调用同样检查恢复状态，原历史保留。传输凭据不写入提示词或工具选择记录。

Loader 配置 `connectorDiscovery` 可设置单次结果数 `maxResults`（默认 8）、单会话工具数 `maxLoadedTools`（默认 64）及完整结果字节数 `maxResultBytes`（默认 32768）。完整定义、输出包装和恢复元数据均受大小检查；超限时不注册部分结果，模型需缩小查询或新建对话。

搜索仅匹配工具原名和原生 MCP 说明，优先原名及较少见的业务词；连接器名称本身不会匹配整库。英文按完整词匹配并拆分驼峰名称，中文按相邻字片段匹配，统一大小写与全角字符。模型可在 `query` 之外提供最多 4 个 `queryVariants`，填写同一操作的同义词或中英文表达，每项最多 200 字符；各表达独立评分，合并去重后共用结果上限。查询和返回定义随官方会话日志记录，不额外调用模型或向量服务。这仍是词匹配，无法保证理解任意语义；模型应检查返回说明，未命中时换词搜索。

### 技能与专家中的精确引用

在原生 `SKILL.md` 或专家 Markdown 说明中，指定真实连接器 ID 和区分大小写的 MCP 工具原名，并要求模型先调用 `connector_search_tools`：

```json
{ "connectorId": "erp", "toolNames": ["orders_read_00", "orders_write"] }
```

示例名称需替换为实际目录中的值；搜索结果返回 `connectorId`、`toolName`、`version` 和可调用的 `name`。精确引用不按关键词匹配，也不接受生成的可调用名称代替工具原名；不能同时传 `query`、`queryVariants` 或 `limit`。全部引用通过实时访问、版本、声明及实际 MCP 定义检查后才统一加载，任意一项失败均不新增工具，不改用其他工具。工具原名缺失、未连接及版本变化分别报错；目录无法区分不存在与无权访问时统一报告不可用，网络故障保留原错误。

精确调用和关键词查询共用数量、字节、审批及恢复规则；每次最多 `maxResults` 个不重复原名。说明中写明引用只是给模型的操作指引，不会自动解析 Markdown、预加载工具或强制执行流程。引用确保已请求工具的解析准确，模型是否选择并正确调用仍需实际任务验收。

## 知识库与恢复

任务快照位于 `DSH_HOME/product-knowledge-tasks-v1`，固定知识库 ID 和官方派生定义；快照选择及 Host IPC 请求复用产品协议校验，拒绝非法 ID、重复快照选择和过时请求字段。能力快照通过原生字面量提示词段记录，标识中的花括号不解析为模板变量。模型只能传查询、数量或检索返回的来源 ID；检索及引用读取均检查实际返回的知识库 ID。权限由服务端实时校验，目录刷新不改变任务选择。

任务结果仅在用户明确要求时通过 `knowledge_destinations` 选择可写库，再由 `knowledge_save` 保存 Markdown 并请求原生审批。部门或公司目标须由用户明确指定；保存不改变任务检索范围，也不表示索引已就绪。

任务选择读取与准备沿用调用者的取消信号，通过原生 Session 查询中止历史读取；页面关闭或插件卸载后不返回迟到结果。准备操作已经提交的不可变快照保留供后续复用，取消不会删除已提交内容。

单个快照损坏或缺失只阻止对应任务执行，保留原始文件及诊断。启动扫描遇到单条历史不可读时记录该会话的诊断并继续恢复其他任务；已知的缺失快照仍注册阻止执行的组合。任务快照无法恢复时，可显式恢复为新任务，保留工作区、草稿及 Session 历史，不能静默换成普通任务。公司内容版本记录缺失或不可读时，仍可打开历史、切换会话及保留草稿；执行前重新校验固定版本文件，仅合并同时进行的校验请求，失败时明确阻止执行，不采用当前目录内容替代。

## 取消与释放

公司内容检查接收当前执行的取消信号；停止对话立即释放该调用者，最后一个调用者退出后取消原生 Session 历史观察及主进程检查，其他调用者继续使用共享请求。取消保留已提交的版本绑定，尚未提交的暂存文件随操作结束清理。技能和专家管理读取、刷新公司目录时沿用原生调用的取消信号，取消页面等待不会中断主进程供其他页面使用的共享同步。公司内容服务卸载会取消并等待目录读取、刷新及会话版本检查，迟到的成功结果不返回给已关闭的调用。插件释放先关闭 IPC 入口并取消远端请求，等待在途操作、MCP 连接及注册释放。

Office 预览在原文件或转换后暂存文件清理失败时停止返回文件，提示重启桌面端后重试；原操作与清理失败均保留为内部诊断，取消后的后台清理失败写入 Host 错误日志。回归入口见[桌面验收](../../../apps/product-desktop/docs/acceptance.md)。

## 公司模型

公司推理以独立 provider 接入，DeepSeek 复用官方适配器，其他模型通过原生 Settings 的路径编辑维护 `llm-pi-ai.providers.product-gateway`。原生 API-key provider、用户路由和有效默认选择（含 reasoning effort）继续保留；公司密钥只从启动进程环境读取，不写入配置。产品组合关闭原生账号入口，钉钉员工认证与模型凭据分别管理。

原生明确拒绝的 provider 或模型由原生默认模型服务保存为公司默认；首次启动尚未保存默认且原生 API-key 路由没有可用模型目录时，也使用公司默认。用户已保存的选择不会因暂时缺少凭据或网络失败而重置。同时创建任务共享当前修复，配置保存失败时阻止本次创建，后续请求允许重试。

## Model Experience

### Enterprise capabilities

#### What the model sees

模型初始看到连接器搜索入口和所选知识库的 `knowledge_search` 检索工具，搜索后仅增加匹配的原生 MCP 定义；查询、范围与结果通过官方 Session 记录。原生技能由官方 Skill Provider 按需加载。公司技能和专家说明按 Session 固定版本，子会话继承父会话；版本与哈希通过官方上下文快照记录到日志。

#### Token effect

已发现的工具定义、搜索结果、检索查询与返回内容占用上下文；未选择知识库不注册检索工具。

#### KV Cache effect

不管理模型缓存；工具及检索内容的变化由官方模型请求组装处理。

## Known Limitations and Deferred Work
<a id="known-limitations-and-deferred-work"></a>

- [300 工具回归](tests/erp-tool-discovery.md)使用模拟 ERP 与脚本模型，尚未验证真实模型的匹配准确率或响应延迟。
- 企业服务需要有效员工身份及可访问的组织服务；第三方专家和技能插件使用其自身的管理入口。
