# 企业运行时

## 概述

Cordis 插件仅接入企业连接器和任务知识库，沿用官方 Agent、Session、Preset、MCP 与审批。技能发现和说明加载由原生 Skill Provider 与 `skill` 工具负责，不注册自建技能、套件或创作工具。

## 连接器

普通 Agent 和子 Agent 创建时加载当前员工可用且已配置的连接器。公司目录默认全员可见，OAuth 只用于连接第三方账号。每次执行按 ID 查询并检查版本、账号状态和声明工具。READ 放行，WRITE 交由官方审批，未声明工具拒绝。单个 MCP 启动失败释放该连接，其他连接器与普通对话继续运行；模型提示词记录缺失连接器，禁止声称完成其业务操作。目录身份校验或目录解析失败仍阻止执行。凭据仅用于连接传输，不写入会话或提示词。

## 知识库与恢复

任务快照位于 `DSH_HOME/product-knowledge-tasks-v1`，固定知识库 ID 和官方派生定义。模型只能传查询、数量或检索返回的来源 ID；检索及引用读取均检查实际返回的知识库 ID。权限由服务端实时校验，目录刷新不改变任务选择。

单个快照损坏或缺失只阻止对应任务执行，保留原始文件及诊断。旧自建套件任务不再加载其运行时，也不能静默换成普通任务执行；用户可显式恢复为新任务，保留工作区和草稿。官方 Session 历史不删除。

插件释放先关闭 IPC 入口并取消远端请求，等待在途操作、MCP 连接及注册释放。真实 Loader 回归覆盖技能按需加载、连接器审批、范围限制、取消、卸载与重启恢复。

<a id="model-experience"></a>
## 模型体验

### 企业能力

#### 模型看到的内容

模型看到已授权 `MCP` 连接器的工具定义和所选知识库的检索工具；查询、范围与结果通过官方 Session 记录。原生技能由官方 Skill Provider 按需加载。

#### Token 影响

连接器工具定义、检索查询与返回内容占用上下文；未选择知识库不注册检索工具。

#### KV Cache 影响

不管理模型缓存；工具及检索内容的变化由官方模型请求组装处理。

## 已知限制与延期工作
<a id="known-limitations-and-deferred-work"></a>

- 企业服务需要有效员工身份及可访问的组织服务；第三方专家和技能插件使用其自身的管理入口。
