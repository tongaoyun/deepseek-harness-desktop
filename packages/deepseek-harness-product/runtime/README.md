# 企业运行时

## 概述

Cordis 插件仅接入企业连接器和任务知识库，沿用官方 Agent、Session、Preset、MCP 与审批。技能发现和说明加载由原生 Skill Provider 与 `skill` 工具负责，不注册自建技能、套件或创作工具。

## 连接器

产品插件在 Host 加载时查询当前员工可用且已配置的连接器，由官方 MCP 插件完成建连与工具发现；普通 Agent 和子 Agent 共用连接，新建或关闭单个对话不重新加载或释放连接。连接器页面的刷新按钮通过可取消的 `connectors.refresh` 重新加载目录和官方 MCP 客户端，失败后可再次刷新，无需重启；并发刷新串行处理，卸载取消并等待在途刷新。调用时的实时检查立即拒绝已撤销或已变更的配置。公司目录默认全员可见，OAuth 只用于连接第三方账号。每次执行按 ID 查询并检查版本、账号状态和声明工具。READ 放行，WRITE 交由官方审批，未声明工具拒绝。单个 MCP 启动失败释放该连接，其他连接器与普通对话继续运行；模型提示词记录缺失连接器，禁止声称完成其业务操作。目录身份校验或目录解析失败只使连接器工具不可用，普通对话仍可继续；提示词记录目录故障，禁止假装完成相关业务操作。凭据仅用于连接传输，不写入会话或提示词。

## 知识库与恢复

任务快照位于 `DSH_HOME/product-knowledge-tasks-v1`，固定知识库 ID 和官方派生定义。模型只能传查询、数量或检索返回的来源 ID；检索及引用读取均检查实际返回的知识库 ID。权限由服务端实时校验，目录刷新不改变任务选择。

单个快照损坏或缺失只阻止对应任务执行，保留原始文件及诊断。启动扫描遇到单条历史不可读时记录该会话的诊断并继续恢复其他任务；已知的缺失快照仍注册阻止执行的组合。旧自建套件任务不再加载其运行时，也不能静默换成普通任务执行；用户可显式恢复为新任务，保留工作区和草稿。官方 Session 历史不删除。公司内容版本记录缺失或不可读时，仍可打开历史、切换会话及保留草稿；执行前重新校验固定版本文件，仅合并同时进行的校验请求，失败时明确阻止执行，不采用当前目录内容替代。

公司内容检查接收当前执行的取消信号；停止对话立即释放该调用者，最后一个调用者退出后取消主进程检查，其他调用者继续使用共享请求。取消保留已提交的版本绑定，尚未提交的暂存文件随操作结束清理。插件释放先关闭 IPC 入口并取消远端请求，等待在途操作、MCP 连接及注册释放。真实 Loader 回归覆盖技能按需加载、连接器审批、范围限制、取消、卸载与重启恢复。

## 模型体验

### 企业能力

#### 模型看到的内容

模型看到已授权 `MCP` 连接器的工具定义和所选知识库的检索工具；查询、范围与结果通过官方 Session 记录。原生技能由官方 Skill Provider 按需加载。公司技能和专家说明按 Session 固定版本，子会话继承父会话；版本与哈希通过官方上下文快照记录到日志。

#### Token 影响

连接器工具定义、检索查询与返回内容占用上下文；未选择知识库不注册检索工具。

#### KV Cache 影响

不管理模型缓存；工具及检索内容的变化由官方模型请求组装处理。

## 已知限制与延期工作
<a id="known-limitations-and-deferred-work"></a>

- 企业服务需要有效员工身份及可访问的组织服务；第三方专家和技能插件使用其自身的管理入口。
