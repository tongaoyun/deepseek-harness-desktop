# 产品桌面

<a id="summary"></a>
## 概述

进入企业工作区前通过钉钉登录。短期访问令牌和 30 天长期登录凭据由 Electron 主进程使用操作系统加密存储，按服务地址隔离；凭据文件原子替换，不向渲染进程传递。重启后静默恢复登录，临时断网保留凭据。可信桌面扩展管理产品请求与资源。

## 组合与启动

`createExtension` 向官方壳提供启动准备、产品分发、事件和关闭钩子。产品组合负责 `desktop-extension.json`、`assembly.json`、品牌资源与产品配置。官方 profile 默认不加载产品扩展。参见[产品子系统](../../../docs/subsystems/deepseek-harness-product.md)。

扩展创建时读取并校验一次 `product.json`，服务地址、文件限制、MCP 代理期限、设备上报和公司目录刷新间隔在本次扩展生命周期内保持一致。开发环境可覆盖服务地址；打包应用使用资源内的地址。

产品通过原生桌面 profile 加载 Agent Team，并默认对新会话开启。用户通过原生会话开关控制协作，已保存的关闭状态在恢复会话时保持关闭。专家、技能模块及普通子代理工具由产品固定装配。

产品首次准备桌面 profile 时启用原生语音输入；macOS 同时启用 Computer Use，并将未另行选择模式的新会话默认设为 PTC。语音识别模型通过原生插件详情的“下载并准备”安装；Computer Use 的屏幕录制、辅助功能和应用授权沿用原生权限流程。Windows 不启用 macOS Computer Use。

AI 浏览器操作使用原生 Playwright MCP，以有窗口的独立 Chromium 浏览器运行，每个会话独立保存本次运行状态；首次使用缺少浏览器时，通过原生 `browser_install` 工具安装。初始化按原生 bundle、profile 和 home 层叠配置检测已有浏览器提供方，保留默认模式、浏览器参数与禁用设置。三个能力的选择和浏览器配置保存到原生 profile，后续可在原生插件管理中关闭或调整，重启与升级不重新覆盖用户选择。已有会话保留模式；使用 Computer Use 时选择 PTC。

同一扩展的并发 Host 准备请求共享一个操作；关闭会取消并等待准备、认证、目录同步与桥接的实际结束。重复关闭共享同一个清理结果，避免退出期间重复销毁资源或让迟到的启动结果继续写入配置。

企业登录、工作区配置和推理 overlay 准备完成前不启动 Host。启动授权和工作区内重新登录共用整窗登录布局；工作区内使用原生 Modal 保留会话节点、草稿和返回焦点，不导航或重载工作区。桌面壳将认证后环境和有序 overlay 交给原生 profile 启动器，加载产品运行时与内建专家、技能；员工令牌留在主进程。通用扩展传输与页面重载规则见 [Desktop](../../../apps/desktop/README.md#low-level-development-overrides)。

通过 `pnpm --dir apps/product-desktop run package <target>` 打包产品，未签名制品添加 `--unsigned`。该入口为官方构建流程选择产品组合。内部桌面 CI 与发布流程使用此入口；根目录的 `package:desktop:*` 命令打包不含产品资源的官方桌面。

产品打包直接将本包 `assembly.json` 交给官方桌面构建流程；产品扩展使用统一 JavaScript 构建，无独立 Rust 工具链。

桌面构建将 `electron` 保留为外部依赖，由正在运行的 Electron 进程提供主进程 API。


<a id="identity"></a>
## 身份与模型

产品使用企业员工登录，装配时停用原生账号推理、账号设置和账号通知；原生 API Key 与用户自配模型仍可使用。

员工切换时同步更新当前身份并使旧公司的同步、文件句柄、待上传选择和 MCP 连接失效，再等待各项清理；较早的同步收尾不能清理较晚员工的资源。Host 固定启动员工，身份变化取消在途产品请求、废止原代理凭证并关闭流连接。

同一员工重新登录后可刷新连接器，公司技能、专家与专家团在下次读取或执行时恢复；换成其他员工须重启桌面端。公司内容恢复共享一次初始化，等待旧同步清理完成，取消单个读取不影响其他读取；初始化失败可重试，已有任务仍使用固定版本。关闭同时等待这些身份清理完成。登录信息的凭据文件写入或删除失败仍等待清理，通过主进程日志报告；本地登录信息可能过时，需修复存储后重新登录。

并发登录调用共享一次授权尝试，浏览器授权期限为 5 分钟，调用方传输期限晚于授权期限。取消一个调用方只结束其等待；最后一个调用方取消时结束授权。关闭会取消并等待全部授权尝试，旧响应不能替换当前员工会话。

启动时钉钉登录或工作区配置请求遇到网络中断、超时、服务端暂时不可用时，显示中文重试或退出对话框。用户确认后重新认证并读取配置；成功前不启动 Host、不写入推理配置。登录超时允许重新授权，认证失效返回正常登录流程。网络失败保留本机数据及未被服务端撤销的登录记录；不使用旧推理配置或默认模型继续启动。格式错误仍作为启动错误报告。

主进程从 Electron 提供 `runtime.environment.desktopVersion`，Renderer 无法覆盖。Host 与 HTTP 请求将调用方取消与扩展生命周期信号组合。关闭时停止后台刷新，取消待处理操作并等待完成。单项清理失败仍按顺序释放其余资源、等待在途请求与授权结束，最后汇总报告错误。不含凭据的产品诊断保留错误码、资源 ID、可重试性和依赖结果。

企业启动先通过钉钉认证，再按服务端 Bootstrap 的精确模型 ID 追加公司模型。产品 profile 关闭原生账号设置与账号模型路由；原生欢迎页通过公司凭据元数据直接进入工作区，账号底层服务保留作桌面壳启动依赖。模型适配器、默认选择和凭据隔离见[产品运行时的公司模型](../runtime/README.md#公司模型)。已有 Session 的模型通过官方选择器管理。

<a id="connectors"></a>
## 连接器

`PersonalConnectors` 发现 MCP 工具，使用操作系统存储加密私密 Header 与环境变量，并通过 SDK 本地 HTTP 转发 stdio 的工具、服务说明及上游声明的资源能力。说明和资源由原生 MCP 客户端与资源工具消费。只有实际非破坏性只读注解允许 READ，其他已声明工具走官方审批，未声明工具拒绝。公开配置同步服务端，私密配置按员工隔离留在设备。服务端确认删除后，分别清理本机连接、加密配置及待恢复文件；任一失败仍执行其余清理，并报告已删除但本机清理未完成，不建议重复删除。切换账号与关闭会结束 SDK 连接和子进程。员工令牌只发送到产品服务端精确的托管 MCP 路径，已配置 OAuth 复用现有服务端提供方。

使用本机配置时，同一员工、连接器及版本共用一次 MCP 连接。握手期间，每个请求可独立取消等待；最后一个等待者取消后终止握手并等待资源释放。成功连接由桌面管理器保留，每个 stdio 连接仅保留一个 Host 的 SDK HTTP 会话；新初始化关闭旧会话，缺失或过期的会话不能执行业务调用。DELETE、单次取消或超时不关闭共享上游连接，SDK 取消通知继续传到原请求。

发布新版本、替换本机配置或删除连接器后，立即取消旧目录和该连接器的配置读取，再释放当前员工该连接器所有版本的缓存连接；迟到的读取不能重新启动旧进程，其他连接器的连接和业务调用保持运行。切换账号和关闭桌面释放全部连接；释放会主动取消握手和在途调用，并等待 HTTP 会话及上游子进程退出，不等待连接期限耗尽。关闭后不能再次读取目录或建立连接。

公开配置保留私密字段名及空值。本人在新设备上使用、或其他员工使用已共享的非托管连接器时，通过“配置本机连接”填写自己的值；该操作固定目录版本、端点、命令、参数和字段名，仅执行 MCP 工具发现并加密保存，不调用业务工具或创建服务端新版本。读取仅返回字段名与配置状态。禁用或不可用连接器不能配置和执行，凭据不跨员工复用。

新建、编辑、填写本机配置及读取加密配置均复用[产品私密字段校验](../product/README.md#authentication)，无效配置不能启动连接。

`ConnectorProxy` 将调用方断开连接和关闭应用的取消信号贯穿目录查询与转发。并发启动共享一次端口绑定；关闭等待在途绑定完成后释放监听器，再等待目录请求和 stdio 代理清理完成。取消后迟到的目录结果不能发起新的上游请求，关闭后的目录不能再返回代理地址。

主进程拥有的 `product.json` 通过 `connectorProxy.responseTimeoutMs`（默认 30,000，范围 1,000–300,000）和 `streamIdleTimeoutMs`（默认 120,000，范围 1,000–3,600,000）配置 HTTP 转发。两者分别限制响应头等待和每次无数据读取。活跃 SSE 没有总时长限制；SDK 的单次操作仍使用 `timeoutSeconds` 期限。

私有 MCP 转发地址包含连接器 ID 与固定版本；每次调用只读取该连接器，当前版本变化返回 409，转发前不调用新端点。托管服务端代理还校验主进程添加的 `X-Harness-Connector-Version`，拒绝检查后发生的配置更新。目录浏览仅读取本机配置状态，不建立 MCP 连接；任务执行按实际依赖发现工具并读取实时注解。

个人连接器保存按员工与资源串行执行。提交版本前，主进程原子保留加密的待确认配置。保存回执核对资源、版本、当前员工和状态，丢失或无效时通过已认证的不可变目录核对；重启或刷新目录仅在所有者、版本、公开元数据、连接目标和工具名称一致时恢复配置。恢复写入与同连接器的管理操作串行，排队期间沿用原目录、连接器与调用方取消信号，取得执行权后重读配置；已失效的恢复不能写入旧配置或关闭新连接。结果未知时保留待确认配置，需重试同一配置；明确拒绝时清理。关闭应用取消并等待保存完成。待确认记录和临时文件不会向渲染进程暴露凭据。

待确认与正式配置共用加密写入流程，先刷盘再原子替换；只在替换失败时清理暂存文件，清理失败同时保留原始写入原因。服务端已确认而正式配置写入失败时，保留待确认记录供恢复。

所有者修改时读取公开字段，本机私密键只返回空占位值。仅连接类型、地址、命令和参数均未改变时，留空才保留已有密钥；HTTP 字段名不区分大小写，环境变量名精确匹配。修改目标地址需要重新填写私密值。保存发现工具并创建新版本。

读取编辑信息、本机配置、创建、修改和删除按员工与连接器串行执行，权限和版本在前一操作结束后重新检查；详情与配置模板的资源 ID 必须匹配请求，错配时停止管理操作。删除后排队请求不能继续使用旧目录结果。取消的排队操作不发出请求，关闭时取消并等待全部管理操作结束。

删除使服务端全部版本退役，关闭当前员工该连接器各版本的缓存连接并移除当前版本的本机配置；其他连接器的连接和在途调用继续运行。删除仅接受服务端的显式确认；拒绝或回执未确认时保留连接和配置。提交审核须确认同员工、资源版本及待审核状态后才显示成功。修改失败保留原配置。

本机 MCP 配置将 `timeoutSeconds` 保存在加密设备配置中，范围 1–600 秒，默认 60 秒。连接、完整的分页工具发现和工具调用遵循该期限及调用方取消。工具发现使用 SDK 的完整列表和默认分页上限，主动刷新服务端注解，不采用尚未过期的旧发现结果；完整列表最多 512 项，超限拒绝保存。Host 接收无凭据超时配置并交给官方 MCP 客户端。创建连接器的通用桌面传输期限包含两次操作期限和服务端保存时间，Host 目录查询允许最大连接及发现期限。已配置 OAuth 保留默认超时。

<a id="library-files"></a>
## 资料库文件

跨库文件列表通过员工认证读取元数据，筛选、排序和分页在服务端完成。预览和添加附件完成读取后记录本人访问；下载和系统打开在准备好文件、交付原生操作前记录，取消选择不计为访问。主进程读取原文件时核对不可变 SHA-256、大小与当前权限，再以有界块交给 Renderer。原文件预览复用 Harness 预览 Factory，Word 和 PowerPoint 使用原生 Office 转换；下载和系统打开沿用原生文件选择与系统能力。

上传接受原生选择器或桌面文件路径桥登记的本地文件、文件夹，以及 Host 按原生 Session 事件读取的产物快照。文件夹连同根目录、子目录和空目录一起上传，保留相对层级；单次最多 16 层、100 个目录、1,000 个文件。重叠选择只登记一份；符号链接、空文件和超限选择整体拒绝，不登记部分内容。待上传文件总大小不超过 `uploadMaxBytes` 的两倍且不超过 100 MiB。对话来源仅由主进程核实的产物记录生成，Renderer 不能自行声明；来源会话标识仅向文件创建者返回。登记只返回句柄和相对目录，不回传绝对路径或字节；读取拒绝符号链接并核对文件身份、大小、修改时间和变更时间，选中后发生变化须重新选择。首次上传锁定字节摘要、目标和幂等键，重试复用回执；清理失败不把成功上传报告为失败。账号切换或退出释放选择，闲置选择按 `transferLifetimeMs` 回收。

`product.json` 的 `libraryFiles` 配置文件限制：预览 32 MiB、表格 16 MiB、Office 输入 50 MiB、转换输出 100 MiB、下载 250 MiB、上传 50 MiB，临时传输有效 15 分钟，请求期限 5 分钟，最多 8 个并行传输。上传还受服务端实时限制。

<a id="company-content"></a>
## 公司内容

产品 profile 默认装配原生 Agent Team 服务、工具和团队面板，保留普通子代理工具；固定装配内建专家和技能，页面合入产品 UI，代码随桌面更新；官方 profile 不加载。个人专家配置使用官方 Settings，本机技能使用原生文件。同步与发布见[公司内容说明](../../../apps/product-desktop/docs/company-content.md)。

公司内容由 `CompanyContentSync` 在主进程合并与节流请求；启动和页面打开先显示本地目录，后台校验更新。每位员工的目录指针、不可变文件及 Session 版本绑定独立保存，个人团队的公司专家按标识和摘要从独立资源缓存读取，缺失时通过已认证的精确版本接口下载；读取不切换目录指针或 Session 绑定。关闭时取消并等待启动缓存读取、后台刷新、精确版本读取和任务绑定，结束后不再启动刷新。

每次任务绑定、恢复和执行检查都会重新读取公司内容文件并核对固定哈希。缓存缺失、内容变动或非法路径返回 `COMPANY_CONTENT_CACHE_INVALID`，保留原文件和版本记录，拒绝新建绑定及继续执行；其他完好版本仍可使用。同一 Session 的绑定写入串行，其他 Session 独立恢复；校验结果不缓存，不以最新版本替换固定内容。

<a id="device-and-feedback"></a>
## 设备与反馈

`DesktopSupport` 在员工认证后上报主进程采集的 Electron 应用版本、平台、架构、显示缩放及操作系统凭据加密状态。设备标识复用 Harness 原生 `getOrCreateAnonymousUserId`，将当前 `$DSH_HOME`（默认 `~/.dsh`）的匿名 UUID 哈希为公司上报用 UUIDv8；原始匿名 ID 不发送到服务端或页面。同一 home 跨重启共用设备，切换或重置 home 创建新设备。匿名 ID 持久化沿用原生尽力写入语义；home 不可写时仅保证本次进程稳定。打包的 `product.json` 必须提供 `support.heartbeatIntervalMs`（60,000–3,600,000）及 `support.reportIntervalMs`（不小于心跳间隔，不超过 86,400,000）。完整能力上报之间发送在线心跳，元信息变更触发完整上报。失败保留可见的异常状态，在窗口聚焦或下一周期重试，不阻塞对话；恢复成功清除失败码，保留最近完整上报时间。账号切换取消请求并重置员工状态；关闭时取消并等待在途操作。

产品设置入口提供员工主动反馈，包含正文、分类及最多四张主动选择的 PNG/JPEG/WebP 截图，每张不超过 5 MiB。主进程校验内容、补充真实版本和设备 ID，并使用员工范围内的 UUID 幂等键提交；渲染进程仅收到非空回执 ID。失败、取消或回执无效时保留草稿及重试键，修改内容生成新键。设备上报和反馈不收集对话历史、本地路径、员工令牌或运行 Bootstrap 密钥。产品不提供桌面执行审计 API。

<a id="model-experience"></a>
## 模型体验

### 产品桌面

#### 模型看到的内容

主进程通过 `prepareHost` 向 Host 提供推理配置。本地 MCP 代理将上游凭据替换为私有代理凭证，并逐请求检查连接器可用性。员工令牌留在主进程，Renderer 不接收员工令牌或运行时 Bootstrap 机密。

#### Token 影响

认证和原生操作不增加模型 Token。

#### KV Cache 影响
