# 专家套件

## Summary

随产品桌面固定装配，产品 UI 在左侧“扩展能力”直接挂载页面，不另行安装功能插件，不提供设置重复页或独立更新。个人专家和专家团由官方 Settings 保存；单个专家通过当前官方 Subagent `startActivation` 委派，在子 Agent 创建时注册专家说明与工具限制；专家团在原生 Agent Team 就绪且没有深度限制时使用团队服务，否则使用普通子代理。不保留旧 `start` 或旧能力标志的适配。页面统一为“市场／我的”：市场展示审核发布的公司专家和专家团；创建入口只在“我的”，支持创建、导入、修改、删除与提交发布。审核通过后进入市场供全公司使用，内容由服务端同步。

分类按跨境 ERP 的业务流程、产品研发与企业协作组织。目录筛选、创建编辑、专家团选人共用固定顺序，空分类仍可选择；已发布内容的自定义分类继续按实际目录展示。分类只组织专家目录，不改变专家身份或执行方式。完整分类及发布目录示例见[公司内容说明](../../../apps/product-desktop/docs/company-content.md)。

首次读取时保留筛选栏，列表使用原生加载指示；当前来源的统计未读到时显示“—”，读取失败不显示空目录。专家团目录和详情显示默认执行方式，展开可查看选择原因；执行前仍按当前会话重新检查，实际方式记录在召唤结果中。

## 装配与维护

Host 模块通过产品 profile 固定装配，普通 ESM 客户端模块合入产品 UI 的浏览器产物；不声明独立安装包。根目录 `pnpm run build:artifacts` 完成构建，本目录 `tsconfig.json` 检查源码。官方 profile 不加载产品模块。

代码按当前产品版本维护，许可证见 [LICENSE](LICENSE)。团队内容的格式和发布入口见[公司内容说明](../../../apps/product-desktop/docs/company-content.md)。

专家管理使用原生 Remote/Typert 生成契约，不要求独立 HTTP 服务，Settings 保存个人内容；编辑冲突通过类型化错误返回。目录缓存和弹窗状态由挂载实例管理，关闭或卸载时释放订阅；菜单和对话框的焦点、Escape 行为由原生 UI 组件负责。专家配置使用原生 YAML 解析规则。目录、专家编辑、说明读取及公司内容刷新沿用原生 Remote 取消信号；切换市场或我的、切换专家或专家团、重置连接及卸载页面时取消详情读取，迟到结果不能重新打开弹窗。提交发布使用相同的读取取消信号和原生字节编码工具。关闭页面释放等待，不中断主进程中供其他页面使用的共享同步，迟到的目录不发布为当前结果。

`@` 菜单与工具栏直接读取同一目录快照，通过原生快照订阅更新，不另存已启用名册、专家团列表或通知集合。保存确认前的页面选择不改变 `@` 名册；新增或移除公司分类后同步更新原生输入来源，无需重启或切换语言。选择专家团时重新核对当前快照中的启用状态，已停用或移除的旧候选不能插入；复制名称使用最新已确认的团队名称。

团队查询、保存、启停、删除及草案编辑准备返回统一的完整团队快照，包含当前原生成员映射和可用的执行方式；客户端直接接受回执，不以旧缓存补齐执行元数据。团队提交发布将原生取消信号传到公司目录、团队目录及成员说明读取，取消后不返回迟到的发布内容。打开已确认草案时，离开操作入口会取消编辑准备；Host 在领取草案前检查取消，尚未领取的草案仍可重试。已打开的编辑表单按原有方式保留待保存内容。

模型可见的专家说明、工具文案及新委派名称遵循设置中的语言。明确选择 `zh` 或 `zh-*` 使用中文，未选择或无法读取时采用 Harness 默认英文；历史会话中已记录的名称和内容不重新翻译。

## Model Experience

### Native capabilities

#### What the model sees

模型通过 `list_experts` 浏览专家名册并通过 `summon_expert` 使用选定说明；个人内容和团队内容按当前版本读取。公司内容按 Session 固定版本，输入记录沿用原生日志。

#### Token effect

名册、委派参数和说明按需占用上下文。页面整合不新增模型输入。

#### KV Cache effect

不管理模型缓存；内容变化由官方请求组装处理。
