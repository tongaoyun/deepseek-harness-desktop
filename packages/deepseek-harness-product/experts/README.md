# 专家套件

## 概述

随产品桌面固定装配，产品 UI 在左侧“扩展能力”直接挂载页面，不另行安装功能插件，不提供设置重复页或独立更新。个人专家和专家团由官方 Settings 保存；单个专家通过当前官方 Subagent `startActivation` 委派，在子 Agent 创建时注册专家说明与工具限制；专家团在原生 Agent Team 就绪且没有深度限制时使用团队服务，否则使用普通子代理。不保留旧 `start` 或旧能力标志的适配。页面统一为“市场／我的”：市场展示审核发布的公司专家和专家团；创建入口只在“我的”，支持创建、导入、修改、删除与提交发布。审核通过后进入市场供全公司使用，内容由服务端同步。

分类按跨境 ERP 的业务流程、产品研发与企业协作组织。目录筛选、创建编辑、专家团选人共用固定顺序，空分类仍可选择；已发布内容的自定义分类继续按实际目录展示，中英文标签只匹配固定分类名，其他分类保留原名。分类只组织专家目录，不改变专家身份或执行方式。完整分类及发布目录示例见[公司内容说明](../../../apps/product-desktop/docs/company-content.md)。

首次读取时保留筛选栏，列表使用原生加载指示；当前来源的统计未读到时显示“—”，读取失败不显示空目录。专家团目录和详情显示默认执行方式，展开可查看选择原因；执行前仍按当前会话重新检查，实际方式记录在召唤结果中。

## 装配与维护

Host 模块通过产品 profile 固定装配，普通 ESM 客户端模块合入产品 UI 的浏览器产物；不声明独立安装包。根目录 `pnpm run build:artifacts` 完成构建，构建准备阶段使用本目录 `tsconfig.json` 强制检查源码和测试。官方 profile 不加载产品模块。界面直接使用原生 UI 组件及其 TypeScript 声明，不维护替代类型。按钮、单行输入和弹窗沿用当前原生属性（`variant`、`size`、`icon`、`onClose`）；产品仅增加主题、危险态和忙碌态。Agent Team 作为可选原生服务装配，消费接口直接从当前 `TeamService` 提取，使用原生 Agent、任务 ID 和成员状态，不另写宿主接口或探测旧方法。弹窗的 Esc 层级、输入法组合保护、Tab 焦点限制及关闭后焦点恢复由原生 Modal 管理；指定初始焦点使用其自动聚焦标记，不另建全局键盘栈。设置页策略直接调用原生 `Settings.configure`，由当前插件生命周期释放；个人专家与专家团共用同一设置存取及修订号检查。公开客户端入口仅提供插件装配；内部组件与辅助函数由包内测试直接引用，浏览器安全数据类型通过 `./types` 入口提供。

宿主语言只从当前原生 Settings 的配置投影读取，沿用官方 locale 命名空间；工具说明使用缓存快照，在语言配置变更或 locale 激活后刷新，不探测旧版 `get()`。

本地专家 Markdown 的元数据与正文共用原生文档 YAML 解析入口，支持多行标量、转义引号和注释；名称与简介必须是文本，重复键或无效 YAML 不进入名册。目录扫描只按分块读取有上限的文件头，正文仍按需读取。挂载后的客户端直接使用 Typert 生成的完整 Remote 类型，不探测旧版本方法；仅供专家视图使用的窄接口保留其实际所需方法。

原始来源摘要见 [upstream.json](upstream.json)，保留 [Apache-2.0 许可](LICENSE)。代码由本仓库维护，社区更新选择性合入，不整包替换。团队内容的格式和发布入口见[公司内容说明](../../../apps/product-desktop/docs/company-content.md)。

模型可见的专家说明、工具文案及新委派名称遵循设置中的语言。明确选择 `zh` 或 `zh-*` 使用中文，未选择或无法读取时采用 Harness 默认英文；历史会话中已记录的名称和内容不重新翻译。

「我的」支持通过对话创建专家或专家团：入口将自然语言前缀追加到当前对话草稿，不覆盖正文、附件或引用。模型生成完整预览，可继续修改；确认后通过原生询问卡片核对，再点击对话内「核对并保存草案」打开已填好的个人编辑器，最终点击保存才持久化。不会自动发布公司内容，保存后仍使用现有提交审核入口。

专家输入使用原生 Session 服务的类型、主视图保留信息及 `scope` 定位输入机，不另行维护会话或 Conversation 兼容接口。示例填入沿用原生草稿修订号：引用提交后若用户已清空或继续编辑草稿，旧示例不能写入新草稿；因草稿变化中止团队追加时，保留新正文并提示追加失败。

草案严格归属原始主会话，修改后旧提案失效，按单调时钟计时 15 分钟后过期，不受系统日期跳变影响，每个提案只允许一个编辑窗口领取；历史回放不会自动打开弹窗。专家团支持中文名、英文名、完整或简短标识匹配，重名或简称有歧义时列出候选并要求澄清。停用专家可用于设计团队，启用团队时仍由原有表单确认所需成员。

专家列表支持按来源、分类、状态及关键词筛选后批量启停；确认层展示人数，只修改已确认目标的个人启用状态。提交时重读最新名册和启用状态，跳过已删除或冲突项，保留其他专家的并发变更；修订号冲突时显示错误并等待重试。

<a id="dev-note"></a>
### 开发备注

源码从固定社区版本移入产品包，已有断言按原始语法指纹移入仓库检查基线，禁止增加新断言。原社区实现保留原 lint 范围，由独立严格类型检查（拒绝未使用的变量和参数）及行为测试验证；新增装配、配置读取和提交出口仍执行仓库 lint。个人配置身份、本机技能文件与官方 Session 存储保持稳定，不读取历史插件设置备份。

个人专家与专家团的修订号冲突使用原生 RemoteError 的 `experts/conflict` 错误码，界面据此要求核对最新内容；设置事务中的并发冲突也保留同一语义，不靠报错文案识别。读取、编辑和批量操作保留原生错误码与详情，核对本身不自动保存或覆盖草稿。

专家的 Remote 方法、参数顺序及客户端类型从实际 Host 服务由原生 Typert 生成器生成，构建时检查产物是否过期；不再手写第二套方法描述、宿主类型或装饰器降级器。UUID、长度、默认值、转换及严格对象校验仍由产品 schema 定义，并通过原生 Remote 工厂应用到 Host 和 Client 的同一契约。

专家名册和专家团快照由每次插件挂载独立持有，订阅与异常隔离复用原生 snapshot store。目录与专家团读取通过原生 Remote 传递插件生命周期取消信号，连接重置或卸载及时结束等待；共享的公司同步不随单个读取取消。连接重置清空旧宿主状态并重新读取，保留已打开的编辑草稿；旧读取回执不能覆盖新保存，卸载后迟到回执不能再发布。专家团列表和选择菜单以该 store 的订阅为唯一显示来源，不再次把查询或旧保存回执写入界面快照。保存回执省略的宿主执行方式统一由数据持有者保留，下次完整读取可更新或清除；各编辑入口不再分别补写。切换插件数据实例或卸载后，旧操作不再发布提示、调用保存成功回调或关闭新菜单；已完成的宿主写入和草稿追加不自动撤销。并发公司刷新合并为一次，前序本地读取失败仍执行显式刷新。原生成员显示名随专家目录、专家团快照和语言刷新；宿主复用名称文本节点时按当前标识重新映射，卸载后不再发起名称读取。

## 模型体验

### 原生能力

#### 模型看到的内容

创建流程新增 `list_creation_experts`、两项提案工具及两项编辑确认工具。完整草案通过工具结果进入会话记录；打开编辑器不代表保存。设计名册最多返回 80 位匹配专家并标记截断，可通过关键词继续缩小范围。模型通过 `list_experts` 浏览专家名册并通过 `summon_expert` 使用选定说明；个人内容和团队内容按当前版本读取。公司内容按 Session 固定版本，输入记录沿用原生日志。

#### Token 影响

新增五项工具的 schema 占用请求上下文；名册查询、完整草案预览、确认结果、委派参数和专家说明按需进入上下文。列表筛选和批量启停不向模型发送新输入。

#### KV Cache 影响

不管理模型缓存；内容变化由官方请求组装处理。

## 已知限制与延期工作
<a id="known-limitations-and-deferred-work"></a>

- 仅随产品桌面装配和更新，不作为社区插件独立发布。
- 草案暂存在 Host 内存中，重启、过期或领取后取消编辑都需要重新生成；保存失败时可在当前编辑窗口重试。
- 实时推荐、新增第三方技能来源和 Antigravity 导入尚未接入。
