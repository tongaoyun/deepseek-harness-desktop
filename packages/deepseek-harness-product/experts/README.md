# 专家套件

<a id="summary"></a>
## 概述

在“我的”通过 AI 创建、导入和管理个人 AgentSpec 包与专家团，在“市场”使用公司审核内容。委派复用原生 Subagent 与 Agent Team。格式、发布与同步说明见[公司内容](../../../apps/product-desktop/docs/company-content.md)。

## 内容与存储

专家保留 AgentSpec manifest、SOUL.md、可选 AGENTS.md、参考资料及二进制模板。导入以包根目录的 manifest 为入口，嵌套的同名模板文件作为资源保留；不接受多个并列专家包，ZIP 解压未返回全部文件时拒绝导入。导入、编辑和导出区分未提供与空的 AGENTS.md；未修改的文件保留原始内容和摘要。说明作为字面量提示词交给原生 Subagent，并提供固定资源目录；不执行包内安装声明。个人文件按员工和摘要隔离，先写不可变版本，再通过官方 Settings 修订号原子切换引用。Settings 保存展示信息、启用状态和版本化 Team 文档。

个人包每次读取均核对目标版本的完整目录与文件摘要，拒绝未登记文件或目录、符号链接和重复索引；校验失败保留原文件并阻止该版本导出及执行。团队固定的完好版本不受其他版本文件损坏影响。

版本目录通过原子重命名安装，成功后不再清理已移走的暂存路径；同内容并发保存校验已有完整版本后合并。安装失败会清理暂存目录，清理也失败时保留两项错误，Settings 引用不切换。

公司内容由主进程校验索引与文件后安装，模块每次读取时解析公司内容服务，消费对应的固定版本目录。专家团定义与成员目录在同次操作中使用同一公司版本。新会话固定资源摘要，子会话继承。团队成员引用精确专家版本，更新专家不替换既有团队成员。个人团队按成员摘要读取独立的公司专家包，缺少本地版本时按员工权限下载同一版本；缓存损坏时阻止执行。失效引用须重新选择。

个人团队只能选择独立专家。公司团队内部的固定成员仅供所属团队使用，不进入个人团队候选；个人团队保存、启用、导出和执行时也会校验成员。选人列表只渲染可见行与当前焦点项，按专家标识保留按钮；目录更新或视口变化后校正滚动位置，剩余候选仍可选择。当前聚焦候选被移除或不再符合筛选时，焦点返回选人搜索框，不滚动或抢占其他控件，保留查询、文本选择及团队草稿。

成员固定版本缺失或需要重新选择时，目录卡片提示编辑并保存，启用和加入草稿均拒绝操作；仍可停用、编辑或删除团队。保存会固定当前成员版本，完整的旧版本引用可继续使用，不因专家更新自动升级。

专家导出固定本次目录快照及其文件来源：公司包使用同一不可变目录，个人包按摘要读取，显式配置的本地包从其目录读取。同步更新不混用展示信息和另一版本的文件。包文件及个人索引使用[受限文件读取](../product/README.md#company-content)，取消或检测到大小变化时停止，不返回部分包；原内容保留，可在编辑完成后重试。

## API 与界面

页面标题和说明遵循[统一资源页规范](../../extensions/ui-deepseek-harness-product/DESIGN.md#页面标题)，专家与专家团共用[统一状态容器与启停反馈](../../extensions/ui-deepseek-harness-product/DESIGN.md#状态与权限)。

创建专家和专家团通过原生新会话描述需求，由 AI 生成完整内容，经原生工具审批后直接保存并启用个人内容。专家可包含说明和文本资料，团队从已有专家中选择成员并固定版本。已有内容可编辑，导入需选择 AgentSpec 目录或 ZIP；公司发布单独提交审核。

市场、我的、编辑器及专家团选人使用[共用业务分类](../product/README.md#catalogs-and-tasks)，AI 创建使用相同预设。市场或我的专家、专家团清除筛选后，焦点返回当前搜索框。专家与专家团页签随文字增高，窄窗口将名称、总数与启用统计分行显示，选中框覆盖完整页签。导入包的分类仅在展示和筛选时映射，未修改分类时保存原始元数据。

管理操作使用原生 Remote/Typert 生成契约，目录与团队通过原生订阅共享快照。目录刷新按专家标识保留卡片、头像与键盘焦点；滚出视口但仍持有焦点的卡片也保留，不因前面的条目移除而重建。目录读取重试保留错误、入口和搜索选择，等待期间标记忙碌并阻止重复提交；成功移除入口时，仅将其持有的焦点交还搜索框，详情内交还团队标题，不滚动或抢占其他控件。读取失败显示错误，不伪装为空目录；关闭页面、切换来源或断开连接取消在途读取。目录重置或卸载也取消在途写入，旧回执不能覆盖新目录、继续插入聊天草稿或显示旧错误。取消不能撤回已提交的 Settings 事务；被取消的保存保留编辑稿并恢复操作。

专家启停、删除及批量操作的冲突、选择失败和保存或删除完成提示随界面语言更新；保留搜索、筛选和在途请求，不重复读取、写入或插入引用。写入期间保留冲突操作的外观并锁定重复写入，专家及专家团的 AI 创建入口保持可用。专家和专家团启停结束后恢复因临时禁用丢失的开关焦点；卡片被筛选移除、删除成功或关闭预览与编辑器后，失去目标的焦点回到当前搜索框，不抢占其他控件的焦点或改动草稿与文本选择。提示词预览复用原生弹窗记录打开时的焦点，不用延迟聚焦覆盖等待读取期间主动选择的位置。删除及批量启停确认在请求发起时保护关闭，重试保留错误，接受权威回执后清除。

专家和专家团未保存的说明、标签和附件在关闭编辑器前需要确认放弃；取消放弃保留原字段和文本选区，刷新窗口时保护未保存内容和在途保存。增删团队任务示例保留其余输入框及文本选择。保存及删除确认等待期间保留操作按钮、键盘焦点和外观，阻止重复提交与关闭；团队表单内临时锁定的按钮也保留外观，数量上限及顺序限制仍显示禁用。保存重试及读取最新配置保留错误提示；复核读取期间保留原按钮与键盘焦点，重复触发只读取一次。冲突核对后以最新内容为比较基线，保留草稿仍须保存实际差异；团队标签按将要保存的内容比较，附件条目顺序不影响判断。恢复当前基线内容或关闭编辑器后解除刷新保护。

专家编辑器保存、导入或读取附件时，分类选择保留当前名称和外观并关闭已展开菜单；操作完成后需重新打开，不自动恢复菜单或更改分类。实际不可用的选项保留禁用样式。

复制市场专家或专家团时，名称保留副本后缀，按完整字符截短到编辑器上限；已有同名内容时追加序号，比较时忽略首尾空格和字母大小写。团队副本使用成员的正式专家标识，保存时固定当前可用版本；成员失效或名称冲突时须手动替换。副本独立保存，原内容及其固定版本不变。

专家团替换和示例追加的确认弹窗在连接重置或插件卸载时取消并关闭；写入引用和追加正文前核对原聊天输入仍为当前目标，取消或目标变化后不写入草稿。确认追加后，在选择完成前写入示例，保留正文、引用和附件；追加失败保留已选择的团队并显示提示。

专家编辑器的字段、包格式和冲突提示按当前界面语言显示；切换语言保留草稿，不重发请求。损坏的 ZIP、manifest JSON 或 UTF-8 内容使用包格式错误提示；ZIP 和目录导入均限制为 2048 个文件、32 MiB。

Host 和 Client 共用 AgentSpec 文本校验：专家说明、工作规则与 manifest 每份最多 128 KiB，按 UTF-8 字节计算，拒绝空字符；专家说明不能为空。保存、导出和添加附件在编码前校验说明，失败保留草稿与原有资源，缩短内容后可继续操作。参考资料和二进制模板仍按完整包大小限制，不受说明文件上限影响。

专家团复用原生具名子代理、消息和任务板。成员显示名称通过原生 `label` 提供，路由标识限制在 32 字符内；同团空闲且可恢复的成员复用，运行中或同名外部成员拒绝重复派发，一次性子代理不参与复用。会话开启 Agent Team 时使用原生协作，关闭时使用普通子代理；两种方式均保留深度限制。

编辑器支持目录／ZIP 导入、完整 ZIP 导出、说明和附件编辑。导入、附件读取和保存分别报告忙碌状态；文件读取及失败重试保留入口按钮焦点，等待时不能再次打开文件选择；保存与保存并启用仅提交按钮显示进度，其余按钮保留名称与外观并临时锁定。导入和添加附件先检查整批文件大小及可移植路径，文件名规则见[公司内容](../product/README.md#company-content)；取消后，当前文件读取完成即停止，不再读取后续文件或解压 ZIP。ZIP 显式目录与文件的隐式父目录共用路径检查，拒绝非法目录名、重复条目、大小写别名和文件／目录冲突；仅导入文件。附件选择拒绝同批重名、大小写别名和文件／目录冲突，路径长度包含包目录；校验失败保留草稿。单文件替换按完整包的实际文件数与字节数校验。

新建或导入不能覆盖已有同标识专家，更新须显式编辑。保存前检查标识及中英文名称冲突，拒绝时不写入包文件；写入后仍核对 Settings 修订号，防止并发覆盖。导入后的简介最多展示 160 字符，未修改时保留完整原始 manifest。分类只影响展示，不改变包标识。并发冲突保留草稿，要求读取最新内容后确认。专家与专家团重新复核时保留对照内容和按钮，锁定内容采用、保存及重复读取；成功后原位更新对照，失败或取消清除旧结果，重新读取成功后才可继续保存。焦点在对照区时，读取失败或取消返回读取按钮，确认采用内容后返回名称字段；焦点已移到其他编辑区域时保持原位。

专家和专家团编辑器的错误显示在固定操作区；编辑、复制及查看专家说明的读取重试保留错误，成功打开内容后清除。使用结构模板时，仅将模板按钮持有的焦点交给专家说明，保留其他字段的焦点和选区。选中新增或替换的成员后进入对应职责摘要，取消选择返回原入口。成员排序保留当前移动按钮的焦点、分工草稿及展开状态；到达首尾后按钮保留焦点并显示禁用状态，重复操作不能越界，也不保存团队。选择头像后焦点返回入口；移除附件或成员后转到下一项、上一项或添加入口，移除示例后转到相邻输入框，新增示例后进入新输入框。ZIP 导出按导入上限重新核对当前完整文件，超限时不生成下载。导出失败保留草稿和编辑操作，重试成功清除错误。专家团的校验、目录、保存和冲突复核提示随界面语言更新，不重复请求或丢弃草稿。保存与删除接受权威回执，不用后续读取失败重复写入。团队启停和删除不依赖聊天输入；召唤时无法取得输入目标会显示错误。

专家团菜单与详情页在选择、启停或删除期间只接受一次操作，临时禁用保留按钮外观，仅当前团队和所选示例标记忙碌。详情在召唤、选择示例及失败重试时保留操作按钮与焦点；示例按正文标识，相同示例只展示一次；后台更新移除聚焦示例时，焦点返回详情标题，保留搜索、提示词展开状态和选区，不滚动或抢占其他控件。管理页正在查看的团队被移除时，详情关闭，失去目标的焦点返回当前搜索框；其他区域的焦点和草稿保持原位。目录更新后选择当前团队内容。操作期间保护详情与确认框关闭；失败在当前弹窗显示，重试保留错误至成功。目录恢复提供原位刷新入口，等待时保留按钮焦点与外观，连续触发共用一次读取，团队及成员目录全部确认后结束等待；首次读取失败及重试期间只保留错误与刷新入口，不同时显示加载占位。启用确认等待服务端回执，启用已提交而草稿插入失败时，只重试插入。页面切换后，旧操作不能关闭新菜单或解除新操作的忙碌状态。

对话中的专家选择浮层挂载到页面根节点，使用 CSS Anchor 定位并保留视口边距；调整窗口、滚动或内容变化时跟随触发按钮，避免被输入框裁切。浮层与原生 Modal 使用相同层级，后打开的详情和确认遮住底层菜单；关闭后恢复原入口焦点和搜索状态。后台更新按专家标识保留选择按钮与头像，分类变化不重建条目；专家或专家团条目被删除、停用后退出当前结果时，其持有的焦点返回搜索，保留查询和文本选区，不抢占其他控件。专家与专家团目录的刷新使用原生按钮，重试保留错误、按钮和键盘焦点，不插入加载占位；团队列表独立滚动，页签与搜索框保持可见。刷新成功移除错误区时，仅将刷新按钮持有的焦点交还搜索框，不滚动页面或抢走其他控件的焦点。选择期间保留原列表按钮的焦点和外观，通过无障碍状态报告暂不可用，连续触发只处理一次；专家选择重试保留原错误至结果确认，失效专家仍显示禁用。连续刷新共用一次读取，成功后清除错误；关闭或重新打开菜单后，旧回包不改变当前菜单状态。目录读取结束不解除仍在进行的专家选择操作。

## 执行

单专家使用原生 Subagent `startActivation`。产品默认加载原生 Agent Team 服务、工具和面板，同时保留普通子代理。团队按当前会话能力选择原生 Agent Team 或普通子代理，实际选择记录在召唤结果中；原生服务未挂载时仍可浏览专家团，模块探测使用 Node 解析器，不依赖插件宿主提供 `import.meta.resolve`。主会话负责汇总。委派开始即固定本次团队配置，执行期间编辑团队不改变本次任务板标题、队友标识或成员说明。团队成员不能自行扩大团队，原生 `tools.guard` 在执行前拦截委派工具。单专家仍受宿主深度、权限和原生审批约束。

专家说明可以指导模型使用技能、MCP 与知识库，不新增资源绑定或权限引擎。知识库继续受员工授权和任务范围限制。

<a id="model-experience"></a>
## 模型体验

### 专家委派

#### 模型看到的内容

模型通过原生 `list_experts`、`summon_expert` 查看专家目录并召唤专家。子代理接收字面量 `SOUL.md`、可选 `AGENTS.md` 和固定版本的资源根目录，按需使用原生文件工具读取资料；技能由原生 Skill Provider 加载。

#### Token 影响

目录摘要、选中的专家说明、委派任务和实际读取的资料进入上下文；附件不会全量注入。

#### KV Cache 影响

不单独管理模型缓存；请求与上下文组装沿用原生实现。

## 已知限制与延期工作
<a id="known-limitations-and-deferred-work"></a>

- 公司团队只能引用已发布的公司专家。
- AgentSpec 只分发内容，不启动 Worker，也不执行安装声明或定时任务。
- 说明中的工具使用要求由模型理解，权限和写入审批由原生宿主执行。
