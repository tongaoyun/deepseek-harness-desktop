# 专家套件

## Summary

在“市场”使用公司审核的专家和专家团，在“我的”创建、导入、修改或提交个人内容。单个专家使用原生子代理；专家团按能力和深度限制选择原生 Agent Team 或普通子代理。模块随桌面统一更新，个人配置由官方 Settings 保存。

<a id="catalogs"></a>
## 目录与选择

分类按跨境 ERP 的业务流程、产品研发与企业协作组织。目录筛选、创建编辑、专家团选人共用固定顺序，空分类仍可选择；已发布内容的自定义分类继续按实际目录展示。分类菜单在控件禁用时关闭，恢复启用后需重新打开。分类只组织专家目录，不改变专家身份或执行方式。完整分类及发布目录示例见[公司内容说明](../../../apps/product-desktop/docs/company-content.md)。

首次读取时保留筛选栏，列表使用原生加载指示；顶部统计通过原生 Slot 订阅读取已确认的目录，不另存计数或等待子页面回传，切换市场或我的时直接计算当前来源。统计未读到时显示“—”，读取失败不显示空目录。专家团目录和详情显示默认执行方式，展开可查看选择原因；执行前仍按当前会话重新检查，实际方式记录在召唤结果中。

<a id="assembly"></a>
## 装配与维护

Host 模块通过产品 profile 固定装配，普通 ESM 客户端模块合入产品 UI 的浏览器产物；不声明独立安装包。Tabler 图标作为开发依赖编入客户端产物，Host 不需要安装图标库；完整 MIT 许可随 `NOTICE` 分发。根目录 `pnpm run build:artifacts` 完成构建，本目录 `tsconfig.json` 检查源码。官方 profile 不加载产品模块。

代码按当前产品版本维护，许可证见 [LICENSE](LICENSE)。团队内容的格式和发布入口见[公司内容说明](../../../apps/product-desktop/docs/company-content.md)。

<a id="cancellation"></a>
## 读取与取消

专家管理使用原生 Remote/Typert 生成契约，Settings 保存个人内容，编辑冲突通过类型化错误返回。单个专家通过原生 Subagent `startActivation` 委派，在子 Agent 创建时注册说明与工具限制。

目录缓存和弹窗状态由挂载实例管理，关闭或卸载时释放订阅；菜单使用原生图标，快捷选择器、菜单和对话框的键盘层级及焦点由原生 UI 组件负责：输入法候选与组合结束的 Escape 不关闭选择器，嵌套详情只关闭最上层，Tab 留在当前弹窗，关闭后恢复原焦点；切换专家或专家团时聚焦搜索框。弹窗参数从原生类型推导。确认操作忙碌时使用原生加载指示，保留按钮文案和可访问名称，并禁止重复点击。

专家配置使用原生 YAML 解析规则。目录、专家编辑、说明读取及公司内容刷新沿用原生 Remote 取消信号；切换市场或我的、切换专家或专家团、重置连接及卸载页面时取消详情读取，迟到结果不能重新打开弹窗。提交发布使用相同的读取取消信号和原生字节编码工具。关闭页面释放等待，不中断主进程中供其他页面使用的共享同步，迟到的目录不发布为当前结果。

`@` 菜单、工具栏和专家团页面直接读取同一目录快照，通过 React 原生外部存储订阅更新，不另存已启用名册、专家团列表或通知集合。启用选择和修订号统一随 `getCatalog` 读取，保存后接受 `setEnabled` 回执。切换目录实例的首次提交即读取新快照，旧目录更新不影响当前页面。

同一修订的目录和团队回执使用原生 JSON 结构比较；仅对象字段顺序变化时保留已有快照，不通知订阅者，列表顺序和成员映射变化仍发布更新。保存确认前的页面选择不改变 `@` 名册；新增或移除公司分类后同步更新原生输入来源，无需重启或切换语言。选择专家团时重新核对当前快照中的启用状态，已停用或移除的旧候选不能插入；复制名称使用最新已确认的团队名称。

<a id="teams"></a>
## 专家团

团队查询、保存、启停、删除及草案编辑准备返回统一的完整团队快照，包含当前原生成员映射和可用的执行方式；客户端直接接受回执，不以旧缓存补齐执行元数据。原生成员卡片按当前 Harness 界面结构映射显示名，任务路由标识保持原值。

团队提交发布将原生取消信号传到公司目录、团队目录及成员说明读取，取消后不返回迟到的发布内容。打开已确认草案时，离开操作入口会取消编辑准备；Host 在领取草案前检查取消，尚未领取的草案仍可重试。已打开的编辑表单按原有方式保留待保存内容。

专家团目录刷新失败时保留已确认的目录、搜索条件和重试入口；成功读取后清除错误。切换目录或关闭页面后，旧请求不能更新当前提示。

快捷选择器在目录读取期间关闭后可重新打开，复用同一在途读取；刷新中选择专家先等待目录，再按最新修订号启用并写入操作发起时的编辑器。等待期间关闭或卸载不发起启用；已派发的启用请求继续完成，关闭后不插入。读取失败保留提示和刷新重试入口，成功重试前不使用旧目录启用或插入。

个人专家和专家团保存、启停与删除沿用原生 Remote 取消信号。准备目录期间取消不提交设置；已交给原生 Settings 的事务完整结束，不因页面关闭回滚。取消后的目录和团队回读不作为成功回执返回。

公司专家目录仅缓存完整读取的结果；目录、专家文件或专家团文件发生读取故障时不返回部分名册，保留内部原因并提示刷新。读取恢复后可重新加载同一固定版本，成功结果继续复用。显式配置的本地分类可以缺失，无效元数据仍不进入名册。

模型可见的专家说明、工具文案及新委派名称遵循设置中的语言。明确选择 `zh` 或 `zh-*` 使用中文，未选择或无法读取时采用 Harness 默认英文；历史会话中已记录的名称和内容不重新翻译。

<a id="model-experience"></a>
## Model Experience

### Native capabilities

#### What the model sees

模型通过 `list_experts` 浏览专家名册并通过 `summon_expert` 使用选定说明；个人内容和团队内容按当前版本读取。独立专家目录与数量仅包含已启用且可独立召唤的专家，不包含专家团内置成员。公司内容按 Session 固定版本，输入记录沿用原生日志。专家及普通专家团成员的说明使用原生字面量提示词段，保留 `{{…}}` 示例原文，不解析为宿主变量。父任务取消时立即释放普通子代理，等待清理完成后再结束召唤；其他取消监听器不能阻断释放，迟到答案不作为召唤结果。创建专家、专家团及打开草案编辑器的工具将原生取消信号传到目录读取；取消后不返回名册成功结果、不写入或确认草案，也不发起编辑确认。

#### Token effect

名册、委派参数和说明按需占用上下文。页面整合不新增模型输入。

#### KV Cache effect

不管理模型缓存；内容变化由官方请求组装处理。
