# 企业产品界面

## 概述

左侧“扩展能力”提供专家套件、技能、连接器和知识库入口，以及反馈和检查更新入口。专家套件、技能在主内容区内嵌展示，设置中的入口继续保留；两处复用同一插件页面和数据。打开设置时内嵌页面暂停，避免重复挂载。专家与技能由预装的 Agency Agents、Skills Manager 插件管理，不再提供自建目录、创作、导入或套件选择器。

市场仅展示已发布的公司连接器，我的展示本人可管理的连接器；本人已发布内容在两处均可见，草稿和待审核内容只在我的。连接器目录支持搜索、分类、市场／我的筛选；分类入口固定显示，六类依次为业务系统、电商平台、协同办公、数据分析、开发运维、其他，未填写或未识别的分类在目录和详情统一归入“其他”。空分类仍可选择；切换市场／我的时重置为全部分类。分类按系统用途划分，ERP 的订单、库存等模块仍属于同一个连接器，不影响工具发现和审批。

创建支持表单和 MCP JSON，表单可选择分类；所有者可修改、提交发布或删除，第三方账号连接与设备私密配置独立管理。目录和详情不展示就绪、待配置、停用或不可用状态；需要第三方授权或设备私密配置时，详情提供对应操作，连接失败在实际使用时提示原因。协议与认证参数留在配置流程。操作按回执核对资源 ID 和版本；失败保留输入，切换员工后取消旧请求。

连接器表单、尚未应用的 MCP JSON 和设备私密配置有未保存修改时，关闭需确认；保存期间禁止关闭，刷新窗口保留离开提示。剪贴板读取只应用到发起读取时的表单，后续编辑、保存或新的粘贴请求会使旧结果失效。

第三方授权从发起请求起最多等待 60 秒，期限覆盖发起请求和状态轮询，不受系统时钟调整影响。到期取消在途请求、停止轮询并允许重新发起；关闭详情取消等待，迟到结果不刷新目录或影响新的授权尝试。

目录搜索包含本地化分类名称，空结果支持清除筛选。详情中的业务能力支持名称、说明和工具原名搜索及只读／写入筛选，每次显示 20 项；逐项展开查看原名和完整说明，不在浏览时调用业务工具。创建和修改可填写简介，便于目录识别业务用途。显式刷新会提示未连上的连接器名称，不隐藏其他目录项；再次刷新成功后清除提示。

连接器目录读取时在刷新按钮内显示原生加载指示，不在分类标题的位置插入临时文字；刷新期间保留已有列表和空结果，切换员工立即清除旧目录。

知识库保持左侧资料工作区，按个人、直属部门和公司展示。资料支持上传、文件夹与子文件夹管理、搜索、预览和下载，任务引用只在对话输入框添加。选择为空时不启用检索；组织服务故障不能当成权限撤销。具体操作见[产品总览](../../../apps/product-desktop/docs/README.md)。

刷新当前知识库时保留已显示的资料与文件夹，避免加载占位反复替换内容。切换库、文件夹、分页或筛选条件时隔离旧范围；确认失权后立即清除资料和阅读内容。聊天中的引用来源同样在确认失权后关闭阅读器、取消未完成的预览并显示原因；历史引用条目保留，再次打开会重新检查权限。

未确认保存的知识库草稿按员工、知识库和编辑动作恢复，保留原请求标识。切换编辑目标会重建表单并取消旧读取；重叠重试仅接受最新结果，取消的身份读取不会更改后续清理所用的员工存储键。关闭后保留的恢复回调不再发起请求。

原文件预览读取失败或取消时立即返回原始错误，并发起传输关闭；关闭失败独立记录，不覆盖权限错误或延迟取消。正常读取需等到关闭确认后才交付内容。未确认清理的临时文件仍由主进程的传输期限、员工切换和退出清理负责。

目录、详情、编辑器和任务知识库选择器的读取统一使用 `ProductLoading` 原生加载指示，保留可访问的加载状态名称，不短暂插入“加载中”文字或误报空数据；已有的空分组在目录刷新期间保持显示。

会话、工作区、执行模式、草稿和预览通过官方公开接口调用；员工令牌不进入渲染进程。任务准备回执的会话类型须为协议字符串，无效回执不创建会话、不切换执行模式、不改写草稿。旧产品任务配置失效时保留历史和草稿，提供明确恢复入口。

任务准备和重试通过原生会话引用的取消信号等待历史加载；切换员工或卸载界面会结束旧请求的等待并释放引用，不取消其他持有者的共享加载。原生预设读取与选择失败保留错误码、详情及原因，不切换任务或改写草稿；已经完成的能力准备不因后续失败自动回滚。

首次创建任务使用原生默认工作区初始化及其取消信号；取消后不再打开目录选择窗口。目录选择直接调用原生 Remote 并传入同一信号，取消会通知选择器后端终止等待；返回后重新核验操作状态，旧员工的迟到选择不再登记工作区或创建任务。选择失败保留原生错误；取消前已经完成的工作区登记不自动撤销。

技能和自定义专家的“提交到公司”由产品弹窗统一确认、展示审核状态及拒绝原因。插件的 `dsh:company-content-submit` 事件携带名称和可取消的内容准备函数，上传通过主进程执行。仅检查已有提交时允许空状态；提交回执必须包含有效审核状态与文字审核意见，非法回执显示结果未确认并保留内容，不自动重放。同一员工的登录续期、切换界面语言保留弹窗和在途提交；退出、切换员工或卸载组件会取消旧请求。

反馈草稿和截图只属于当前员工；身份尚未确认时收到账号变化，也会清空旧草稿、取消提交并忽略迟到回执。同一员工续期及关闭后重新打开保留草稿。

<a id="model-experience"></a>
## 模型体验

### 企业能力

#### 模型看到的内容

本包不直接组装模型输入；运行时负责记录 `MCP` 连接器工具和知识库检索结果。

#### Token 影响

协议和界面本身不增加模型 Token。

#### KV Cache 影响

不管理模型缓存；工具及检索内容的变化由官方模型请求组装处理。

## 已知限制与延期工作
<a id="known-limitations-and-deferred-work"></a>

- 企业服务需要有效员工身份及可访问的组织服务；第三方专家和技能插件使用其自身的管理入口。
