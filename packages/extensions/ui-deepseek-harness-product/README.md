# 企业产品界面

## Summary

从左侧“扩展能力”使用专家、技能、连接器和知识库，通过设置提交反馈或检查软件更新。专家和技能页面由内建产品模块提供，随桌面统一更新；打开设置时暂停内嵌页面，避免重复挂载。

<a id="connectors"></a>
## 连接器

市场仅展示已发布的公司连接器，我的展示本人可管理的连接器；本人已发布内容在两处均可见，草稿和待审核内容只在我的。连接器目录支持搜索、分类、市场／我的筛选；分类入口固定显示，六类依次为业务系统、电商平台、协同办公、数据分析、开发运维、其他，未填写或未识别的分类统一归入“其他”。空分类仍可选择；切换市场／我的时重置为全部分类。分类按系统用途划分，ERP 的订单、库存等模块仍属于同一个连接器，不影响工具发现和审批。

创建支持表单和 MCP JSON，表单可选择分类；所有者可修改、提交发布或删除，第三方账号连接与设备私密配置独立管理。目录和详情不展示就绪、待配置、停用或不可用状态；需要第三方授权或设备私密配置时，详情提供对应操作，连接失败在实际使用时提示原因。协议与认证参数留在配置流程。操作按回执核对资源 ID 和版本；失败保留输入，切换员工后取消旧请求。

HTTP 连接器表单显示公司 OAuth 提供方的读取状态；读取失败可独立重试，保留当前表单和私密输入，关闭编辑器时取消在途请求。

目录搜索包含本地化分类名称，空结果支持清除筛选。详情中的业务能力支持名称、说明和工具原名搜索及只读／写入筛选，每次显示 20 项；逐项展开查看原名和完整说明，不在浏览时调用业务工具。创建和修改可填写简介，便于目录识别业务用途。显式刷新会提示未连上的连接器名称，不隐藏其他目录项；再次刷新成功后清除提示。

连接器目录读取时在刷新按钮内显示原生加载指示，不在分类标题的位置插入临时文字；刷新期间保留已有列表和空结果，切换员工立即清除旧目录。

连接器与知识库目录通过产品协议包统一校验；缺少资源 ID、重复 ID 或损坏的工具声明会显示读取失败，不用列表序号代替 ID，也不把异常响应显示为空目录。

<a id="knowledge"></a>
## 知识工作区

知识库按个人、直属部门和公司展示，支持上传、目录管理、搜索、预览和下载。任务引用只在对话输入框添加，空选择不启用检索；组织服务故障不能当成权限撤销。权限与任务绑定见[产品子系统](../../../docs/subsystems/deepseek-harness-product.md)。

点击知识库名称返回首页；左侧加号创建顶层目录，文件夹菜单创建子目录。“按文件夹／全部文件”切换直属资料与跨目录文件，文件菜单可定位目录。管理者可改名、移动资料及删除空目录，非空目录拒绝删除；新建和导入使用当前位置，位置未确认时先检查全部文件，不能重复创建。

刷新当前知识库时保留已显示的资料与文件夹，避免加载占位反复替换内容。切换库、文件夹、分页或筛选条件时隔离旧范围；确认失权后立即清除资料和阅读内容。

知识库请求复用统一产品调用入口，取消或页面卸载后立即结束等待，不依赖后端取消回执；已打开的预览传输仍会发送关闭请求。

任务知识库选择跟随当前员工和目录更新。退出或切换员工时清除旧目录与待选状态、取消旧读取；同一员工登录续期及目录刷新保留未提交选择，库名称和可用项重新读取。已勾选但从目录移除的库显示为不可用，仍可取消勾选。

切换界面语言保留知识文档的在途读取及未保存标题、正文，不重新加载覆盖草稿；读取失败使用当前界面语言提示。

目录、详情、编辑器和任务知识库选择器的读取统一使用 `ProductLoading` 原生加载指示，保留可访问的加载状态名称，不短暂插入“加载中”文字或误报空数据；已有的空分组在目录刷新期间保持显示。

<a id="tasks-and-submissions"></a>
## 任务与提交

会话、工作区、执行模式、草稿和预览使用官方公开接口；员工令牌不进入渲染进程。任务配置失效时保留 Session 历史和草稿，提供显式恢复入口。

技能、自定义专家和完整专家团的“提交发布”由产品弹窗统一确认、展示审核状态及拒绝原因。插件的 `dsh:company-content-submit` 事件携带名称和可取消的内容准备函数，上传通过主进程执行。同一员工的登录续期、切换界面语言保留弹窗和在途提交；退出、切换员工或卸载组件会取消旧请求。

任务选择在调用原生 Session API 前校验完整准备回执及依赖检查，损坏或与显式选择不符的回执保留当前任务、草稿和导航，并提供刷新重试提示；任务读取沿用同一产品协议校验。

<a id="support"></a>
## 反馈与更新

反馈草稿和截图只属于当前员工；身份尚未确认时收到账号变化，也会清空旧草稿、取消提交并忽略迟到回执。同一员工续期及关闭后重新打开保留草稿。

检查更新复用原生 `DesktopUpdateBridge.open()`，由主进程展示状态和错误。

<a id="model-experience"></a>
## Model Experience

### Enterprise capabilities

#### What the model sees

本包不直接组装模型输入；运行时负责记录 `MCP` 连接器工具和知识库检索结果。

#### Token effect

协议和界面本身不增加模型 Token。

#### KV Cache effect

不管理模型缓存；工具及检索内容的变化由官方模型请求组装处理。

## Known Limitations and Deferred Work
<a id="known-limitations-and-deferred-work"></a>

- 企业服务需要有效员工身份及可访问的组织服务；第三方专家和技能插件使用其自身的管理入口。
