# 企业产品界面

## Summary

左侧“扩展能力”提供专家套件、技能、连接器和知识库入口，以及反馈和检查更新入口。专家套件、技能在主内容区内嵌展示，不提供设置重复页、独立安装或独立更新。打开设置时内嵌页面暂停，避免重复挂载。专家与技能由预装的 Agency Agents、Skills Manager 插件管理，不再提供自建目录、创作、导入或套件选择器。

市场仅展示已发布的公司连接器，我的展示本人可管理的连接器；本人已发布内容在两处均可见，草稿和待审核内容只在我的。连接器目录支持搜索、分类、市场／我的筛选；分类入口固定显示，六类依次为业务系统、电商平台、协同办公、数据分析、开发运维、其他，未填写或未识别的分类统一归入“其他”。空分类仍可选择；切换市场／我的时重置为全部分类。分类按系统用途划分，ERP 的订单、库存等模块仍属于同一个连接器，不影响工具发现和审批。

创建支持表单和 MCP JSON，表单可选择分类；所有者可修改、提交发布或删除，第三方账号连接与设备私密配置独立管理。目录和详情不展示就绪、待配置、停用或不可用状态；需要第三方授权或设备私密配置时，详情提供对应操作，连接失败在实际使用时提示原因。协议与认证参数留在配置流程。操作按回执核对资源 ID 和版本；失败保留输入，切换员工后取消旧请求。

目录搜索包含本地化分类名称，空结果支持清除筛选。详情中的业务能力支持名称、说明和工具原名搜索及只读／写入筛选，每次显示 20 项；逐项展开查看原名和完整说明，不在浏览时调用业务工具。创建和修改可填写简介，便于目录识别业务用途。显式刷新会提示未连上的连接器名称，不隐藏其他目录项；再次刷新成功后清除提示。

连接器目录读取时在刷新按钮内显示原生加载指示，不在分类标题的位置插入临时文字；刷新期间保留已有列表和空结果，切换员工立即清除旧目录。

连接器与知识库目录通过产品协议包统一校验；缺少资源 ID、重复 ID 或损坏的工具声明会显示读取失败，不用列表序号代替 ID，也不把异常响应显示为空目录。

知识库保持左侧资料工作区，按个人、直属部门和公司展示。资料支持上传、文件夹与子文件夹管理、搜索、预览和下载，任务引用只在对话输入框添加。选择为空时不启用检索；组织服务故障不能当成权限撤销。具体操作见[产品总览](../../../apps/product-desktop/docs/README.md)。

刷新当前知识库时保留已显示的资料与文件夹，避免加载占位反复替换内容。切换库、文件夹、分页或筛选条件时隔离旧范围；确认失权后立即清除资料和阅读内容。

目录、详情、编辑器和任务知识库选择器的读取统一使用 `ProductLoading` 原生加载指示，保留可访问的加载状态名称，不短暂插入“加载中”文字或误报空数据；已有的空分组在目录刷新期间保持显示。

会话、工作区、执行模式、草稿和预览通过官方公开接口调用；员工令牌不进入渲染进程。旧产品任务配置失效时保留历史和草稿，提供明确恢复入口。

技能和自定义专家的“提交到公司”由产品弹窗统一确认、展示审核状态及拒绝原因。插件的 `dsh:company-content-submit` 事件携带名称和可取消的内容准备函数，上传通过主进程执行。同一员工的登录续期、切换界面语言保留弹窗和在途提交；退出、切换员工或卸载组件会取消旧请求。

反馈草稿和截图只属于当前员工；身份尚未确认时收到账号变化，也会清空旧草稿、取消提交并忽略迟到回执。同一员工续期及关闭后重新打开保留草稿。

任务选择在调用原生 Session API 前校验完整准备回执及依赖检查，损坏或与显式选择不符的回执保留当前任务、草稿和导航，并提供刷新重试提示；任务读取沿用同一产品协议校验。

<a id="model-experience"></a>
## Model Experience

### Enterprise capabilities

#### What the model sees

本包不直接组装模型输入；运行时负责记录 `MCP` 连接器工具和知识库检索结果。

#### Token effect

协议和界面本身不增加模型 Token。

#### KV Cache effect

不管理模型缓存；工具及检索内容的变化由官方模型请求组装处理。

## Known Limitations and Deferred Work
<a id="known-limitations-and-deferred-work"></a>

- 企业服务需要有效员工身份及可访问的组织服务；第三方专家和技能插件使用其自身的管理入口。
