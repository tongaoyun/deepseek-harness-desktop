# 企业产品界面

<a id="summary"></a>
## 概述

从左侧“扩展能力”使用专家、技能、连接器和知识库，通过设置提交反馈或检查软件更新。专家和技能页面由内建产品模块提供，随桌面统一更新；打开设置时暂停内嵌页面，避免重复挂载。

四类资源页面共用[页面标题规范](DESIGN.md#页面标题)，统一正文宽度、标题、说明和窗口控件避让空间；空状态、读取提示及键盘焦点遵循[状态规范](DESIGN.md#状态与权限)。

<a id="employee-sign-in"></a>
## 企业登录

左下角常驻员工入口：未登录时显示“未登录”，登录后显示员工名称；检查失败明确标记状态不可用。整行点击展开菜单，未登录时首项为“登录”，打开统一钉钉授权弹窗，等待时可取消，失败可重试。登录状态通过主进程读取和订阅，员工凭据不进入界面。

连接器、知识库及对话中的企业资源操作共用此授权弹窗，不切换当前页面或修改草稿。对话输入框不常驻登录提醒，主动选择知识库时才请求登录。授权等待由侧栏管理，切换资源页保留等待；关闭弹窗或卸载侧栏会取消请求，迟到结果不更新界面。员工菜单提供设置、反馈和软件更新，未登录时也可使用；菜单在员工栏上方对齐，再次点击可关闭。关闭菜单或从菜单打开的授权、反馈窗口后，焦点回到员工入口。

<a id="connectors"></a>
## 连接器

市场展示已发布的公司连接器，我的展示本人可管理的连接器；草稿和待审核内容只在我的。目录支持搜索和六类筛选：业务系统、电商平台、协同办公、数据分析、开发运维、其他。分类固定显示，未知分类归入“其他”；切换市场／我的时重置为全部分类。分类描述系统用途，不拆分 ERP 等系统内部模块，也不影响工具发现和审批。连接器和知识库目录的读取错误随界面语言更新，不重复请求。

创建支持表单和 MCP JSON，可填写分类和简介；所有者可修改、提交发布或删除。第三方账号连接与设备私密配置独立管理，所需操作在详情提供；协议和认证参数仅在配置流程展示，连接失败在实际使用时说明原因。操作回执必须匹配资源 ID 和版本；失败保留输入，切换员工取消旧请求。删除及提交确认在请求发起前锁定重复操作和关闭，等待及失败重试保留错误、按钮焦点与外观，核对回执后清除错误。服务端确认删除但本机清理失败时，目录移除该项并显示重启确认提示，不再提供重复删除；移除的确认按钮将焦点交给“关闭”。关闭详情、编辑器或删除确认时，若原卡片已被刷新移除或重新分组，失去目标的焦点返回目录搜索框；保留搜索草稿、选区及用户主动转移的焦点，不滚动页面。管理操作的错误随界面语言更新。

STDIO 从 MCP JSON 导入或已有连接器编辑时，未修改的命令和参数按原值保存，保留多行脚本、CRLF、空参数及路径字符。手动修改命令仍校验引号，并拒绝管道、重定向和变量展开。

私密字段仅在本机已配置、连接目标未改变且字段名匹配时提示“留空保留”，按[主进程规则](../../deepseek-harness-product/desktop/README.md#connectors)识别字段。新字段、更换目标或本机未配置时提示填写；JSON 导入不替换原配置的判断基准。

HTTP 连接器的公司 OAuth 提供方读取失败可独立重试，保留表单及私密输入；关闭编辑器取消读取。已配置的 OAuth 服务未在列表中时保留当前选择，可主动切换为本机配置或其他可用服务；读取结果不自动改变认证方式。编辑、本机配置和 OAuth 提供方的读取重试保留错误、原按钮及键盘焦点，等待时阻止重复点击并保留外观，成功后清除错误；重试入口移除时，焦点返回服务器类型或本机超时字段，不滚动页面，也不抢占其他控件焦点。请求发起时防止重入，连续触发只读取一次。添加请求头或环境变量行后进入新键名；删除焦点所在行后进入相邻键名或添加入口，焦点在保留行时不转移，保留其余输入及光标、选择范围。表单行标识不进入配置。编辑及设备配置的校验、读取、保存错误和待确认提示随界面语言更新，保留输入和在途请求，不重复读取或保存。

连接器编辑与本机配置的错误固定显示在提交按钮上方，滚动长表单仍可看到；保存等待及失败重试保留提交按钮焦点和错误，核对回执后清除错误。放弃修改确认暂时隐藏并保留表单，聚焦“继续编辑”；取消放弃后恢复原字段、光标及文本选择。粘贴配置按键名更新、优先填充空行，保留已有输入控件、焦点及未改变字段的文本选择；读取期间修改表单使旧粘贴失效。保存时保留配置行粘贴、添加、删除及提供方重试按钮的外观，锁定表单操作；仅执行中的按钮报告忙碌，阻止重复提交。私密字段的规则见[产品协议](../../deepseek-harness-product/product/README.md#authentication)。

连接器和知识库管理、添加资料、文件及文件夹菜单在操作禁用时关闭，恢复可用后需重新点击打开；请求等待保留触发按钮的外观和焦点，不能重开菜单；失去管理权限移除对应管理操作，按钮展开状态与实际菜单一致。从菜单打开编辑或确认窗口，关闭后焦点返回仍存在的原操作按钮。

详情按资源 ID 和版本隔离授权与设备配置；版本变化关闭旧配置并取消请求，迟到回执不能更新新版本或带入旧私密输入。保存配置期间关闭按钮、Esc 和遮罩均保留表单，并提示等待保存结果。取消等待不能撤回已完成的保存。

新建、编辑、本机配置保存及授权操作在请求发起时即防止重入，连续触发只发送一次；保存开始后立即保护关闭。授权与撤销等待及失败重试保留按钮焦点、原错误和按钮外观，按钮报告忙碌，核对成功回执后清除错误；切换语言不重复请求。授权确认后的目录刷新可独立重试，不重复授权或撤销。失败释放操作状态，保留可重试的表单及私密输入。

目录搜索包含本地化分类名称，空结果支持清除筛选；清除连接器、工具或知识库目录筛选后，焦点返回当前搜索框。业务能力支持按名称、说明、工具原名搜索及只读／写入筛选，每次展开 20 项，可展开完整说明；保留已有行与展开状态，最后一批展开后将“显示更多”的键盘焦点移至首个新增工具。浏览不会调用业务工具。刷新保留已有列表和详情的搜索、展开状态，提示未连上的连接器名称，成功后清除提示；详情刷新失败及重试期间隐藏未确认的工具和配置操作，保留工具浏览控件；确认成功后恢复搜索、读写筛选、展开说明和已加载数量。同一版本的能力清空时隐藏并保留浏览控件，能力恢复后沿用搜索、选区、读写筛选、列表展开和已加载数量；隐藏控件不接受键盘焦点。刷新提交详情前捕获焦点；移除配置控件时，其焦点进入重试或恢复后的授权、本机配置按钮；移除工具条目或分页入口时，焦点返回能力搜索框，能力清空时进入能力标题，刷新失败时进入重试按钮。不滚动或抢占保留控件的焦点。连接器与知识库目录重试保留错误区和原操作按钮，等待时阻止重复点击并保留外观，成功后清除错误；首次读取失败后的重试不重新插入首屏占位。身份读取或目录重试成功、刷新移除卡片或错误隐藏列表时，已移除控件的焦点返回当前目录区域，不滚动页面；保留控件及用户主动转移的焦点不变。切换员工或目录类型清除对应旧错误及内容。

连接器与知识库未登录时保留页面标题和简短访问说明，登录操作指向[统一企业登录](#employee-sign-in)。

<a id="knowledge"></a>
## 知识工作区

知识库首页按个人、直属部门和公司筛选，可搜索名称、简介和所属人；选中知识库后进入资料管理，支持上传、目录管理、搜索、预览和下载。任务引用只在对话输入框添加，空选择不启用检索；组织服务故障不能当成权限撤销。权限与任务绑定见[产品子系统](../../../docs/subsystems/deepseek-harness-product.md)。

“添加资料”支持原生文件选择、网页正文导入、新建文档和文件夹。库内可浏览文件夹或全部文件；切回文件夹恢复原位置，文件菜单可定位原目录，非空目录拒绝删除。网页名称可选，无效网址明确提示。PDF 默认沿用库设置，也可选择仅提取已有文字，不识别扫描页或图片文字。创建、导入和上传均显示保存位置；保存回执核对库信息、文件身份和目标目录，结果未确认时保留草稿，重试沿用原请求。

首屏完整读取文件夹与文件后显示资料；等待时使用静态占位并禁用新增操作，失败可重试。刷新保留已有资料及同一文件夹的标题和路径；同一目录修改或清除筛选保留工具栏，不切回首屏占位，清除后焦点返回资料标题。资料删除后的焦点恢复遵循[控件与交互规范](DESIGN.md#控件与交互)。处理轮询使用当前文件夹页，不禁用已选资料的批量操作，手动刷新重新核对。空库隐藏搜索和筛选，筛选无结果保留清除入口。管理者可编辑库名称和简介，保存校验版本；冲突需重新打开编辑，结果未确认时保留原请求及内容。库信息加载失败使用独立提示；服务端缺少接口时明确提示更新服务端。

“正文搜索”复用混合检索，覆盖当前库全部文件夹，最多返回 12 条片段；打开结果重新校验来源权限，暂时隐藏并保留搜索控件和结果，返回时恢复原结果按钮的焦点。等待时重复提交不重发请求；相同查询再次搜索保留已确认结果；后台目录刷新原位复核已提交搜索和当前来源，保留查询及阅读位置，未提交的新查询不执行。修改查询取消旧请求并清除结果，迟到结果不改变新查询。搜索与引用阅读共用片段校验，要求完整字段及匹配的库、来源和文件标识；异常响应清除结果并提供重试，不展示部分正文。同一引用刷新保留片段及阅读入口，切换引用或读取失败清除旧正文。资料列表、保存位置、正文搜索、引用、解析正文和处理详情更新时保留现存控件焦点；链接、重试、分页或摘要操作被移除时，焦点回到资料标题、搜索框或对应区域，不滚动页面，也不抢占其他控件焦点。切换原文件沿用同一规则。阅读支持原文件、解析内容和处理详情；原文件复用 Harness 预览，解析内容按需分页读取入库文本，不触发解析或模型调用。

处理详情显示解析、分段、索引、图片理解和内容整理的状态与实际耗时，无记录时明确提示。仅在处理中自动刷新，失败可手动重试。管理者可重新生成已启用的摘要，提交等待及失败重试保留按钮焦点和错误；处理中不可重复提交，失败保留操作 ID，核对回执后才显示已提交。关闭阅读或失权取消等待。

切换库、文件夹、分页或筛选条件隔离旧请求；确认失权立即清除资料、正文和管理操作，可重新核对或返回目录。路径未确认时不提供库删除操作；当前库被移除后返回目录，不自动读取其他库。库或当前文件在后台刷新后消失时，仅恢复本区域持有的焦点，保留其他控件的焦点。目录首页不读取正文。进入库后暂时隐藏并保留目录；进入阅读或正文搜索时保留资料控件和勾选，返回时恢复原控件、滚动位置及资源按钮焦点。返回资料时取消正文读取，退出登录时移除目录和资料。布局、控件及加载提示见[设计规范](DESIGN.md)。

请求通过统一产品入口，取消或卸载立即结束等待，并尝试关闭已打开的预览传输。预览必须先核对库和文件标识；资料列表和保存位置选择器核对目录、请求页码及页大小，拒绝重复记录，资料还须匹配当前库；混合分页的文件总数必须一致。分页计数须为有效整数，条数不得超过页大小或总数。异常响应不展示部分结果，显示读取失败并提供重试；保存位置未确认时不可提交。

任务知识库引用位于输入正文上方，从原生添加菜单修改；文件引用由原生编辑器管理。退出或切换员工清除旧目录和待选状态、取消读取；同一员工续期或刷新目录保留勾选行、焦点和未提交选择，完成后更新名称与可用性；部门归属变化、条目不可用及恢复时保留同一复选框、搜索和选区，仅更新分组与提示。目录确认前不可应用选择，读取失败清除旧目录并提供重试。任务配置和目录重试保留错误与原按钮，成功后清除错误；输入区重试按钮移除时，通过原生输入接口恢复其持有的焦点、草稿光标，不滚动页面、不抢占其他控件焦点；引用应用、移除和恢复在发起请求前锁定重复操作，并保护关闭。引用应用、移除和恢复等待及失败重试保留按钮焦点和错误；同一任务成功时，仅在原操作仍持有焦点、或该控件移除导致焦点退到页面时，通过原生输入接口恢复草稿光标，等待期间移到其他控件的焦点保持原位。需要新任务时，由原生导航展示并聚焦新输入框。切换任务使旧操作失效，返回同一任务也不接受旧结果。已选但被移除的库标为不可用，仍可取消选择；取消后条目移除时，其键盘焦点返回搜索框，保留查询和选区。切换语言保留搜索、待选内容和在途操作，目录读取与引用调整的错误按当前语言显示，不重复请求。读取完成或失败移除当前聚焦的重试入口或选项时，焦点返回选择器搜索框，不滚动页面，也不抢占其他控件焦点。

资料列表、正文搜索、引用、解析内容、处理详情及编辑器读取失败后，刷新保留错误与原操作按钮，不插入额外加载指示；成功后展示确认结果。连接器与知识库目录、资料列表、处理详情及连接器详情的刷新入口在等待时保留键盘焦点、图标和外观，通过无障碍状态报告暂不可用，重复触发不发起读取。保存位置须同时核实完整路径和文件夹列表，核实期间不能保存。草稿恢复重试保留错误、按钮外观与焦点，连续触发只核对一次员工身份，确认草稿后才开放编辑。资料库信息读取和草稿恢复沿用同一原生弹窗，保留关闭入口及返回原操作按钮的焦点；读取完成移除重试入口时，焦点回到当前表单，不滚动页面，也不抢占其他控件焦点。冲突复核失败移除对照内容、或确认继续编辑时，也将失去目标的焦点交回表单，保留当前草稿。未确认草稿的字段继续锁定。库、目录、文档及网页编辑器在放弃修改确认时保留表单；继续编辑恢复原字段、光标及文本选择，不重复读取保存位置。编辑器保存及“保留并关闭”在等待和失败重试时保留各自按钮、焦点和错误；仅发起操作的按钮报告忙碌，保留失败不关闭窗口或重新保存，成功关闭后再次打开恢复原内容与请求。单文件移动及文件、文件夹删除确认在等待和失败重试时保留取消与提交按钮的外观、焦点和错误，阻止重复提交及关闭；字段无效、冲突或内容未确认时仍显示禁用样式。编辑器、摘要及资料操作重试保留错误，确认成功后清除；下载原文件及外部打开等待和失败重试保留按钮焦点、外观与错误；保存、冲突复核、上传选择及原文件操作在发起请求前锁定重复操作。原文件操作仅标记当前动作忙碌，冲突复核不显示保存进度；重复读取期间保留对照内容并锁定确认，读取失败清除对照内容，重新读取成功后才可确认继续。单文件与批量移动在首次提交时固定目标目录，保留文件版本和操作 ID；连续点击不能改选目标或替换待核实的请求。移动、删除错误只在当前弹窗显示，取消后清除。

资料列表、解析内容和保存位置分页在等待及读取失败时保留分页按钮、键盘焦点、内容区高度与已确认的总数，新页内容须读取成功后展示。翻页不切回首屏占位，资料筛选栏保持原位。读取期间阻止翻页，原可用按钮保留外观；到达首尾页后保留原按钮焦点，边界按钮显示禁用样式且不能翻页。选择保存位置时，进入子目录、返回上级或首页会将导航按钮持有的焦点交到目录选择区，不滚动页面；其他字段的焦点、选区和草稿保持原位。保存期间锁定位置选择。连续点击或交替点击只移动一页，切换文件、目录或筛选条件不沿用旧总数或高度。

知识库删除确认在请求发起前锁定重复操作和关闭，等待及失败重试保留按钮焦点和错误至成功。上传及批量操作将执行状态与上次结果分开保存；等待及失败重试保留原按钮、键盘焦点与错误，阻止重复提交；处理最后一项时保留提交按钮。完成或不可重试的结果移除按钮时，其持有的焦点交到“关闭”，不滚动页面；其他控件及上传条目保持原焦点。未提交的批量操作取消、关闭或按 Esc 后保留勾选和原按钮焦点，不刷新资料；提交后关闭再刷新核对结果，焦点恢复见[控件与交互规范](DESIGN.md#控件与交互)。上传队列仅标记发起操作的按钮忙碌，移除单项不改变上传按钮的名称。

切换界面语言保留未保存内容、上传队列、批量结果和在途操作，不重复读取资料列表、正文、原文件、解析内容或处理详情；资料读取、编辑、删除、上传、批量操作及引用阅读的错误随当前语言更新，重试沿用原请求。

<a id="tasks-and-submissions"></a>
## 任务与提交

会话、工作区、执行模式、草稿和预览使用官方公开接口；员工令牌不进入渲染进程。任务配置失效时保留 Session 历史和草稿，提供显式恢复入口。

技能、自定义专家和完整专家团的“提交发布”由产品弹窗统一确认、展示审核状态及拒绝原因。内容准备、状态读取或提交失败可在原弹窗重试，等待时保留错误、原按钮及键盘焦点，进度只显示在当前按钮，连续触发只执行一次；提交期间不能关闭弹窗。只有核对状态后才允许提交，已有审核记录不重复提交。确认审核状态后禁用提交按钮，其持有的焦点转到“关闭”；其他控件保持焦点，页面不滚动。插件的 `dsh:company-content-submit` 事件携带名称和可取消的内容准备函数，上传通过主进程执行。同一员工的登录续期、切换界面语言保留弹窗和在途提交；退出、切换员工或卸载组件会取消旧请求。

提交失败提示复用产品错误映射，随当前界面语言更新；已识别的业务错误显示诊断码，未知异常不展示内部文本。

任务选择在调用原生 Session API 前校验完整准备回执及依赖检查，损坏或与显式选择不符的回执保留当前任务、草稿和导航，并提供刷新重试提示。知识库引用直接读取任务能力并校验响应，不依赖模式目录；读取失败可重试，登录失效提供登录入口，身份切换要求重启桌面。退出登录时清除界面中的企业引用并停止读取，重新登录后读取当前员工的配置。登录状态与重启提示只显示操作说明，不展示内部诊断码；登录入口见[企业登录](#employee-sign-in)。同一任务切换语言不重复读取配置。

<a id="support"></a>
## 反馈与更新

反馈入口要求员工身份；未登录时复用统一钉钉授权，成功后打开编辑器，取消授权不会再自动打开。登录失效时关闭反馈窗口并清空草稿、取消提交，忽略迟到回执；同一员工续期及关闭后重新打开保留草稿。附件校验和提交错误随界面语言更新，切换语言不重发反馈、不改变重试标识。删除图片保留其余预览，焦点返回反馈正文并保留光标与文本选择。发送期间锁定附件操作并保留按钮外观；发送等待及失败重试保留按钮焦点和错误，核对回执后清除错误。成功时若焦点仍在提交按钮，则回到正文；用户已移到其他控件时保留当前位置。

检查更新复用原生 `DesktopUpdateBridge.open()`，由主进程展示状态和错误。

<a id="model-experience"></a>
## 模型体验

### 企业能力

#### 模型看到的内容

本包不直接组装模型输入；运行时负责记录 `MCP` 连接器工具和知识库检索结果。

#### Token 影响

协议和界面本身不增加模型 Token。

#### KV Cache 影响

不管理模型缓存；工具及检索内容的变化由官方模型请求组装处理。
