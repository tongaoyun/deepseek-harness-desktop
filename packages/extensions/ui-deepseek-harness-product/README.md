# 企业产品界面

## 概述

左侧“扩展能力”提供专家套件、技能、连接器和知识库入口，以及反馈和检查更新入口。专家套件、技能在主内容区内嵌展示，设置中的入口继续保留；两处复用同一插件页面和数据。打开设置时内嵌页面暂停，避免重复挂载。专家与技能由预装的 Agency Agents、Skills Manager 插件管理，不再提供自建目录、创作、导入或套件选择器。

四类扩展能力的页面主标题统一使用 24px 字号、32px 行高和 600 字重，连接器与知识库在产品样式内对齐预装插件。

连接器目录支持搜索、分类、全部／已配置／我的互斥筛选；未填写或未识别的分类统一归入“其他”。创建支持表单和 MCP JSON；所有者可修改、提交共享审核或删除，第三方账号连接与设备私密配置独立管理。目录和详情只展示一个综合状态；“已配置”不代表已实际连接 MCP，停用、不可用、待配置和账号过期分别显示。协议与认证参数留在配置流程。操作按回执核对资源 ID 和版本；失败保留输入，切换员工后取消旧请求。

知识库保持左侧资料工作区，按个人、直属部门和公司展示。资料支持上传、文件夹与子文件夹管理、搜索、预览和下载，任务引用只在对话输入框添加。选择为空时不启用检索；组织服务故障不能当成权限撤销。具体操作见[产品总览](../../../apps/product-desktop/docs/README.md)。

会话、工作区、执行模式、草稿和预览通过官方公开接口调用；员工令牌不进入渲染进程。旧产品任务配置失效时保留历史和草稿，提供明确恢复入口。

技能和自定义专家的“提交到公司”由产品弹窗统一确认、展示审核状态及拒绝原因。插件的 `dsh:company-content-submit` 事件携带名称和可取消的内容准备函数，上传通过主进程执行。同一员工的登录续期、切换界面语言保留弹窗和在途提交；退出、切换员工或卸载组件会取消旧请求。

反馈草稿和截图只属于当前员工；身份尚未确认时收到账号变化，也会清空旧草稿、取消提交并忽略迟到回执。同一员工续期及关闭后重新打开保留草稿。

## 模型体验

### 企业能力

#### 模型看到的内容

本包不直接组装模型输入；运行时负责记录 `MCP` 连接器工具和知识库检索结果。

#### Token 影响

协议和界面本身不增加模型 Token。

#### KV Cache 影响

不管理模型缓存；工具及检索内容的变化由官方模型请求组装处理。

## 已知限制与延期工作
<a id="known-limitations-and-deferred-work"></a>

- 企业服务需要有效员工身份及可访问的组织服务；第三方专家和技能插件使用其自身的管理入口。
