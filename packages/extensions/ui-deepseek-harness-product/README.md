# DeepSeek Harness产品能力

此包在 Harness 官方侧边栏中发布DeepSeek Harness产品能力导航。不会发布 companion 包，因为所有产品操作都通过 Electron 产品方法白名单和 `deepseek-harness.native.v1` sidecar 分发。

## 概述

能力面板展示产品目录，不重新实现 Harness 的对话或任务状态。

## 使用此包

在官方 Electron 桌面组合中启用此扩展，即可在官方侧边栏中展示“能力”分组及专家套件、技能、连接器和知识库四个入口。产品请求始终经过 产品方法白名单并由主进程产品桥处理，Renderer 不会获得员工会话凭据或上游连接器凭据。

目录在服务端完整目录上执行本地搜索。技能和套件按分类分组，连接器使用自身分类，知识库按组织归属分组。紧凑卡片保留名称、简介、作者、版本和实际状态。宽屏下套件与连接器显示两列，技能三列，随面板变窄减少列数。Harness 主题变量、图标和基础组件支持明暗主题。技能详情在官方 Modal 中直接渲染 `SKILL.md` 正文，保留文档标题和排版，不添加目录元数据或额外分区。YAML frontmatter 隐藏。只有正文滚动，标题、关闭按钮和安装操作始终可见；Escape 关闭弹窗并恢复焦点。套件在主面板打开完整详情。连接器“全部 / 已连接”区分账号授权和任务选择。OAuth 提供授权、重新授权和撤销，凭据由服务端保管。界面不推断元数据之外的权限或安装状态。

缺少设备本地配置的连接器显示**待配置**，并从**已连接**筛选中排除，即使服务端报告已授权。已授权但服务端暂时不可用的连接器仍在该筛选中，并显示真实可用状态。

详情为本人及共享非托管连接器提供**配置本机连接**。弹窗固定展示服务端版本的端点或命令，只填写所需私密值与超时，不要求编辑权限、不更改资源版本。失败保留输入；保存仅发现 MCP 工具，完成后刷新连接器目录。已保存私密值只显示空占位，留空保留当前员工的本机值。

授权或撤销成功后，只重新读取连接器目录以更新状态，不等待知识库及组织目录。授权失败与目录读取失败分别展示；目录故障不会改变已经确认的授权结果。

每个目录的刷新按钮只读取当前目录，不先刷新四类目录。知识库或组织服务不可用时，技能、套件与连接器仍可独立刷新；依赖故障不会被当作依赖已就绪，执行前继续校验真实权限。知识库目录临时失败时保留当前资料面板、编辑草稿及原保存请求，导航显示错误与重试；恢复目录不重建编辑器。明确失权或身份变化仍清理对应资料，服务端每次写入重新授权。

知识库、Markdown、网页导入与文件夹编辑通过关闭按钮、遮罩、Escape 或取消退出时，有未保存内容须明确确认放弃。保存中禁止关闭；结果待确认时锁定内容，可重试原保存或**保留并关闭**。关闭前将草稿、原操作编号和版本保存在本窗口的 `sessionStorage`，按认证员工及库、入口隔离；再次打开相同入口先恢复原请求，不能创建替代请求。存储失败保留编辑框，恢复数据损坏时阻止写入并提供重试。页面关闭或刷新仍保护尚未挂起的草稿；已挂起内容可跨本窗口刷新恢复，不承诺跨设备或关闭窗口后恢复。已加载但未修改的文档可直接关闭。

目录与详情分别管理读取请求。同一员工刷新目录或会话时，已打开的详情及其加载继续；关闭详情不取消目录刷新。退出登录或切换员工会清除已打开的资源详情、引用、编辑器、确认框、安装状态和知识库阅读器，并取消旧身份的读取和管理写入；迟到的响应不能重新打开上一员工的内容或发起其修改对话。面板卸载取消全部读取。身份传输不可用时显示加载失败，不误报为退出登录。

**安装技能**下载并校验一次内容，然后为该内容版本显示**已安装**。技能没有启用、停用状态。安装保留当前 Session、模式和草稿。任务依赖满足时，官方技能目录自动发现已安装技能，模型可请求加载说明，用户也可通过 `/<skillName>` 显式调用。已开始的任务保留固定技能版本，新内容版本可安装供后续任务使用。

已安装技能的卡片和详情，包括共享资源，均提供**更多操作 → 卸载**，确认框显示技能名称。卸载移除当前设备安装，新任务不再发现该技能。已开始任务保留固定内容、历史和草稿。服务端资源保留，可重新安装。失败时保留确认框供重试，成功后恢复**安装技能**，当前任务与草稿不变。

专家套件提供初始能力组合。选择知识库时保留已有能力。空任务直接调整，不重写编辑器；开始后通过官方选择检查创建同一工作区的新任务，带入最新文字与引用胶囊，原历史保留。官方草稿初始化接口在导航前持久化目标内容；提交未完成或持久化失败时保留来源任务和草稿。技能和专家套件声明连接器依赖，连接器目录管理账号授权。

可重试的恢复加载失败提供**重试**，只重新加载点击时捕获的 Session 固定快照，不选择 Preset、不创建 Session、不导航、不修改草稿。执行标识发生变化的响应由适配层拒绝。不可重试的快照或权限失败保留独立的显式配置恢复操作；临时故障不会清空套件、连接器或选中的知识库。

套件卡片和详情显示**安装专家套件**或当前目录版本不可点击的**已安装**状态。使用套件前须先安装：未安装详情隐藏**开始使用**。新选择要求本机安装的版本和哈希与可访问目录版本一致；发布新版本后须显式安装更新。准备任务不修改安装记录。新选择套件时，缺少安装或版本不匹配分别返回 `KIT_NOT_INSTALLED` 或 `KIT_INSTALLED_VERSION_CHANGED`。

已安装套件，包括共享资源，均在**更多操作**中提供**卸载**。确认框显示套件名称，说明移除本机安装，同时保留目录和已有任务内容。卸载失败保留确认框供重试；成功后恢复**安装专家套件**，当前任务与草稿保留。准备任务不会重新安装已卸载套件。已有任务保留固定内容和历史；调整模式或知识库无需重新安装快照中的套件。执行与加载说明时仍检查当前访问权限。所有者的修改、审核和删除仍是独立的资源操作。

执行模式直接使用[官方 Preset UI](../../client/ui-agent-preset/README.zh.md)及控制器：空任务菜单展示名称和描述，受开发者工具设置控制，开始一轮执行后在标题栏显示只读标签。组合任务快照按基础模式显示和勾选，Session 日志仍保留实际执行标识。产品不覆盖这两个官方模式插槽。

独立的**专家套件**选择器位于空任务的官方模式旁，使用同样的无框按钮样式。候选仅包含可访问目录中当前版本和哈希已安装到本机的套件。它显示固定的套件名称，未选时显示**专家套件**；当前选择不可用时仍显示名称，但不能作为候选选择。**不使用套件**清除组合，切换套件保留已选知识库，官方模式切换保留固定产品内容。

对话开始后，标题栏在官方模式旁以只读标签显示已选套件，不显示边框、箭头或菜单。未选套件时不显示标签。使用其他套件时，从目录详情选择**开始使用**，通过官方检查准备新任务，保留原任务历史和草稿。知识库仍可从输入框调整，并遵循同样的官方任务边界。

**+ → 引用知识库**支持搜索、多选暂存，再通过**应用**一次提交。已选知识库在输入框内显示为紧凑标签，悬停显示完整名称，超出宽度时横向滚动。可移除可选库；套件必需库保持锁定。未选择时不显示标签。取消丢弃暂存调整，准备失败保留暂存选择供重试。目录失败时保留已选标识。知识目录和任务选择通过本地化文案及诊断码区分员工映射缺失、员工停用、钉钉来源无效、同步过期和组织服务故障；不显示私有上游异常文本，目录不可用时不提供失权恢复动作。任务开始后知识库选择仍在输入框内，调整通过官方检查准备新任务。左侧**能力 → 知识库**目录保持可用。控件不展示私有快照 ID。

知识库“+”菜单入口随输入框注册，不等待能力读取完成。加载期间的打开请求会等待当前任务的能力就绪；切换任务会丢弃待处理请求。从目录返回后，无需先等待能力读取完成再打开选择器。

专家套件详情依次显示名称与版本、作者与来源、简介、技能、连接器、知识库和套件说明。依赖检查在准备任务时执行并显示具体失败原因。技能行显示名称和简介，连接器行显示授权状态，知识库行解析稳定引用并显示组织归属。引用不存在、无权访问、歧义和查询失败均不能显示为可用。套件详情不展示技术 ID 和哈希。说明显示紧凑的带边框 Markdown 预览，点击或通过键盘激活即可完整阅读，Esc 关闭并恢复焦点。选择套件后由用户自行输入需求，技能通过原生机制按需读取。

技能和专家套件提供固定的全部 20 类，包括空分类，以及“全部 / 我的”筛选。卡片不展示正常状态的“可使用”标签，保留依赖异常提示；技能卡片显示“安装”操作或当前设备的“已安装”状态，后者不可点击。“添加”统一创建和导入入口。创建或修改内容时，在来源工作区打开独立的官方对话，预填草稿但不自动发送。修改草稿明确显示资源类型和载入内容的名称。原任务和草稿保留；用户后续导航时不抢焦点。模型通过会话内工具更新内容并直接保存到个人目录，技能同时安装到本机。创建对话不显示预览或保存确认控件。修改个人资源准备新版本，旧任务保留原内容。提交共享审核仍是所有者的独立操作。

导入先选择文件或文件夹，再打开只读预览。标准目录和 ZIP 保留资源；单独导入 `SKILL.md` 时，保存前必须补齐产品元数据。“通过对话完善”补齐信息或调整内容。套件至少包含一个技能，选取可访问目录技能时按固定版本和哈希复制内容及资源。保存失败保留创建草稿，关闭预览取消其请求。未使用的导入暂存会释放，已关联创建 Session 的草稿在桌面重启后保留。对话切换使用官方侧栏。

连接器在授权管理之外提供“添加”和“我的”。“添加”直接打开一个“添加 MCP 服务器”弹窗，内部使用“手动填写 / 粘贴 JSON”标签，尺寸稳定，底部固定“添加”按钮。表单提供服务器类型、名称、HTTP 地址或完整 stdio 命令及私密键值行。资源 ID、版本、简介和分类使用系统生成的默认值，不提供高级编辑。命令解析保留带引号参数，拒绝 shell 操作和变量展开。剪贴板粘贴支持 JSON 字符串映射或每行 `KEY=VALUE`。标准 MCP JSON 填入表单；多个服务器须选择其中一个。切换标签保留已输入内容。本机超时设置接受 1–600 秒，默认 60 秒，用于连接、发现工具和工具调用。仅显式点击“添加”时发现工具，不调用业务工具。私密值遮蔽并只写不读，未保存凭据留在本地表单。已配置 OAuth 复用服务端授权及默认超时；本地配置需要在各设备填写。

连接器详情使用紧凑弹窗展示连接状态、连接类型、认证方式和授权操作，不提供任务勾选框或高级信息折叠项。所有者可通过同一个 MCP 弹窗修改个人连接器，或确认删除。保存失败保留输入，配置加载成功后才允许编辑。私密键显示空值，目标未改变时可以留空保留。读写能力摘要使用独立横栏，能力列表单独折叠，不展示工具技术名称。窄窗口下状态字段和摘要自动换行，不产生横向滚动。专家套件选择器仅显示套件名称，不显示简介，并在当前任务或 Preset 变化时刷新。

知识库继续位于**能力 → 知识库**。主面板左侧按个人、直属部门和公司展示知识库及真实文件夹，点击知识库名称返回首页。右侧通过“按文件夹 / 全部文件”切换当前目录与库内全部文件，搜索框标明文件名搜索范围，清除筛选保留当前浏览范围。文件菜单提供“在文件夹中显示”，按稳定 ID 读取完整路径，不要求先展开或翻页到所在目录。部门标题显示真实名称，仅同名部门附带稳定 ID。选择知识库或文件夹查看对应资料；点击文件将原始字节交给官方文档预览，面包屑和管理操作保持可见。检索索引未完成或失败不影响原文件查看。窄屏可在资料导航和阅读区之间切换。文件名称、格式和处理状态由服务端筛选并分页。右侧工具栏集中搜索、上传和创建操作；左侧仅展示文件夹，右侧列表先列直属子文件夹再列文件，阅读器返回该列表。刷新丢弃旧预览并重新校验当前权限；明确失权清理库内资料，网络故障保留已选文件并提示重试。切换库或文档取消旧请求、清除旧阅读状态，浏览不改变任务或草稿。被引用的知识库详情仍区分**资料**和**检索**；检索命中打开索引片段，其中的**查看原文件**打开文档预览。只有服务端确认的管理者能看到上传、Markdown 新建或修改、网页导入、重建、移动、删除和文件夹管理。上传菜单区分沿用标准处理的普通文件和明确标注**无 OCR**的文本型 PDF 提取；扫描 PDF 使用普通上传。重复上传不改变已有文档的解析方式。Markdown 编辑检查最新文档时间戳，失败保存保留编辑器；删除表示后台任务已提交。文件夹只整理库内资料，不授予访问权。

原文件查看使用官方无需 Session 的 `document.preview` 工厂：PDF 展示页面，Excel 展示只读工作簿，Word 或 PowerPoint 使用官方 Office 转 PDF 能力。缺失字体提示仍可见。Markdown、文本、HTML 和图片与侧栏文档使用相同的官方渲染器。经过认证的产品桥接仅接受资源 ID 并返回有大小限制的字节，不提供上游 URL 或凭据；每次读取和转换均重新校验权限。检索继续使用 WeKnora 索引片段。原文件不存在、响应超限或转换失败时显示本地化错误，不回退为索引正文。传输名额已满时提示稍后重试，读取期间版本变化时提示重新预览；两者保留知识库访问资格并允许用户主动重试。

个人分组提供**新建个人知识库**，服务端将归属固定为已认证员工。文件夹树旁的**新建文件夹**固定创建顶层目录，每个文件夹菜单提供新建子文件夹、上传、重命名和删除。右侧新建默认使用当前目录；“全部文件”视图提示默认保存到知识库首页。创建后选择新目录；删除当前目录回到上级，删除其他目录不改变当前位置。上级选择、面包屑和移动选择显示完整路径。同级名称唯一，仅无资料和子文件夹的目录可以删除。上传完成、取消或失败均保留已选目标目录。Markdown 和网页新建在打开编辑器时固定目标，保存后保留当前位置；位置未确认时保留编辑，提示先检查全部文件再决定是否重新创建。共享库仅提供获准的读取和原文件下载，服务端授予管理权后才展示管理操作。预览失败后，文件菜单仍提供**下载原文件**；**用系统应用打开**仅在桌面展示。预览通过主进程临时传输句柄读取有大小限制的二进制分块，成功、失败或取消后均关闭句柄，不再通过 IPC 传递整个 Base64 文件。

文件树和资料列表仅显示本地化处理状态，不展示解析引擎的原始诊断。

单文件管理操作和上传入口收到明确失权结果时，清除当前库的目录、文件预览和管理弹窗，取消在途操作并停止后续上传恢复请求；网络或组织服务故障保留阅读位置，重新处理和停止处理的重试沿用原操作编号。切换知识库取消在途操作，旧库的迟到结果不改变新库。

检索来源、原文件预览或下载收到明确失权结果时，清除检索摘要及阅读器并取消其在途请求；保留查询文字，重新检索时再检查权限。组织服务临时故障保留检索结果和阅读器，允许重试失败的读取；旧阅读器的迟到结果不影响后续检索。

上传支持一次选择多个文件，在独立上传列表中确认后逐项上传；每项显示待上传、上传中、已上传或具体失败原因。已上传不等于解析完成，资料列表继续显示后台处理状态。部分失败不阻止其余文件上传，重试仅发送可重试的失败项，支持单项重试和移除。关闭上传列表取消当前请求，返回后通过**查看上传列表**恢复本次桌面运行中保留的全部选项，固定原文件夹、解析方式和操作编号。成功项确认后释放，取消和失权停止后续上传；移除不撤销远端已提交内容。文件名可见，路径和凭据仅留在主进程。

管理者可选择当前页文件后批量移动、删除或重新处理；选择本页不包含文件夹、删除中的文件或其他页。切换目录、翻页或改变筛选清空选择。批量移动固定每个文件的原目录和版本；首次提交后锁定目标。确认弹窗逐项展示服务端回执，删除与处理回执仅表示任务已提交，关闭后列表继续显示后台进度。部分失败保留原请求编号与内容，仅重试可重试的未成功项，不重复提交已确认项；冲突保留提示，关闭后刷新检查。失权立即停止后续请求，离开知识库取消在途请求。处理中资料不能重复提交处理任务，可先按状态筛选失败文件再批量重新处理。

删除个人知识库保留当前浏览的知识库。只有删除当前库才从最新目录选择替代库；删除失败保留确认弹窗和浏览位置。

文件夹分支在展开时读取服务端一页。当前位置按文件夹 ID 独立读取路径，目录树翻页不会改变显示位置或创建目标。上级与移动选择器独立分页浏览，支持根目录、上级和子目录选择；路径读取失败时阻止提交，不重置到根目录。文档处理轮询只刷新资料；文件夹写入和显式刷新更新目录元数据，不扫描整个知识库。Markdown 编辑器从同一详情响应加载标题、正文及冲突检查时间戳。

阅读页持续显示文件的检索处理状态。文件因处理完成、失败或取消而离开当前筛选结果时，独立读取已授权元数据并保留原文件阅读位置，不重新下载原文件；核验结束后才开始下一轮状态轮询。明确失权清除阅读内容；组织服务或网络故障保留阅读位置并显示错误，处理中的文件继续检查状态。失败和取消提示说明检索不可用及可执行的下一步，不显示解析器内部诊断。

编辑冲突保留草稿，并阻止携带旧元数据继续保存。**读取最新版本**独立展示服务端当前内容；检查后点击**确认，继续编辑当前草稿**采用新时间戳，不替换草稿，保存仍需主动点击。每次重新读取先清除上次读取结果；读取失败保留草稿及冲突状态，不能确认旧结果。再次发生并发修改时须重新检查。

新建知识库、Markdown、网页导入及文件夹保存遇到网络故障、超时或服务端结果未确认时，保留内容、目标及请求编号并暂时锁定表单。**重试原保存**复用同一内容与编号，服务端已提交时返回原结果，避免重复创建。明确拒绝或编辑冲突仍允许修正；无法确认的外部结果须先检查资料列表，不自动创建另一份资源。关闭编辑器取消在途请求，不撤销可能已经完成的写入。

右侧列表独立查询文件夹分页，按文件夹在前、文件在后组合为每页 20 行。总数包含全部直属文件夹和筛选后的文件，左侧翻页不改变右侧结果。筛选和全部资料视图只显示文件。上传失败保留请求编号、解析方式和目标目录；**重试上传**复用主进程持有的原文件，**结束重试**释放文件选择并刷新资料列表，不取消可能已经提交的服务端写入。离开页面或切换知识库只取消在途请求，返回后从主进程恢复待确认上传；恢复失败时禁止新上传，刷新后重试。原文件内容变化时，需结束重试再重新选择；切换账号或关闭桌面清理保留记录。

文件夹重命名提交读取时的 `updatedAt` 和稳定请求编号。回执丢失后的重试返回原结果，不重复写入；他人已改名时返回 `KNOWLEDGE_FOLDER_CHANGED`，保留输入并提示关闭编辑、刷新后重试。

对话中的 `knowledge_search` 和 `knowledge_read` 行通过官方 keyed toolview 展示已记录来源。展开结果显示文件名、知识库名称和原样位置；点击来源读取已授权片段，**查看原文件**通过官方预览打开对应文档。来源元数据随 Session 重放，无需查询目录。打开来源重新检查当前权限；失败结果或不支持的元数据保留已记录输出，不生成来源链接。阅读原文件时保留位置提示；官方无 Session 预览 API 不支持自动定位页码或表格单元格。

技能、套件和连接器的卡片与详情将仅所有者可用的资源操作放在**更多操作**菜单，依次为**修改**、**提交共享审核**，再分隔展示红色**删除**。审核状态替代重复提交入口。共享确认说明审核通过后供公司使用，审核期间本人仍可使用。删除确认显示资源名称并保留对话历史，存在已发布版本时须先下架。技能和连接器的管理入口固定在弹窗底部，不随正文滚动。写入失败保留弹窗和资源供重试，删除成功后移除资源，不改变当前任务或草稿。

反馈弹窗的内容编辑区接受粘贴或拖入的 PNG、JPEG、WebP 截图，最多四张，每张不超过 5 MB。图片缩略图、文件名和移除按钮位于内容框内，文字与图片一起提交；混合粘贴保留剪贴板中的纯文本。没有独立上传区或设备上报操作。提交失败或取消保留文字、图片和操作 ID 供重试；切换账号清空草稿。关闭弹窗释放预览地址并保留未发送的文件。主进程补充员工和设备信息，反馈不包含对话历史。

桌面左下角**更多 → 检查更新**调用官方原生更新器，发现新版后确认下载，完成后另行确认重启安装；普通浏览器不显示该入口。未配置更新源的版本显示说明和当前版本，不展示检查失败或侧栏重试提醒；真实网络失败可以重试。检查、下载和重启确认均由桌面主进程处理。安装版更新条件见[产品桌面分发](../../../apps/product-desktop/README.md#软件版本更新)。

<a id="model-experience"></a>

知识库资料仍在排队、处理或收尾时，管理者可通过文件的**更多操作 → 停止处理**调用 WeKnora 官方取消接口。成功后显示**已取消**，保留原文件并提供**重新处理**；普通阅读者不显示管理操作。处理中状态提示原件可查看、检索需等待处理完成。失败保留请求编号并显示产品错误，不将超时当作取消成功，也不暴露解析器内部路径。该能力仅供界面使用，不向模型或 Host 开放。

## 模型体验

### 产品导航

#### 模型看到的内容

扩展只负责渲染能力导航和目录面板，不增加 `ToolDefinition`、提示词片段或其他面向模型的行为。

#### Token 影响

不会增加模型 token。

#### KV Cache 影响

不会创建缓存条目；扩展只负责渲染产品能力目录。

## 已知限制与延期工作

<a id="known-limitations-and-deferred-work"></a>

- 能力面板需要 Electron 产品桥和可访问的DeepSeek Harness服务端。
- 不提供离线目录或第二套执行路径。

### 开发备注

<a id="dev-note"></a>

使用仓库标准包构建流程构建此扩展。Desktop Host 在官方 Web profile 上应用本包导出的 `cordis.patch.yml`，装配产品导航并关闭官方账号引导。Host 安装提供产品插件，无需将它加入上游 Web bundle。`harness-actions.ts` 集中对接官方 Session、Workspace、输入框和 Preset 服务，注册入口只连接 slot 和操作。产品 API 调用放在 `packages/deepseek-harness-product/product`。
