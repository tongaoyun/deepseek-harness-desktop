# 企业产品界面

<a id="summary"></a>
## 概述

从左侧“扩展能力”使用专家、技能、连接器和资料库，通过设置提交反馈或检查软件更新。专家和技能页面由内建产品模块提供，随桌面统一更新；打开设置时暂停内嵌页面，避免重复挂载。

四类资源页面共用[页面标题规范](DESIGN.md#布局与操作)，统一正文宽度、标题、说明和窗口控件避让空间；空状态、读取提示及键盘焦点遵循[状态规范](DESIGN.md#状态与焦点)。保存、提交、资料选择、删除、上传及归档按钮预留普通、进度与重试文案的宽度，等待时保留自身及相邻控件的位置；资料编辑弹窗为错误和关闭受阻提示预留固定高度，窄窗口长提示可滚动阅读。成员管理的错误提示可用键盘聚焦、滚动，重试期间保留提示和列表；读取成功后，已消失的提示或重试按钮将焦点交给成员搜索框或当前页签。

## 企业登录

左下角常驻员工入口：未登录时显示“未登录”，登录后显示员工名称；检查失败明确标记状态不可用。整行点击展开菜单，未登录时首项为“登录”，打开统一整窗钉钉登录界面，等待时可取消，失败可重试。首次读取确认未登录、登录失效或收到授权要求时，自动打开同一登录界面，点击登录后才启动浏览器授权；同次失效不重复弹出，取消后可从员工菜单重新打开，成功登录后恢复下一次失效提示。资料库、连接器、技能和专家页面在员工身份确认后挂载，未登录时不展示页面内登录提示或目录读取错误；身份核实失败保留错误供重试，不当作未登录。同一员工续期保留页面节点；身份失效或切换员工时卸载旧页面并清除内容和草稿，重新验证后挂载。登录状态通过主进程读取和订阅，员工凭据不进入界面。

桌面首次启动在工作区加载前展示整页授权等待；工作区内的产品能力共用相同布局的整窗登录界面，复用原生 Modal 的键盘和焦点管理，不重载会话或修改草稿。对话输入框不常驻登录提醒，主动选择资料库时才请求登录。授权等待由侧栏管理，切换资源页保留等待；取消登录或卸载侧栏会取消请求，迟到结果不更新界面。授权等待复用启动页的展示样式，浏览器操作说明保持原位，失败提示预留当前语言的空间；重试保留错误、原按钮和键盘焦点，只有登录按钮报告忙碌并阻止重复请求。员工菜单提供设置、反馈和软件更新，未登录时也可使用；菜单在员工栏上方对齐，再次点击可关闭。关闭菜单或从菜单打开的授权、反馈窗口后，焦点回到员工入口；从资源页打开授权时，原生弹窗优先返回原入口，关闭时原入口已移除，则将丢失的焦点交给员工入口；窄窗口侧栏收起时返回原资源页，对话操作返回原生输入框。

<a id="connectors"></a>
## 连接器

同一连接器更新版本时保留详情和能力浏览状态；已打开的本机配置固定其编辑版本，保存时校验版本，避免将草稿应用到新的连接目标。

市场展示已发布的公司连接器，我的展示本人可管理的连接器；草稿和待审核内容只在我的。目录支持搜索和六类筛选：业务系统、电商平台、协同办公、数据分析、开发运维、其他。分类固定显示，未知分类归入“其他”；切换市场／我的时重置为全部分类。分类描述系统用途，不拆分 ERP 等系统内部模块，也不影响工具发现和审批。连接器和资料库目录的读取错误随界面语言更新，不重复请求。连接器后台刷新失败保留已确认的卡片、页签、搜索、部分连接失败提示及焦点，错误区预留空间，支持键盘滚动阅读，重试不重建列表；组织权限或主进程身份不可用时收起目录，重新读取成功后恢复。

创建支持表单和 MCP JSON，可填写分类和简介；所有者可修改、提交发布或删除。第三方账号连接与设备私密配置独立管理，所需操作在详情提供；协议和认证参数仅在配置流程展示，连接失败在实际使用时说明原因。操作回执必须匹配资源 ID 和版本；失败保留输入，切换员工取消旧请求。删除及提交确认在请求发起前锁定重复操作和关闭，等待及失败重试保留错误、按钮焦点与外观，核对回执后清除错误。服务端确认删除但本机清理失败时，目录移除该项并显示重启确认提示，不再提供重复删除；移除的确认按钮将焦点交给“关闭”。关闭详情、编辑器或删除确认时，若原卡片已被刷新移除或重新分组，失去目标的焦点返回目录搜索框；保留搜索草稿、选区及用户主动转移的焦点，不滚动页面。管理操作的错误随界面语言更新。

STDIO 从 MCP JSON 导入或已有连接器编辑时，未修改的命令和参数按原值保存，保留多行脚本、CRLF、空参数及路径字符。手动修改命令仍校验引号，并拒绝管道、重定向和变量展开。

私密字段仅在本机已配置、连接目标未改变且字段名匹配时提示“留空保留”，按[主进程规则](../../deepseek-harness-product/desktop/README.md#connectors)识别字段。新字段、更换目标或本机未配置时提示填写；JSON 导入不替换原配置的判断基准。

HTTP 连接器的公司 OAuth 提供方读取失败可独立重试，保留表单及私密输入；关闭编辑器取消读取。已配置的 OAuth 服务未在列表中时保留当前选择，可主动切换为本机配置或其他可用服务；读取结果不自动改变认证方式。编辑、本机配置和 OAuth 提供方的读取重试保留错误、原按钮及键盘焦点，等待时阻止重复点击并保留外观，成功后清除错误；读取成功移除重试入口或底部错误时，仅将其持有的焦点返回服务器类型或本机超时字段，不滚动页面，也不抢占其他控件焦点。请求发起时防止重入，连续触发只读取一次。添加请求头或环境变量行后进入新键名；删除焦点所在行后进入相邻键名或添加入口，焦点在保留行时不转移，保留其余输入及光标、选择范围。表单行标识不进入配置。编辑及设备配置的校验、读取、保存错误和待确认提示随界面语言更新，保留输入和在途请求，不重复读取或保存。

连接器编辑与本机配置在提交按钮上方预留本地化错误及保存中关闭提示空间，失败、重试或尝试关闭不改变窗口或表单可视区域；长错误可滚动并通过键盘阅读，滚动长表单仍可看到；保存等待及失败重试保留当前按钮焦点和错误，核对回执后清除错误。放弃修改确认暂时隐藏并保留表单，聚焦“继续编辑”；取消放弃后恢复原字段、光标及文本选择。粘贴配置按键名更新、优先填充空行；HTTP 请求头不区分大小写，环境变量区分大小写，重复键整次拒绝。保留已有输入控件、焦点及未改变字段的文本选择；读取期间已提交的表单修改使旧粘贴失效，未提交的渲染不影响当前粘贴。保存时保留配置行粘贴、添加、删除及提供方重试按钮的外观，锁定表单操作；仅执行中的按钮报告忙碌，阻止重复提交。私密字段的规则见[产品协议](../../deepseek-harness-product/product/README.md#authentication)。

连接器和资料库管理、添加资料、文件及文件夹菜单在操作禁用时关闭，恢复可用后需重新点击打开；请求等待保留触发按钮的外观和焦点，不能重开菜单；失去管理权限移除对应管理操作，按钮展开状态与实际菜单一致。从菜单打开编辑或确认窗口，关闭后焦点返回仍存在的原操作按钮。

详情按资源 ID 和版本隔离授权与设备配置；版本变化关闭旧配置并取消请求，迟到回执不能更新新版本或带入旧私密输入。保存配置期间关闭按钮、Esc 和遮罩均保留表单，并提示等待保存结果。取消等待不能撤回已完成的保存。

新建、编辑、本机配置保存及授权操作在请求发起时即防止重入，连续触发只发送一次；保存开始后立即保护关闭。账号操作预留连接、重新连接、断开与进度文案的宽度，状态切换保留同一按钮；错误区预留当前语言文案的空间，窄窗口换行，不挤压按钮或推动相邻操作。授权与撤销等待及失败重试保留按钮焦点、原错误和按钮外观，按钮报告忙碌，核对成功回执后清除错误；切换语言不重复请求。授权或本机配置确认后的目录刷新可独立重试，不重复授权、撤销或保存。复核等待保留本机配置入口的焦点和外观，锁定重复打开；失败移除入口时，焦点进入状态重试，用户已移到其他控件时保持原位。本机配置保存后关闭窗口，焦点返回原配置入口；刷新失败则进入状态重试按钮，重试成功后返回可用的配置操作。失败释放操作状态，保留可重试的表单及私密输入。

目录搜索包含本地化分类名称，空结果支持清除筛选；清除连接器、工具或资料库目录筛选后，焦点返回当前搜索框。业务能力支持按名称、说明、工具原名搜索及只读／写入筛选，每次展开 20 项，可展开完整说明；保留已有行与展开状态，最后一批展开后将“显示更多”的键盘焦点移至首个新增工具。浏览不会调用业务工具。刷新保留已有列表和详情的搜索、展开状态，提示未连上的连接器名称，成功后清除提示；详情刷新失败及重试期间隐藏未确认的工具和配置操作，保留工具浏览控件；确认成功后恢复搜索、读写筛选、展开说明和已加载数量。同一版本的能力清空时隐藏并保留浏览控件，能力恢复后沿用搜索、选区、读写筛选、列表展开和已加载数量；隐藏控件不接受键盘焦点。刷新提交详情前捕获焦点；移除配置控件时，其焦点进入重试或恢复后的授权、本机配置按钮；移除工具条目或分页入口时，焦点返回能力搜索框，能力清空时进入能力标题，刷新失败时进入重试按钮。不滚动或抢占保留控件的焦点。连接器与资料库目录重试保留错误区和原操作按钮，等待时阻止重复点击并保留外观，成功后清除错误；首次读取失败后的重试不重新插入首屏占位。身份读取或目录重试成功、刷新移除卡片或错误隐藏列表时，已移除控件的焦点返回当前目录区域，不滚动页面；保留控件及用户主动转移的焦点不变。切换员工或目录类型清除对应旧错误及内容。

资源页面通过产品装配中的统一身份检查控制访问，登录操作由[企业登录](#employee-sign-in)入口负责。

## 资料库

“我的资料”旁的“+”提供上传文件和新建文件夹，目标固定为个人根目录；可编辑文件夹在鼠标悬停或键盘聚焦时显示同一菜单，点击选中后移开鼠标不会保留按钮，目标固定为该文件夹。菜单打开时保持入口可见，不改变目录展开状态；文件操作菜单因写入等待关闭后，需主动重新打开。文件和文件夹可从目录树或文件列表拖到同库的可编辑目录或根目录；文件列表中的文件夹整行接收拖入，包括日期、大小和操作区域，同一行内移动保留目标高亮，旧目标的离开事件不清除新目标高亮；自身、子目录、同位置、跨库、只读目标和外部拖入均不执行移动。移动沿用版本校验，等待时阻止重复写入，失败保留原文件，成功后刷新目录；刷新失败只重试读取。

资料库采用左侧导航、右侧文件列表：左侧提供新建、最近、我的资料及共享空间，目录树复用原生 `sidebar.files.tree` Factory，分组下及每层目录缩进 18px，选中背景覆盖整行，按需展开和分页读取；右侧提供搜索、上传及通过对话生成，文件固定使用列表展示。窄窗口将导航置于文件区上方，主要操作保持可用。最近展示跨库文件，我的资料与共享空间按目录展示文件和文件夹，顶部路径可返回上级目录，下方图标和标题显示当前目录。可编辑文件夹可通过侧栏悬停菜单重命名、移动或删除，也可点击当前目录标题重命名，沿用原生弹窗和版本校验；只读目录不展示写入入口。删除或移动当前目录及其上级目录后返回有效的上级目录。新建文件夹直接命名，可编辑的个人或共享目录内默认保存到当前目录，未选中可编辑目录时默认我的资料，成功后展示实际保存目录并清除搜索；目录树同步更新。点击已展开但未选中的目录会进入该目录，点击当前目录可折叠；共享空间与我的资料均直接展示目录树，名称进入根目录；可管理共享空间的根目录及文件夹提供“+”，用于上传和新建文件夹。团队目录分页结束后，失去入口的焦点返回所属团队。当前可管理目录直接上传，最近先选择目标。个人资料仅本人可读可管理。新建共享空间在保存前可直接关闭、取消或按 Esc 退出，保存期间阻止关闭；已有内容编辑保留放弃修改确认。普通员工可新建共享空间，默认仅创建者可见；顶部“成员”或空间菜单打开同一成员窗口，所有者在同一窗口选择员工、部门或全公司并直接添加，已有授权列表保持可见，可原位修改权限或移除成员；写入进度仅标在实际操作入口，其他操作和授权对象页签保留外观及节点，并阻止冲突操作；成员列表预留键盘焦点框的滚动边距，保持内容对齐；重复选择当前权限只关闭菜单，不写入或刷新；成员窗口复用原生 Modal、搜索框、分段控件、按钮和权限菜单，直接显示可滚动的选择列表，切换页码和查询保留已选对象，转让所有权收在窗口的更多菜单中。成员写入遇到版本冲突后锁定提交，成功重新读取权限、成员和候选对象后，由用户明确重试；读取期间保留已选对象与原控件，成功后清除错误并恢复丢失的焦点。成员窗口读取成功即同步名称和权限，不等待成员列表；权限变化及失败重试保留搜索词、输入节点和文本选区，所有者搜索候选对象时保留完整授权列表，其他成员按关键词查询名单。成员操作或重试入口消失时，焦点返回可见的搜索框；部门和全公司页签下返回当前分类，不聚焦隐藏控件，也不抢占用户已转移的焦点。关闭只退出窗口，不回写初始信息或触发重复读取。资料库元数据采用更高版本，同版本下先前发出的目录或最近文件请求不能覆盖期间新确认的权限；列表失败保留已确认状态；文件行、搜索词及仍有效的焦点不变。成员分为所有者、可编辑和仅查看；所有者管理成员、资料库和所有权，可编辑成员管理文件。目录树同步当前目录、最近文件操作及成员读取已确认的名称和员工权限，同版本权限变化也会保留；首次目录尚未返回时同样保留已确认信息。确认前发起的目录请求不能覆盖该变更，随后主动读取可重新核实同版本权限。同步保留目录节点和展开状态。权限元数据读取成功后立即更新当前目录、写入入口及已缓存目录；后续文件列表或路径读取失败仍保留新权限、原文件和错误重试。所有读取和写入由服务端重新授权。“通过对话生成”复用原生新会话入口，向已有草稿追加文件制作需求，用户确认发送后生成实际文件，再显式保存到资料库。

上传弹窗提供拖放区域、选择文件和选择文件夹，文件夹上传保留层级；选择后确认上传。新建文件夹只填写名称，目标由操作入口确定。上传、创建文件夹、重命名、移动及删除使用原生弹窗，编辑保留草稿、文本选区和并发版本。保存、删除、上传及归档的写入错误在底部预留区域显示，长错误可滚动阅读；错误、重试及保存中关闭提示不推动输入框或按钮。下载失败也在预览底部显示，重试保留原生阅读器、正文滚动位置及按钮焦点。下载、选文件和归档准备重试成功移除错误时，若焦点仍在错误文本，则返回对应下载、选文件或取消按钮；用户已聚焦其他控件时保持原位。后台刷新保留当前目录的列表及原错误；切换保存目录时清除不属于目标目录的旧内容，读取失败不恢复原目录。保存成功与后续读取失败分别处理。关闭弹窗优先返回仍有效的原入口；后台刷新或写入后刷新移除入口时，丢失的焦点返回当前搜索框，保留用户主动转移的焦点。

保存位置选择器打开深层搜索目录失败时，重试继续读取该目录的实际路径，不刷新原列表代替导航；等待期间保留错误、原按钮及焦点，成功后进入目标目录。

创建文件夹时，同一提交内容沿用重试标识；仅修改名称首尾空白不会重复创建。版本冲突后锁定再次写入，重新读取仅标记读取入口忙碌，保存和删除按钮保持锁定及原外观。关闭等待提示在写入结束后消失；新一轮保存清除上一轮的关闭提示，只有本轮再次尝试关闭时才显示。连接器编辑与本机配置沿用同一规则。

原生产物归档区分文件准备与保存进度。准备和准备重试仅标记文件准备区域及重试按钮忙碌，保存按钮保持锁定；实际写入后才标记保存按钮忙碌。

对话资料选择窗预留固定读取反馈区，长错误可聚焦并滚动阅读，不挤动文件列表；重试成功后，已消失错误区的焦点返回搜索框，其他有效控件上的焦点保持原位。

选择文件夹保留根目录、子目录和空目录；移除待上传文件夹同时移除其中的待上传内容。上传选文件期间可关闭并取消准备；开始写入后等待结果。部分上传成功时保留未确认文件，重试沿用原标识；可移除失效或不需要的选择，再选择文件，其他待上传项保持不变。选文件与上传错误独立展示，重新选择文件不清除未解决的上传错误。移除聚焦项后返回选文件按钮，不抢占其他控件的焦点；准备和上传期间阻止移除。取消文件选择保留已有错误和列表。上传及资料编辑弹窗重新激活时恢复可用的请求生命周期，关闭后取消旧请求，迟到结果不更新界面。对话资料选择等待员工身份核实后读取目录，未登录时使用统一登录入口，核实失败可在原窗口重试。

资料库立即采用已确认的员工身份事件，取消旧员工的读取和编辑；同一员工续期保留目录、草稿和选区。身份核实失败可原位重试，等待时保留错误及焦点、阻止重复读取；成功后将失去入口的焦点交给目录搜索框。

目录读取错误预留固定反馈空间，失败、重试和恢复不挤动列表。未知目录使用静态列表占位，目录树不插入加载行；返回已访问目录时先显示本页已确认内容并后台重新授权读取，写入或刷新后不复用旧页。首页读取与写入错误独立展示，互不遮挡或清除。长错误可通过键盘滚动；重试保留错误节点和焦点，读取期间阻止重复刷新；恢复后仅将丢失的焦点交给搜索框。重复点击当前目录保留列表、控件及焦点。首页或选择器返回同一目录并清除搜索时，保留当前列表与错误直至读回成功，不回退到较旧缓存；固定根目录沿用最新确认的名称与权限，不恢复窗口初始信息。同目录搜索和翻页复用已确认路径，刷新时重新核对目录名称及父级。最近、个人目录和共享目录分别展示各自已确认的内容，切换范围不复用其他范围的结果；个人根目录仅在无查询且缓存仍有效时先展示缓存，再重新读取。切换保留搜索框和查询，读取失败不显示其他资料库的文件。搜索、最近文件中的文件夹按实际父级生成路径；路径读取失败保留原列表和错误；此前发出的目录刷新回包不能清除或覆盖新错误，资料选择窗重试继续原文件夹导航。切换搜索后忽略旧路径回包。页数收缩时取得有效页后再替换列表。空状态区分资料库列表、文件列表和目标文件夹。放弃修改的确认期间隐藏保存操作，继续编辑保留原输入和选区。

打开文件或切换目录时取消尚在准备的移动窗口，迟到结果不打开窗口或显示旧错误。移动预检采用已确认的资料库版本并同步名称和权限，权限失效时保留文件和搜索状态、移除写入入口，旧列表回包不能恢复已失效的权限。移动窗口可直接取消目录选择，不触发草稿确认；原目录和文件夹自身不能作为保存目标。写入期间保留目录、搜索、分页和按钮节点，锁定目标选择；失败后可调整目标或重试，成功后的目录读取失败只重试读取。

对话加号菜单中的“资料库”使用“最近／我的资料／共享空间”页签与文件表格，支持搜索、文件夹导航和跨目录多选，底部显示已选数量并统一确认；各页签保留搜索词，重新聚焦搜索框时恢复该页签的文字选区，切换不抢占原生页签焦点；只提供文件引用，不展示管理操作。同目录搜索和翻页保留最新确认的列表与错误，读取成功后更新，不恢复较早查询的缓存；不同目录的内容分别保存。资料库文件、目录及成员搜索最多输入 180 个字符。每次最多选择 20 个文件、总大小不超过 100 MB；超限时在底部提示，保留原选择，调整选择后清除提示。所选文件交给原生附件卡片、上传及重试流程；读取附件期间锁定目录导航、搜索、页签和文件选择，取消未完成的文件夹路径导航，保留原控件及外观，仍可取消。添加失败后恢复选择操作，在底部预留区域显示错误；重试保留所选文件、目录、选区、滚动位置和按钮焦点。预览使用原生预览 Factory 和 Office 转换；原生产物的“保存到资料库”操作显式选择目标后归档，长文件名在窗口内换行。附件准备、预览和文件选择共用资料库请求入口；取消会释放已打开及迟到的文件资源，保留对话草稿和已有附件。准备文件失败保留窗口及取消按钮的位置，重试成功后焦点留在窗口内；提交归档后锁定目标选择，等待写入结果；失败后须在原位置重试，改选位置时提示关闭后重新保存，重试沿用原标识。切换员工清除选择并取消旧请求，同一员工续期保留操作。文件引用成功后清除选择器的登录请求意图，后续身份失效由统一登录入口处理。普通对话和模型输出不会自动上传。

<a id="tasks-and-submissions"></a>
## 任务与提交

资料库、技能、专家和专家团的创建入口与原生自动化一致：由原生新会话能力选择或创建空白会话，在已有草稿后追加创建需求，导航和失败提示交给原生能力处理。连接器的创建、导入与发布审核复用各自模块。产品页保留原生对话、输入框、任务和审批，不替换原生执行页面。

## 反馈与更新

反馈入口要求员工身份；未登录时复用统一钉钉授权，成功后打开编辑器，取消授权不会再自动打开。登录失效时关闭反馈窗口并清空草稿、取消提交，忽略迟到回执；同一员工续期及关闭后重新打开保留草稿。附件校验和提交错误随界面语言更新，切换语言不重发反馈、不改变重试标识。删除图片保留其余预览，焦点返回反馈正文并保留光标与文本选择。粘贴文字和截图时使用文本框原生选区替换，光标停在插入内容之后。发送按钮预留普通与进度文案宽度，反馈结果预留本地化提示空间；错误、重试和回执切换不挤动表单。发送期间锁定附件操作并保留按钮外观；发送等待及失败重试保留按钮焦点和错误，核对回执后清除错误。成功时若焦点仍在提交按钮，则回到正文；用户已移到其他控件时保留当前位置。

检查更新复用原生 `DesktopUpdateBridge.open()`，由主进程展示状态和错误。

<a id="model-experience"></a>
## 模型体验

### 企业能力

#### 模型看到的内容

本包不直接组装模型输入；连接器复用原生 MCP，选中的资料文件通过 `ConversationController.createDrafts` 交给原生附件和 Session 记录。

#### Token 影响

协议和界面本身不增加模型 Token。

#### KV Cache 影响

不管理模型缓存；工具及附件内容由原生模型请求组装处理。

<a id="known-limitations-and-deferred-work"></a>

- 企业服务需要有效员工身份及可访问的组织服务；第三方专家和技能插件使用其自身的管理入口。
