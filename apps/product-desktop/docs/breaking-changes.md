# 产品破坏性变更

连接器目录移除未使用的 `availabilityStatus` 派生字段；界面直接根据服务状态、设备配置和第三方账号状态展示。内部目录接口只保留分页和按 ID 查询，不保留全量读取接口或旧构造器。

## 移除自建技能和专家套件

自建技能、专家套件的目录、创建修改、导入、制品下载、安装和审核接口已删除。产品桌面预装 Agency Agents 与 Skills Manager，使用官方插件、Agent、Skill Provider 和 Session。它们是第三方插件，固定版本随产品构建交付；企业连接器、知识库、钉钉登录、反馈和软件更新保留。

不转换旧产品协议、缓存或制品。旧自建套件任务保留官方历史及草稿，但不能继续使用已删除的产品组合，也不能静默换成默认能力。打开任务后使用知识库恢复入口创建替代任务，或直接新建对话；确认新的知识库范围后再发送。

服务端迁移 V64 删除自建内容与设备安装记录表，不删除知识库 ID、WeKnora 文件或官方 Session。连接器机器发布配置改为 `deepseek-harness.connectors.publisher-token`，旧配置键不再读取。对象存储中的历史制品不自动删除。

升级时先部署服务端，再安装新版桌面。验收原生插件可见、技能按需加载、连接器审批、知识库精确范围及旧任务恢复；不再调用 `/api/v1/skills` 或 `/api/v1/expert-kits`。

## 公司原生内容分发

两插件改为随桌面构建的源码分支，插件独立更新及外部反馈入口已移除，统一随软件更新。新桌面启动要求服务端公司内容接口，需先部署服务端 V65；未发布内容时保持空公司目录。个人插件配置和官方 Session 保留，不恢复已移除的产品技能、套件制品及执行协议。详见[公司内容](company-content.md)。

## 公司内容发布工具

原 `apps/product-desktop/scripts/publish-company-content.mjs <目录> --check|--publish` 已移除，改用仓库内完整技能的 `scripts/publish-company-content.mjs`：`check <目录>`、`plan <目录> --out <计划>` 和 `publish <计划> --confirm <摘要>`。默认按本次资源增量合并，保留公司其他内容；修改已有资源先 export，并保留编辑来源摘要。不会继续保留可直接覆盖全目录的旧机器发布命令。Codex／Claude 从同一仓库安装或更新发布技能，无需构建桌面；接入说明见[公司内容](company-content.md#ai-publishing)。服务端接口和桌面同步协议不变。

## 预装插件 1.2.9

专家套件和技能插件基线更新到 1.2.9。技能的启用、导入和重新启用不再覆盖源文件调用权限；仅限用户调用的技能不会进入模型可用目录。非法调用声明继续阻断调用。公司内容同步、固定工作区加载及统一软件更新方式保留。

## 连接器入口收敛

移除额外预装的 MCP 连接器市场及本机连接管理插件，左侧“连接器”恢复公司目录、授权和原有创建管理流程。插件专用存储接口、构建配置和依赖一并移除，不提供旧插件配置迁移；公司连接器继续使用官方 MCP 客户端和审批，原有授权、个人连接器及 Session 历史保留。

## 连接器状态与故障隔离

连接器的“已连接”展示和筛选改为“已配置”，不再以账号凭据有效推断服务已连通。详情移除重复的授权、认证方式和作用域展示；OAuth 操作改称连接或断开账号。服务端保留原始服务状态。连接器随 Host 产品插件加载，普通对话和子 Agent 共用官方 MCP 连接；不再在新建对话时查询目录、建连或发现工具。单个 MCP 启动故障只禁用对应连接器，不阻塞普通对话和其他连接器；新增或变更配置、重试启动失败的连接器需要重新加载产品插件或重启桌面。目录身份校验失败仍明确中止，不能绕过权限检查。
