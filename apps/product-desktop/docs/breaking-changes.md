# 产品破坏性变更

## 选择性吸纳社区修复

技能不再将含中文等非 ASCII 字符的声明名截断成英文名称；这类条目仍可查看，但不再向模型注册。请将 `SKILL.md` 的 `name` 改为英文小写字母、数字和连字符，目录名可以保留中文。损坏或丢失文件的已登记技能可撤销启用权限，重复停用保持成功；文件修复后需要明确重新启用。技能页面请求保留反向代理路径前缀。

专家宿主文案仅在语言偏好明确为 `zh` 或 `zh-*` 时使用中文，未选择时默认英文；需要中文可在设置中选择。历史会话内容不改写。选择性移植的来源提交记在两个模块的 `upstream.json` 中；未引入独立插件更新或侧栏开关。

## 移除历史插件兼容

专家委派只使用当前 Harness `startActivation` 和子 Agent 注册点，移除旧 `start`、`persona/toolFilter` 能力标志与客户端全局 `current` 会话适配。技能只读取当前 Session、Workspace 和 Web 启动字段，删除独立插件更新类型和未使用的目录身份接口。个人专家设置拒绝无效名单和条目，不再过滤后静默保存。两个模块开启未使用变量和参数检查，移除废弃焦点管理、筛选和重复展示函数。

技能仓库 `repositories.json` 改为 version 2，安装位置、归档 SHA-256、文件摘要和确认状态必须完整；不再接受字符串身份、无位置记录、Git commit 缓存回退或同名技能重关联。策略文件不再自动补齐新增来源；回收站缺少来源时拒绝恢复，不猜测全局目录。移除 OpenClaw 的旧 `.clawdbot` 目录扫描。旧状态文件原样保留并明确报错，需检查后重新配置；不迁移或自动删除技能文件，不改变官方 Session 历史。

## 专家团公司发布

专家团可从“我的”提交发布，控制中心在“专家套件 → 专家团”审核；通过后进入市场。团队定义和全部成员说明一起保存为 `teams/<标识>.json`，不接受仅引用发布者本机专家的内容。公司团队只读，可复制到个人目录；启用团队时同时启用其成员。旧会话继续读取原公司内容版本，不因市场更新替换成员说明。沿用现有公司内容接口和存储，无需数据库迁移；先更新服务端，再更新桌面。

## 企业连接器分类

连接器分类统一为业务系统（`business-systems`）、电商平台（`ecommerce-platforms`）、协同办公（`collaboration`）、数据分析（`data-analysis`）、开发运维（`development-operations`）、其他（`other`）。旧分类不再作为提交值接受。滚动升级时先将 Nacos 的 `deepseek-harness.nacos-ai.categories` 中旧分类暂设为 `other`，部署服务端 V68 并确认全部副本就绪，再设为新分类（ERP 使用 `business-systems`），最后更新桌面。数据库迁移保留连接器 ID、版本和工具；分类不影响 MCP 调用与审批。

## 连接器工具按需发现

企业 MCP 工具不再全量加入每个会话。模型通过 `connector_search_tools` 搜索业务关键词，匹配项才进入该会话的原生工具列表；不要求用户在界面逐项启用。技能和专家说明明确指定工具时，使用 `connectorId`＋`toolNames` 精确加载；与 `query`／`queryVariants`／`limit` 互斥，全部引用有效才加载，不匹配替代工具。搜索结果包含可供引用的连接器 ID、工具原名和版本；用法见[运行时说明](../../../packages/deepseek-harness-product/runtime/README.md#技能与专家中的精确引用)。READ／WRITE 与官方审批规则保持不变；个人新建连接器也使用同一发现流程。

搜索不再因连接器名称或英文词内片段而命中工具，按工具原名和说明中的业务词排序。模型可提供最多 4 组同义或翻译表达 `queryVariants`，与主查询共用结果上限。只写系统名称的旧关键词需改为具体操作；已记录的工具选择和精确引用不重新排名。

新会话及子 Agent 独立发现，刷新不会扩大全量工具可见范围。已发现工具按版本和定义哈希固定并随官方 Session 日志恢复；定义变更需新建对话，旧历史保留。旧会话若成功调用过企业工具但缺少选择记录，明确阻止继续执行，不推测或补绑新定义。无企业工具调用的历史可继续使用。没有旧发现协议或缓存的兼容分支。

搜索默认单次最多 8 项、单会话最多 64 项，完整结果最多 32768 字节；可以通过产品运行时 `connectorDiscovery` 配置调整。超限、撤销、目录故障及损坏记录均明确报错。此改动只涉及产品运行时与装配配置，不修改官方 Agent 执行循环。

## 专家来源收敛

连接器、技能和专家套件目录统一为“市场／我的”。市场只展示审核发布的公司内容；个人草稿和待审核连接器只在“我的”，本人已发布连接器在两处均可见。技能的本机、项目、发现技能和回收站入口移入“我的”，个人专家团也在“我的”管理。“提交共享”统一为“提交发布”，审核通过后全公司可用。仅调整目录与操作文案，无需迁移内容、任务或本机文件。

专家套件目录仅保留“市场”和“我的”，不再分发社区预置专家、名称翻译映射或预置专家团。默认目录为空；个人专家由本人创建或导入，共享专家经发布后由服务端同步。旧预置专家引用保留在历史记录中，但不能继续调用；请创建或导入所需内容后重新选择，不自动替换为其他专家。个人专家团内容保持原文，移除 `builtin` 字段。服务端不再预留社区专家文件名，实际资源归属、摘要、重名检查和会话固定版本保持不变。

公司技能发布改为解析 YAML 1.2，并检查原生调用字段。非字符串简介、损坏或重复字段、未知标签、别名、超过 64 层的嵌套，以及无效或旧拼写的调用声明不再接受。修正 SKILL.md 后以新版本重新发布；不改写既有文件、摘要或任务绑定。专家说明格式不变。

公司内容包拒绝同一父目录的大小写别名，例如 `Assets/a.txt` 与 `assets/b.txt`，避免在 Mac、Windows 上产生不同的落盘结果。发布前统一目录拼写；不改写已绑定任务的原文件或摘要，损坏内容仍需显式恢复。

公司内容提交、审核回执和状态查询只返回摘要，完整文件仅通过详情读取。内容包在写入缓存前拒绝文件与目录路径冲突；不保留接受冲突路径的旧校验行为。认证 API 拒绝重定向，部署入口必须直接返回 API 响应。

员工可提交原生技能和自定义专家供公司审核，使用新的 `content.submissions.*` 产品接口及服务端 V66；不恢复旧自建制品审核协议。先部署服务端，再更新桌面。

连接器目录移除未使用的 `availabilityStatus` 派生字段；界面直接根据服务状态、设备配置和第三方账号状态展示。内部目录接口只保留分页和按 ID 查询，不保留全量读取接口或旧构造器。

## 公司内容版本与历史查看

公司内容版本绑定失败仅阻止对应任务执行，不中止历史会话加载或移除侧栏条目。已开始且缺少绑定的任务显示明确原因，需要新建对话；历史和草稿保留，不自动补绑到最新内容。

启动恢复隔离单条不可读历史，不再使整个产品运行时加载失败。公司内容固定版本在绑定、恢复和执行前重新核对文件哈希，缓存缺失或损坏明确拒绝执行；保留原文件和任务绑定，不沿用过期的进程内校验结果。

## 移除自建技能和专家套件

自建技能、专家套件的目录、创建修改、导入、制品下载、安装和审核接口已删除。产品桌面预装 Agency Agents 与 Skills Manager，使用官方插件、Agent、Skill Provider 和 Session。它们是第三方插件，固定版本随产品构建交付；企业连接器、知识库、钉钉登录、反馈和软件更新保留。

不转换旧产品协议、缓存或制品。旧自建套件任务保留官方历史及草稿，但不能继续使用已删除的产品组合，也不能静默换成默认能力。打开任务后使用知识库恢复入口创建替代任务，或直接新建对话；确认新的知识库范围后再发送。

服务端迁移 V64 删除自建内容与设备安装记录表，不删除知识库 ID、WeKnora 文件或官方 Session。连接器机器发布配置改为 `deepseek-harness.connectors.publisher-token`，旧配置键不再读取。对象存储中的历史制品不自动删除。

升级时先部署服务端，再安装新版桌面。验收原生插件可见、技能按需加载、连接器审批、知识库精确范围及旧任务恢复；不再调用 `/api/v1/skills` 或 `/api/v1/expert-kits`。

## 公司原生内容分发

两插件改为随桌面构建的源码分支，插件独立更新及外部反馈入口已移除，统一随软件更新。新桌面启动要求服务端公司内容接口，需先部署服务端 V65；未发布内容时保持空公司目录。个人插件配置和官方 Session 保留，不恢复已移除的产品技能、套件制品及执行协议。详见[公司内容](company-content.md)。

## 公司内容自动同步与会话绑定

公司内容改为启动后台检查、进入专家套件或技能页自动检查，默认成功检查间隔 60 秒，无需重启工作区。内容更新只影响目录和新会话；旧会话、子会话及重启恢复使用原版本。同步失败保留本地目录，不再因公司目录网络故障退出工作区。

新版以按员工保存的 Session 绑定记录固定版本，不根据当前目录推测旧任务使用过的内容。升级前已经执行且没有绑定记录的任务不能继续执行，请新建对话；官方历史和草稿不删除。损坏记录与丢失内容也不会自动重建或切换版本。

## 公司内容发布工具

原 `apps/product-desktop/scripts/publish-company-content.mjs <目录> --check|--publish` 已移除，改用仓库内完整技能的 `scripts/publish-company-content.mjs`：`check <目录>`、`plan <目录> --out <计划>` 和 `publish <计划> --confirm <摘要>`。默认按本次资源增量合并，保留公司其他内容；修改已有资源先 export，并保留编辑来源摘要。不会继续保留可直接覆盖全目录的旧机器发布命令。Codex／Claude 从同一仓库安装或更新发布技能，无需构建桌面；接入说明见[公司内容](company-content.md#ai-publishing)。服务端接口和桌面同步协议不变。

## 预装插件 1.2.9

专家套件和技能插件基线更新到 1.2.9。技能的启用、导入和重新启用不再覆盖源文件调用权限；仅限用户调用的技能不会进入模型可用目录。非法调用声明继续阻断调用。公司内容同步、固定工作区加载及统一软件更新方式保留。

## 连接器入口收敛

移除额外预装的 MCP 连接器市场及本机连接管理插件，左侧“连接器”恢复公司目录、授权和原有创建管理流程。插件专用存储接口、构建配置和依赖一并移除，不提供旧插件配置迁移；公司连接器继续使用官方 MCP 客户端和审批，原有授权、个人连接器及 Session 历史保留。

## 连接器状态与故障隔离

连接器的“已连接”展示和筛选改为“已配置”，不再以账号凭据有效推断服务已连通。详情移除重复的授权、认证方式和作用域展示；OAuth 操作改称连接或断开账号。服务端保留原始服务状态。连接器随 Host 产品插件加载，普通对话和子 Agent 共用官方 MCP 连接；不再在新建对话时查询目录、建连或发现工具。单个 MCP 启动故障只禁用对应连接器，不阻塞普通对话和其他连接器；新增或变更配置、重试启动失败的连接器需要重新加载产品插件或重启桌面。目录身份校验失败仍明确中止，不能绕过权限检查。

## 公司内容独立发布

控制中心专家套件与技能拆为独立目录和员工提交审核，连接器目录与审核合并为一个导航入口。管理员发布接口仅接受单项 `{resourceKey, sha256, files, expectedSha256}`，不再接受完整目录或客户端版本号。AI 发布工具采用单项计划，不读取旧计划；原生文件不需要 `release.json`，导出编辑来源保存到 `.publication.json`。请从仓库更新发布技能；桌面内容分发与固定会话不受影响。

## 连接器加载恢复

连接器目录加载失败不再阻止普通聊天；相关工具保持不可用。连接器页面的刷新按钮会重新加载工具，无需重启桌面。未声明工具拒绝执行，WRITE 审批和实时权限校验保持不变。

## 专家套件与技能内建

专家套件与技能由桌面固定装配，左侧直接打开，移除设置重复页、独立插件安装声明和旧设置备份导入。模块代码随桌面更新；个人内容继续由官方 Settings 和本机技能目录保存，Session 历史及内容版本绑定不变。旧的自行安装社区插件配置不参与产品装配，请在插件管理中移除后使用内建入口；原内容文件不会被删除。
