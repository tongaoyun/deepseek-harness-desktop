# 任务执行与结果展示

## 对话与过程

桌面对话统一由 Agent 执行。用户提交目标后，模型按需调用已启用的技能、专家套件、连接器和本地工具；输入框不提供 Agent / Plan 切换。

一次对话包含多个执行轮次。提交后立即显示用户消息与轻量「正在处理」状态；运行环境首次初始化在后台进行，不在对话中展示「启动 Agent」。模型中间文本、命令、文件和连接器活动按实际事件流更新，不为普通问答编造计划或步骤。

桌面对话与在线桌面承接的 IM 任务在每一轮使用同一份执行约定：理解本轮意图，必要时澄清，按复杂度拆解，调用实际工具，检查结果并交付。检查与诊断不自动授权修改；追加修改沿用上下文，并先确认当前成果状态。失败时根据原因调整，不盲目重复可能已成功的外部写入。执行约定用于指导模型，不替代工具检查，也不保证任意模型都能可靠完成所有任务。

模型已经输出部分文字后报错，或达到输出上限，仍属于未完成轮次，不标记成功。桌面保留部分正文、实际文件与执行记录，另附失败信息；后续队列暂停，不因存在文字就继续自动执行。

## 新任务与上下文

本机 SQLite 完整保存任务消息和执行记录，不按任务数或对话条数自动删除。侧栏初次加载最近 200 个任务，可继续加载更早任务；搜索查询持久化历史而不仅是已加载列表。分页排除已加载的任务 ID，删除或更新前面的记录不会使后续记录因位置偏移而遗漏。定时任务中的执行记录链接可直接按 ID 读取数据库，不依赖侧栏已加载范围。

对话正文继续按 60 条分页展示。持久化、界面分页与模型上下文预算相互独立；保存失败明确显示，不通过丢弃旧消息掩盖错误。网页预览使用浏览器存储，容量不足、历史 JSON 损坏或结构异常会报错；不会在下次保存时把原始历史覆盖为空列表。

「桌面设置 → 附件存储」显示粘贴文件与图片的缓存占用，可手动确认清理未引用缓存。检查覆盖所有账号的本地任务、归档、草稿、队列与定时计划；保留最近 24 小时的缓存。读取引用失败时不开始清理，不删除工作目录原文件、成果或符号链接。删除缓存不可撤销，不提供后台自动清理。

重建会话时，在最近对话前保留有界的任务恢复摘录：最初需求、较早用户约束、近期追加要求、最新未完成步骤和实际文件状态。摘录来自历史原文，不由模型编造，不构成新的执行授权；较新要求优先。未保留的对话与被截断原文明确标注，不保证无限长度任务的所有决定都被保留；恢复总预算仍约 24000 字符。

新任务以 Qoder Work 式的单一输入入口组织岗位工作，专家套件提供完整岗位方案，技能提供具体工作方法；不按写作、设计或编程拆成独立执行引擎。

- 「＋」统一提供文件/图片入口，以及专家套件、技能、连接器、知识库四类可搜索内容。空分类提供管理入口，不生成占位能力。
- 在正文任意空白边界输入 `/` 搜索套件、技能和命令，输入 `@` 搜索知识库、已就绪连接器与当前工作目录。方向键选择，Enter/Tab 确认，Esc 关闭；确认保留前后正文。
- 一次显式指定一个套件、技能或套件命令，以可移除标签显示；内部保留规范调用标识，执行通过 `selectedExtension` 加载实际能力。移除标签后回到通用执行，切换或移除会重建会话并带回对话上下文。其他已启用技能仍可按任务需要自动匹配。
- 未选择知识库、且套件未声明知识库范围时，可按需检索当前员工有权访问的知识库，不要求先手动选库。显式选择与套件声明合并去重后构成本轮范围，最多 32 个引用；套件明确声明空数组且用户未添加引用时保持空范围。员工身份与服务端访问范围始终生效。
- 连接器不指定时使用已启用且就绪的目录；显式选中后，本轮只装配所选连接器。未就绪连接器不可选；已选连接器失效时阻止发送并给出处理提示。该范围不限制内置文件等非连接器工具。
- 目录菜单支持选择文件夹、查看和移除当前目录、从最近 8 个工作目录重新选择。显示完整路径提示，失效路径需重新选择。
- 聊天支持通过「＋ → 添加文件」、原生拖拽和粘贴添加附件。macOS Finder 的文件 URL、Windows 资源管理器的文件列表在用户粘贴时读取，不后台监听剪贴板；普通文字和纯文本路径仍作为文字插入。复制的文件夹作为工作目录，文件作为附件，不自动发送任务。Windows 原生文件列表实现仍需 Windows 桌面实机验收。
- 应用提供剪贴板文件二进制时，PNG/JPEG 图片单张最多 10 MB，其他文件单个最多 25 MiB；超过时提示改用拖拽或文件选择。原生文件路径无需复制二进制，实际读取继续遵守各文件工具限制。网页预览不提供原生剪贴板文件读取和附件存储能力。
- 每次最多 16 个附件，其中最多 4 张图片。三种添加方式共用去重、数量检查、导入状态和任务上下文校验，不静默截断。导入中禁止重复添加和发送；切换任务后丢弃迟到结果，不把附件加入新任务。文件二进制批量导入逐项反馈失败，保留成功项；合并后超出数量上限时保留原选择并提示。运行中的轮次仍仅接受文字排队，附件需在本轮结束后添加。
- 本机图片附件显示缩略图，文件和图片可打开现有预览面板。运行时图片最长边 2560 像素、总计不超过 400 万像素，超出需裁剪或缩小；Host 不静默截掉多余图片。
- 新任务和已有任务分别保存未发送的正文、指定能力、附件位置、目录、知识库、连接器和模型。点击新任务会恢复未发送的新任务草稿，切换或重新打开应用不会清空。每名员工最多保留最近 100 份非空草稿；只保存引用与元数据，不把附件二进制或连接器凭据放进草稿。
- 侧栏切换区仅显示「任务」「频道」，不提供独立归档页。任务菜单仍可归档；已归档任务不出现在最近列表，可通过搜索找到并移出归档，原有记录不删除。
- 通过小胤创建定时任务、技能或专家套件时，三个入口各自保存正文、附件、目录与模型，不共用普通新任务草稿。首次进入填入对应模板，再次进入恢复该类型草稿，切换时同步创建类型，不重复拼接、不自动发送；提交仅清理当前类型的已发送草稿。
- 附件恢复重新授权其原目录；文件移动或目录不可用时明确提示，不伪装恢复成功。粘贴图片保存在应用数据目录 `pasted-images`，其他二进制粘贴文件保存在 `pasted-files`，使用内容摘要避免同名文件互相覆盖，不随退出清除；原生复制文件仅保存原路径引用。
- 执行会话重建时，除可见对话外，携带实际附件、成果和变更的目录 ID、相对路径及最新文件状态；失败或停止轮次也保留文件引用与未完成状态，不把错误消息冒充完成结果。文件摘要最多 30 项、约 7000 字符，在约 24000 字符的总回放预算内优先保留；超出范围明确提示。历史引用不等于文件仍然存在，续轮需核实授权与磁盘现状。

- 进度说明使用 Agent 实际发送的中间文本，直接排在对话中，不加重复标题与大块底色；不生成或伪装模型内部思维过程。
- 连续工具事件按实际动作展示「已读取文件 · 已编辑文件 · 已运行命令」等摘要；执行中、失败和已停止分别标明，不把未成功操作纳入完成摘要。同类动作合并，展开后显示准确操作次数与每次明细；操作次数不冒充文件数量。摘要只依据工具类型，不从命令或助手文字猜测已编辑文件、已搜索网页或已验证结果。
- 普通工具组和明细默认收起，点击可展开命令、文件、连接器和协作任务详情；工具开始、完成和追加下一工具只更新摘要，不自动反复折叠。错误与待确认请求自动展开。
- 错误、警告和待确认操作单独展示，不被成功步骤折叠隐藏。任务失败或取消时，未完成步骤结束运行状态。
- 当前活动只在本轮过程区显示，不在输入框上方重复铺设状态横栏。运行中显示实际活动和耗时；完成或停止后，过程默认收起，可展开检查。失败详情默认展开。
- 正在生成的文本持续可见；最终回复到达后才对过程中的同一条文本去重。结束后保留执行耗时、最终回复和真实产物。
- 待确认请求到达时自动展开过程；用户收起过程或操作明细后，确认按钮仍单独保留。提交期间禁用重复点击，失败在原位置说明原因并允许重试；已提交的决定保持禁用，等待真实执行结果。停止中及结束后不能再提交确认。过程重复展开不播放进场动画。
- 整轮完成时，过程折叠与最终回复在同一次渲染中切换，不先展示展开状态再收起；正文使用同一已加载的 Markdown 组件，不经过纯文本占位。自动跟随在浏览器绘制前完成，不做逐次平滑滚动；手动回到底部仍支持平滑滚动。
- 停止期间忽略迟到的正文、新工具调用和会话状态；已开始工具的结束回执仍可补齐成果、文件改动与步骤状态，不改变“正在停止”。退出应用后，执行进程在标准输入关闭时立即中止当前任务并清理服务，不等待任务自然结束，也不启动尚未执行的排队请求。
- 重启恢复的未完成任务标记 `XY-INTERRUPTED`，侧栏显示“已中断”、过程摘要显示“上次运行已中断”；保留最近保存的内容与成果，不把应用离线时间显示为执行耗时。追加修改先检查实际文件，再继续未完成工作。
- 在底部阅读时随输出和内容尺寸变化跟随；向上查看历史后，新输出不强制拉回底部，可点击向下按钮回到最新消息。对话不使用 `content-visibility` 占位，避免 WebKit 在审核分栏变化时丢失正文。
- 长会话首次展示最近 60 条消息，按需向前加载，每次 60 条；保留原消息索引及加载前阅读位置，不删减持久化历史。千条消息回归验证首屏渲染数量和切换任务后的窗口重置。
- 收起运行中的过程只隐藏历史步骤，最新进度说明与正文仍保持可见和流式更新，不因下一工具开始而消失；展开后不重复正文。警告、错误和失败操作即使收起过程也保留，存在详情时默认展开。
- 多步骤任务要求模型先简述工作方向，并在关键结果、阶段转换和阻碍出现时更新说明；简单问答不强行播报。说明来自实际模型输出，不通过定时器制造进度，也不将单次工具成功描述为整项任务验证通过。
- 完成回复提供复制与「编辑后重发」；后者将原问题和附件放回输入框，不直接重复执行。代码块提供独立复制按钮和语言标识。复制失败显示可重试提示，不因正文以「正在」开头而隐藏操作。
- 历史回复、过程说明和未改变的工具记录复用渲染结果，避免每个文本增量和耗时更新都重新解析整个历史 Markdown。
- 手动发送新问题回到最新轮次；后台追加消息不打断历史阅读。Esc 已由输入建议或上层交互处理时，不再顺带关闭文件预览。

## 停止与继续

「停止本轮」中断当前执行，不删除对话。点击后显示「正在停止」并禁用重复点击；后台确认结束后显示「已停止」，保留已收到的文本、步骤、文件与变更，仍可输入新要求继续。

- 任务在本地准备和首次初始化前登记取消状态；初始化期间同样可停止。
- macOS/Linux 的每个 Host 使用独立进程组；停止时主动关闭 SDK，打断当前模型轮次并清理它管理的工具子进程，不等待当前任务自然完成。5 秒内未结束则强制终止该任务进程组。Windows 使用进程树终止。
- 停止不回滚已经完成的文件写入、外部操作或主动脱离任务进程组的服务。
- 取消请求之后忽略迟到的流式通知，完成响应不能将本轮改回成功；自动重试间隙收到停止时，不再开启下一次尝试。取消不是模型故障，不显示错误编号，也不触发模型自动重试。
- 停止后保留对话记录，下一轮重建执行会话并带回已有上下文；待处理队列保持暂停，由用户决定是否继续。

## 运行中追加要求

任务运行中仍可输入文字，Enter 或「加入队列」将要求加入该任务的待处理列表；Shift+Enter 换行，中文输入法确认不触发发送。

- 当前轮成功完成后，按加入顺序逐条执行，沿用原任务的对话、工作目录和知识库选择；模型仍可用时保留原任务选择。每轮重新生成能力快照；模型或能力发生变化时重建执行会话，并带入可见对话与成果上下文。
- 切换到其他任务不改变后台队列所属任务，也不清空当前页面未发送的草稿。
- 支持编辑、移除、暂停和继续。准备执行期间若消息被编辑、删除或暂停，该次准备不会发送过期内容。
- 执行失败、工作目录不可用或手动停止时，后续消息暂停，需手动继续。正在执行的消息不再属于待处理列表。
- 队列按员工存储于本机。重启恢复时默认暂停；存储失败时明确报错并暂停自动执行，不提示保存成功。
- 每个任务最多排队 20 条，每条最多 20000 字符。目前仅支持文字排队，附件需在当前轮完成后另行添加。
- 同时仅调度一个队列续轮，可与现有交互任务并行；已有 3 个桌面任务运行时等待空闲。归档任务不调度队列，删除任务同时清理其队列。

队列是打开应用期间的对话续轮，不是云端定时任务；关闭应用后不继续执行，也不保证跨进程崩溃的事务级消息交付。重启后可在任务历史中检查中断轮次并重试。

## 配置变更与续轮

- 桌面每 60 秒同步模型配置与能力目录，回到窗口时也会刷新；并发刷新合并，离开账号后丢弃迟到响应。模型配置未变化时保持对象稳定，不重置输入或反复加载目录。
- 首次连接失败会自动重试；后台刷新失败暂用上次模型配置并显示提示，恢复后清除提示，不中断已经运行的任务。
- 模型被移除后，下一轮使用当前模型列表中的首个可用模型；列表为空时保留输入并提示配置模型，不凭空请求默认模型。排队任务也检查当前模型列表。
- 每轮按当前已安装且启用的技能、套件和当前连接器配置执行，不沿用历史快照中的旧地址或旧版本。历史快照只描述那一轮的能力；安装更新需要用户实际执行安装，目录有新版本不等于自动升级。
- 手动选择的连接器不可用时阻止发送并保留输入；自动工具集合排除已删除、停用或缺少必填配置的连接器。凭据和默认请求参数来自当前配置，历史记录不保存凭据值。
- 运行中的轮次保持提交时的配置。下一轮发生模型或能力变化时重建会话并回放可见上下文，不重复执行已完成操作。停用或移除排队任务明确指定的技能/套件后，队列暂停，不静默换成普通任务。
- 安装后的本机清单刷新优先于尚未结束的后台旧请求，避免旧结果覆盖升级或停用状态。连接器页面的“重新检测”执行真实握手与工具发现；成功结果不代表服务持续在线。

## 进度保存与异常恢复

- 开始、完成、失败和停止写入任务历史；执行中的正文、工具状态与成果每 2 秒检查一次，只保存发生变化的运行任务，不按每个输出片段写数据库。页面退出会尝试保存最新快照，但强制结束进程仍可能丢失最近一个周期的进度。
- 同一员工、同一任务的保存和删除按调用顺序执行，提交保存时固定快照，避免旧运行状态覆盖最终状态或延迟保存复活已删除任务。一次写入失败不会永久阻断后续保存；周期保存失败在桌面显示提示。
- 重启将残留运行任务标记为中断，保留最近已保存的部分正文、步骤、变更与成果；清空旧运行会话 ID，下一轮使用文件状态与可见对话恢复。恢复不自动重复执行工具，需先核对实际结果。
- 控制面接收桌面真实结果上报，主动停止使用 `CANCELED`，不计为 `FAILED`。管理端「任务与自动化 → 桌面记录」支持查询、结果/日期筛选和导出；记录仅表示已收到的事件，不代表全量对话同步、实时在线任务或远程执行权限。上报不可达时不阻塞本地工作，控制面可能暂时缺少记录。

## 文件交付

工具返回的文件显示名称、类型、创建/修改/就绪状态、大小（工具提供时）和实际路径。点击文件名或「打开」进入本地预览；文件夹按钮在系统文件管理器定位。

- Office 工具的结构化结果自动登记产物。通过代码、Shell 或应用生成的其他成果，在检查后调用 `local_files_publish(rootId, path)`，使用已授权目录 ID 与相对路径登记；同一路径在本轮重复登记只更新一张卡片。
- 登记检查文件实际存在、可读、为非空普通文件，支持文档、表格、图片及其他文件格式；目录、失效路径和空文件报错，不生成成功卡片。登记不创建、修改或上传文件，也不表示内容正确、公式正确或测试通过。
- 登记的文件显示「已就绪」，不虚构创建、修改、差异或撤销基线。已有的文件变更记录仍可审核；Shell 改动没有受支持的变更回执时不提供自动撤销。
- 交付前按成果类型检查：代码测试/构建，表格数据与公式，文档内容与可用的版面预览。最终回复说明实际完成的检查及未验证项，不用成功卡片代替质量验收。
- IM 回传仅收集主任务中成功的 Office 产物和显式登记的文件，使用原生目录 ID 定位。只读工具返回的路径、失败结果和子任务临时输出不直接回传；子任务成果由主任务检查后登记。

对话中的文件以紧凑浅灰行展示，不增加大尺寸交付面板；类型图标保留颜色区分，文件数量摘要供辅助技术读取。步骤说明、队列和输入框遵循 [视觉规范](brand.md)。

只有工具实际报告的文件才生成产物卡片；模型回复中提到文件名不等于文件已生成。浏览器开发页不能代替桌面原生文件能力。

## 成果文件恢复

成果读取失败区分目录授权失效、原路径不存在、系统权限不足和其他读取错误，提供重新读取、重新授权原目录或选择文件打开。路径不存在只能说明原位置不可用，不断言文件已删除。重新选择的文件在预览标签中打开，不修改历史成果路径，不继承原文件的审核基线和撤销记录；取消选择、关闭预览或切换文件后的迟到结果不改变当前预览。

## 保存失败恢复

任务最终保存和运行中检查点使用统一的保存状态。失败后在工作区顶部持续显示「尚未保存」及原因，切换页面或其他任务保存成功不会清除此提示。重试保存该任务最新的内存内容，不重跑任务；只有对应保存成功或明确删除任务后才移除其提示，旧请求的迟到结果不能清除新失败。

草稿写入失败时保留输入，阻止新建或切换对话覆盖当前草稿；修复存储问题后可重试。页面退出事件申请未保存提示，但不保证拦截原生强制退出或系统终止，因此仍明确提示保存成功前不要退出应用。内存保留不等于已持久保存，也不能代替备份。

## 文件审核与撤销

- 文件改动卡片使用白底、细边框，包含本轮文件数量、逐文件路径和状态。完整行数可用时显示总计；部分统计缺失时提示进入审核，不把缺失数量当成零。
- 「审核」打开本卡片全部可审查文件，不受折叠列表的前三项限制；点击路径单独打开。同一路径再次打开会替换审核基线并重新读取，切换任务清空预览，不混用其他轮次或任务的文件状态。
- 审核以本轮第一次写入前的备份与当前磁盘内容比较，行数根据实际差异重新计算。可展开未修改上下文，切换文件视图，刷新磁盘内容。备份失效时仍可查看当前文件并显示原因；截断内容不冒充完整差异。界面最多渲染 5000 行，超限有提示。
- 「撤销」先确认，逐文件验证本轮最终 SHA-256 与磁盘现状、初始备份 SHA-256。支持带校验记录的新建、修改和复制普通文件，单文件不超过 32 MiB；连续写入保留首次基线和最后一次内容校验，不累加中间改动数。
- 新建文件移入恢复目录；修改文件恢复初始备份。撤销前的版本保存在工作目录 `.xiaoyin-backups/undo/<唯一标识>/`，文件夹按钮可以定位恢复副本。不会删除整轮对话，也不回滚命令执行或外部系统操作。
- 有桌面任务运行时禁用撤销。后续被修改的文件、失效备份、缺少校验记录、移动和删除操作不自动覆盖恢复；逐文件报告错误，已成功文件仍保留成功状态，可处理冲突后重试剩余项。
- 撤销结果保存到任务历史；下一轮重建执行会话并携带撤销状态，以实际磁盘内容为准。文件改动卡片中的审核/撤销与独立的 Office 产物交付行分开组织；Office 产物行不提供撤销按钮。

## IM 执行与送达

云端定时结果通知与本机 IM 对话分别处理；轮询、重试与运行边界见 [定时任务与 IM](schedules-and-im.md)。旧 IM 状态不能覆盖更新的桌面执行，迟到同步不替换本机刚变更的任务列表。

- 本地 IM 区分准备、执行和结果发送阶段，持久保存待发送正文、文件清单及已确认发送成功项。任务执行开始前写入阶段记录；执行异常或重启发现中断执行时暂停，不能自动重跑可能已经产生变更的任务。
- 结果发送失败只重试尚未成功的正文或文件，不再次调用 Agent，已确认送达的文件不重复发送。发送阶段最多尝试 3 次；同一会话在重试期间保持串行，不让新任务覆盖旧任务待交付文件。
- 部分文件失败时仍尝试发送其他文件，桌面 IM 会话保留原答案，并显示失败原因与待发送文件名。全部送达后才标记完成。用尽尝试次数后暂停，员工可检查已有成果并明确要求补发；不宣称外部发送具备严格的“恰好一次”保证，发送成功但确认或本地落盘失败的窗口仍可能导致重复送达。
- 本地状态保存失败会报错；后续独立保存可以恢复，不让一次磁盘故障永久阻断整条保存队列。

## Office 成果验证

Office 验证流程为：检测 `office_engine_status` → 用 `office_xlsx_recalculate` 重算表格副本或 `office_document_export_pdf` 导出 PDF → 检查返回的结构问题 → 使用 `office_pdf_page` 查看需要核验的页面。新文件自动进入成果与改动卡片，源文件不被标记为已修改；只读任务不注册转换与重算工具。依赖与边界见 [成果结构与页面检查](architecture.md#成果结构与页面检查)。

真实模型验收使用独立临时工作目录与合成销售 CSV：读取资料和含空列的旧成果 → 内置工具生成公式表格 → 检查并交付 → 同一任务追加修改数量、保留公式、新增复核表 → 打开更新后的成果。测试预期初始数量/金额为 9/167.5，修改后为 12/287.5；在模型之外读取实际 XLSX 核对数值、公式、工作表及 CSV 原件，不能仅以最终回答作为通过依据。

## IM 附件读取

- 文件附件保存在已授权 IM 工作目录的 `im-attachments/<内容标识>/`，原件保留；DOCX、XLSX、PPTX、PDF、UTF-8 TXT/CSV/Markdown 的完整文本解析结果另存为 `extracted.json`。同名不同内容使用不同目录。
- 首轮只注入最多 24000 个 Unicode 字符的预览，标明已读/总字节数、文件位置和下一读取偏移。模型使用现有 `local_files_read_text` 按 `nextOffset` 继续，无需额外阅读引擎；分页保留 UTF-8 字符边界，不丢失中文或表情字符。
- 完整解析缓存最多 20 MiB；超限、格式不支持或解析失败明确说明，仍提供原文件位置供其他工具检查。文档解析保留各解析器的格式与资源约束，不承诺任何大小或格式都能处理。文本解析不是 OCR、公式重算或版面验收，不把预览或解析成功当成完整验证。

## 验证

操作截图按可见区域读取，初始展示最多 6 张卡片，更多截图由用户展开。每张独立加载和重试，离开视区或切换任务时释放图片 URL 与观察器；查看大图时保留当前图片，关闭后恢复原按钮焦点。截图原件仍保留在本机附件存储中，释放预览内存不删除原件。

macOS 桌面观察返回控件标签、标识、坐标和可读取的实际文本值；密码输入框不返回值。遍历设置时间、深度和数量边界，超出时标记观察不完整。Unicode 输入明确清除继承的修饰键标志，组合键在工具中单独指定。截图与输入仍需要系统辅助功能和屏幕录制权限，默认不替用户修改系统授权。

`harness-host/native/computer-use-fixture.swift` 是独立的临时验收窗口，手动编译启动后运行 `node harness-host/scripts/acceptance-macos-computer-use.mjs`。脚本经真实 Mac 桥接执行观察、点击、中文输入、Command+A 替换、按钮结果读取和提前取消检查，每步只接受验收窗口为当前前台；不调用真实业务应用，也不等同于模型自主执行复杂应用流程。

`harness-host/scripts/acceptance-macos-agent.mjs` 使用真实模型、生产 Cordis 配置和桌面工具，自动创建独立测试文档与窗口。支持 `complete`（打开、修改、保存、磁盘回读和同会话只读续聊）、`cancel`（真实输入返回后关闭运行时，确认未保存）、`unavailable`（测试路径不能作为文件打开，模型说明失败且不输入）。凭据只通过环境注入，不写入脚本或验收报告；工具回执和实际磁盘内容共同作为依据，不能只看最终回复。

`harness-host/scripts/acceptance-macos-focus.mjs` 使用两个独立测试窗口，验证前台进程变化后不输入到另一个窗口、失败后不能盲目重试，以及旧窗口签名被拒绝。Mac 操作必须先取得成功观察，窗口/显示状态变化或执行失败后重新观察。

macOS 控件观察优先返回当前焦点控件和焦点窗口，再补充其他控件并去重，避免文件选择器的后台列表挤掉路径输入框。按键工具支持 `G`、`L`，可组合 Command+Shift+G 前往路径、Command+L 聚焦地址栏；应用仍需按当前观察判断是否支持快捷键。

`harness-host/scripts/acceptance-macos-textedit.mjs` 是手动运行的真实模型验收：准备程序只创建临时文件并启动 TextEdit，模型通过应用的打开对话框读取目标 txt、修改、保存、关闭后重新打开，再进行同会话只读核对。磁盘实际内容、控件文本与工具回执共同校验，另一个临时文档必须保持不变。运行需环境变量 `DEEPSEEK_API_KEY` 和系统桌面权限，会消耗模型额度并占用前台；脚本不强制退出 TextEdit，以免影响用户文档。

`output/conversation-performance.html` 使用真实聊天组件与 2000 条合成消息，提供 100 次连续切换验收，统计组件提交耗时、渲染消息数、DOM 节点数和页面溢出。此页只供开发服务访问，不写入任务历史。`TaskVisuals.test.tsx` 验证 100 次截图切换后 URL 与观察器释放数量平衡，以及单张失败、迟到回执和键盘关闭；这些是有界压力与资源生命周期检查，不代替整夜运行的进程内存测试。

`App.queue.test.tsx` 覆盖 App 调度中的后台续轮、草稿切换/重启恢复、连接器范围、指定套件及移除后的执行、失败暂停和停止竞争。`TaskComposer.test.tsx` 与 `composerInput.test.ts` 覆盖正文调用、真实知识引用、菜单、截图粘贴与目录选择；`taskDrafts.test.ts` 覆盖草稿隔离和最近目录。`useTaskQueue.test.tsx` 覆盖顺序执行、存储故障、恢复、编辑、归档和并发限制；`executionGroups.test.tsx` 覆盖分组、错误、确认入口及最终回复去重。

`taskRecovery.test.ts` 覆盖恢复期间停止；`useHarnessNotifications.test.tsx` 覆盖停止后忽略迟到事件。原生 Harness 测试覆盖启动前取消登记、任务隔离，以及忽略 TERM 的进程与子进程终止。

`ConversationReview.test.tsx`、`ChatFlow.test.tsx` 覆盖整轮审核、跨轮基线更新、切换任务清理、确认入口、滚动跟随、代码复制、差异展开与部分撤销冲突。`conversationReplay.test.ts` 覆盖撤销后的上下文提示；原生 `local_file_undo` 测试在独立临时目录验证恢复、保留恢复副本、拒绝后续改动和失效备份，不使用用户工作文件执行撤销测试。

`taskDelivery.test.tsx` 在独立临时目录创建和追加修改真实文件，通过 Host 登记结果、桌面事件归并和文件卡片渲染验证交付链路。Host `runtime.test.ts` 检查首轮与续轮均携带执行约定；本地文件测试覆盖登记失败；IM 测试覆盖固定目录 ID 和产物筛选；原生知识库范围测试覆盖未指定、明确空范围、合并去重和数量限制。

`runtime.test.ts` 与 `App.queue.test.tsx` 覆盖部分输出后失败和输出上限；`conversationReplay.test.ts` 覆盖失败/空正文的文件引用、最新状态及回放预算。`im-delivery.test.ts` 使用受控发送器验证只重试发送、重启补发和执行中断不重跑；`im-attachments.test.ts` 使用真实临时 TXT/DOCX 文件验证长文缓存、UTF-8 连续读取、格式不支持和解析失败提示，不向真实钉钉会话发送测试消息。

这些回归使用受控模型响应。模型、搜索、连接器和 Office 生成的端到端验收仍需可达的企业服务和桌面 Runtime，不以界面样例代替真实执行结果。

`office-conversion.test.ts` 在存在 LibreOffice 的环境使用真实临时 DOCX、PPTX、XLSX 验证转换、强制重算、文件哈希与原件保留；无依赖时这些实机用例明确跳过。通用用例覆盖依赖缺失、无输出不报成功、超时、取消以及宏/外部工作簿不自动处理。转换结果的桌面卡片与 IM 文件识别另有事件链路测试，真实 IM 上传仍需联调。

该测试同时通过真实注册工具串联表格创建、含空格读取、重算、追加修改、再次重算及 PDF 导出。`local-documents-plugin.test.ts` 覆盖四种表格写入入口的公式对象、文本不隐式转换、缓存不可伪造及空格数组的无损 JSON；原生 `local_artifacts` 测试覆盖空列位置、自闭合单元格和缺少计算结果的预览。

Office 回归同时校验实际工具返回值经 JSON 往返后完全一致，覆盖 PDF 导出与跨格式结构检查，不仅检查磁盘文件是否存在。macOS 实机测试核对导出后的不同中文字符，防止缺字体时重复占位字符被误判为正常；排版测试核对列宽、换行、打印范围、公式保留和备份可恢复。文本模型无法独立完成页面视觉验收，需图像模型或人工逐页查看。
