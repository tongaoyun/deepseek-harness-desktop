# 任务执行

桌面对话、定时计划和在线桌面承接的 IM 任务共用 Harness Session、工具与结果协议。默认使用 Agent 执行任务；计划模式只检查环境并提交计划，不执行修改。执行约定指导模型澄清、拆解、操作、验证和交付，但授权和完成判断仍以真实工具回执及检查结果为准。

## 输入与能力

- 统一输入框支持文字、文件、图片、目录、套件、技能、连接器和知识库。输入 `/` 搜索套件、技能和命令，输入 `@` 搜索知识库、连接器和工作目录；选择会作为结构化能力传给执行层，不解析展示文本。
- 每个任务最多组合 8 项套件和技能。Capability Resolver 固定制品版本、依赖、连接器及知识范围。缺失或冲突的显式依赖阻止发送；未显式选择的技能仅以受限目录供按需加载，不自动取得额外工具或写权限。
- 连接器仅在显式选择或所选能力声明依赖时装配。知识库未显式指定时，按当前员工权限检索；显式范围和套件声明合并去重，最多 32 项。更改选择会保留对话并重建会话。
- 添加附件可用文件选择、拖放或粘贴；最多 16 个，其中图片最多 4 张。粘贴二进制图片单张上限 10 MiB，其他文件 25 MiB。导入完成前不可发送；当前轮执行中只接受文字排队。文件目录授权和内容校验由原生层执行，网页预览不等于原生文件验收。
- 新任务、现有任务和创建套件/技能/定时计划分别保存草稿。草稿、最近目录及队列按员工隔离存入本机 SQLite；未落盘的草稿有 WebView 应急记录。保存失败保留输入并提示，不假定已持久化。

## 会话与历史

Harness JSONL Session Log 是对话、工具和执行事件的事实源；官方 Persistence 负责读取和恢复，Session Query 提供搜索索引。小胤 SQLite 只保存任务产品索引、摘要、草稿、队列和定时计划，不复制完整会话正文。Host 通过 Session 事件适配器把同一份官方事件源提供给实时视图和历史回放，并注册 `xiaoyin.product` 产品投影供桌面展示成果、文件、来源和结果。

侧栏先加载最近 200 个任务，可继续分页；对话正文每次展示 60 条。搜索合并本地标题/元数据与 Harness 正文结果，中文使用官方 `filterEvents` 字面量扫描，英文使用 FTS5。切换账号或搜索词后丢弃迟到结果。Session 暂不可读时提示恢复失败，不用列表摘要伪造对话。

会话重建携带有界的初始需求、较早约束、近期追加要求、未完成步骤及实际文件引用，总预算约 24000 字符；较新要求优先。文件引用不是文件仍存在的证据，继续前应核对授权和磁盘状态。员工、模型、凭据、能力目录、连接器、知识范围、模式或权限变化时重新初始化 Runtime；执行中轮次保持提交时的快照。

## 过程、停止与队列

模型中间说明、工具调用、文件和连接器活动从真实事件展示；普通问答不编造计划。完成后默认收起过程，警告、错误和待确认操作保持可见。审批提交期间禁止重复点击，停止中及结束后不接受迟到审批。长对话加载更早消息时保持阅读位置，用户向上阅读时新输出不强制滚回底部。

停止会中断当前轮和受管子进程，保留已有正文、文件与操作回执，不回滚外部写入。迟到输出不能把停止改回成功；重启后的运行中任务显示为中断，后续队列暂停，用户核对后决定继续。首次初始化及自动重试间隙也可以停止。

任务运行时可追加文字到该任务队列，每项最多 20000 字符，每任务最多 20 项；支持编辑、移除、暂停和继续。当前轮成功后按序执行；失败、停止、目录失效或能力不可用时暂停。重启默认暂停，保存失败不继续自动执行。员工主动发起的任务可并行，自动续轮同时只调度一个；已有 3 个任务运行时，自动队列和定时计划等待空位。关闭应用后队列不执行。

## 结果与外部操作

Harness 轮次结束与用户目标完成是不同状态。状态只来自官方 `turn/end`、工具结果、Goal、Todo、Present、审批和问题事件。模型正文不改变执行状态；未完成轮次保留成果并暂停自动续轮。文件、公式、知识引用和外部回执仍需核验。

MCP 写操作先在员工及任务隔离的本地 SQLite 登记，再发请求。相同轮次、连接器、工具及参数的成功回执可复用；未获成功回执的操作跨进程阻止盲目重试，用户在「外部操作核对」确认实际结果后再继续。记录不保存原始参数；业务端支持幂等键时应同时使用。Shell、浏览器和其他外部写入同样必须检查实际结果。

执行状态与 IM 送达状态分别记录。发送失败只重试未确认的正文或文件，不重新调用 Agent；网络超时可能造成外部已送达但本地未知，不承诺跨服务恰好一次。详情见[定时任务与 IM](schedules-and-im.md)。

## 文件与验收

只有工具实际报告的文件才显示成果，模型提及路径不构成交付。无显式授权目录时使用 Harness `present` 声明 Session filesystem 的相对路径；有授权目录时使用小胤 `local_files_publish`，由原生层执行目录检查、备份与撤销。投影只保存文件引用，不复制文件内容。

成果面板可内嵌预览图片、PDF、文本、Markdown、HTML 和系统 WebView 支持的媒体。Office 文件由 Harness 官方技能读取、修改和检查，通过 `present` 交付，并使用本机 Office 应用打开；桌面端不再维护第二套 Office 解析器。预览失败区分授权失效、原路径不存在和系统权限；重新选择文件不改写历史成果路径。

文件审核比较本轮首次写入前的备份与当前磁盘内容。撤销先校验本轮最终文件与备份的 SHA-256，保留撤销前副本；后续修改、移动、删除、无校验记录或外部操作不自动撤销。有运行中任务时禁用撤销。保存失败显示持续的「尚未保存」，重试只保存状态，不重跑任务。

发布前运行 `pnpm check`，并按[发布验收](system-readiness.md)在真实桌面、模型及目标服务上核对登录、停止恢复、成果和外部送达。模拟回归、文件存在和最终回复均不能单独证明任务完成。
