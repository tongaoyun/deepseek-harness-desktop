# 技能与专家套件

发布包及任务执行的验证方式见[扩展与任务验收](extension-acceptance.md)。

技能提供一项可复用的工作方法。专家套件面向岗位或团队，将工作场景、执行流程、交付标准、技能、快捷命令和连接器组织为完整工作方案。两者使用同一个 Agent 执行。

## 创建与使用

1. 从侧栏「扩展」分组打开「技能」或「专家套件」。
2. 通过「添加 → 通过小胤创建」描述任务，创建套件时补充适用岗位、工作流程和输出要求。
3. 对话完成后点击「保存为技能 / 专家套件」，确认名称、简介和执行说明。套件可以选择已安装技能和连接器；保存时复制技能与辅助资源，生成岗位指南和 `start` 命令。
4. 点击卡片进入详情页，在顶部选择「在对话中使用」或点击具体命令；也可以在输入框输入 `/` 搜索、用方向键选择、Enter 或 Tab 确认。确认后继续填写需求，再发送。通过「返回列表」或 Esc 回到目录。

显式调用格式：`/skill:<id>`、`/kit:<id>`、`/kit:<id>:<command>`。也可从输入框「＋」选择专家套件或技能，或在正文空白边界输入 `/`。选中后以可移除标签展示，不占用正文；一次显式指定一个能力，其他启用技能仍可自动匹配。菜单只显示已安装且可用的扩展；有更新时使用本机已安装版的命令。后续对话沿用当前选择，切换或移除会保留对话内容并重建执行会话，移除后不再强制使用旧套件。

简介应直接说明适用岗位、能完成的工作和交付结果。详情页展示技能、命令、连接器、知识库和后台工作流；依赖未就绪时可以跳转连接器页面继续配置。

## 本地导入

| 入口 | 支持的内容 |
|---|---|
| 添加 → 上传技能 | 单个 `SKILL.md`，或包含 `SKILL.md` 和辅助文件的 ZIP/tar.gz |
| 上传窗口 → 选择本地文件夹 | 技能目录根部含 `SKILL.md`，保留 scripts、references、assets 等资源 |
| 添加 → 上传套件 | 原生 `.xiaoyin-kit/kit.json`，或 `.claude-plugin/plugin.json` / `.qwen-plugin/plugin.json` / `.qoder-plugin/plugin.json`；也可在窗口内选择文件夹 |

上传窗口支持点击选择或原生拖放，一次选择一个包。选择文件、文件夹或取消选择不会安装；确认「安装」后才进行结构校验与写入。安装失败保留当前选择并显示原因，可以更换文件或重试。安装中禁用重复提交和关闭。

压缩包允许根目录直接包含入口，或用一个顶层文件夹包裹。单独导入 `SKILL.md` 只包含该文件；需要脚本、模板、参考资料时使用目录或压缩包。标准技能无须手写小胤清单，名称和简介从 frontmatter 提取，缺失时补默认元数据。

外部套件 `plugin.json` 必须包含 `name`。支持 `skills`、`commands` 的相对路径或路径数组，默认读取 `skills/`、`commands/`；命令为 Markdown 文件。支持内嵌 `mcpServers`、指向配置文件的路径或根目录 `.mcp.json`，支持 STDIO、HTTP 和 SSE 配置。`${CLAUDE_PLUGIN_ROOT}` / `${QWEN_PLUGIN_ROOT}` / `${QODER_PLUGIN_ROOT}` 在命令和连接器配置中解析为安装目录，命令正文中的 `$ARGUMENTS` 使用任务文本。

套件安装后逐项保存新的个人连接器；已有同 ID 配置不会覆盖。连接器保存失败不撤销套件安装，页面会报告失败项，可在连接器页面手动导入或配置。更新外部套件后请核对保留的连接器配置，特别是指向旧版本目录的启动路径。

兼容范围是技能、Markdown 命令、辅助文件和 MCP 配置转换，不是完整的其他产品插件运行环境。Hooks、自定义 Agents、LSP、OAuth 连接器不会自动迁移；检测到这些声明时明确拒绝转换。依赖的软件、运行时和登录授权仍需在本机准备。企业发布制品保持原生清单格式。

文件最多 32 MiB，展开资源最多 64 MiB、1024 项；文件夹预检限制同样的资源大小和项目数量，不支持符号链接。

## 已安装扩展管理

- 「在聊天中启用」独立于安装和卸载；关闭后不再出现在下一轮的能力快照和 `/` 候选中，原生执行层也不加载。正在执行的轮次不热卸载已加载内容；续聊重新检查当前安装与启用状态。
- 设置保存在设备的扩展 ID 目录，更新版本后保留；没有设置记录时默认启用。
- 技能详情显示实际 SKILL.md；套件详情可逐项打开技能和命令原文、展开 README。
- 文件夹按钮打开实际安装目录。浏览器预览不能读写桌面扩展目录，会显示需要桌面端的提示。
- 「本机」展示本地导入技能；「已安装」包含本地与企业目录安装项。目录排序为推荐顺序或名称，不使用未提供的下载统计与发布时间。

## 定制与分享

- 从已安装扩展详情页选择「定制」，指定保存目录。生成新 ID 的副本，不覆盖原安装；打开新对话并带入副本工作目录。
- 描述调整要求，让小胤修改副本。完成后通过对应上传窗口的「选择本地文件夹」安装。
- 「我的创作」可编辑基本信息和入口说明，保存时保留原有命令、技能和辅助资源；修改资源结构使用定制目录。
- 点击「分享 → 导出为 ZIP 包」分享已安装版本，同事通过对应上传入口安装。原始附带文件会保留，运行安装记录不会导出；个人连接器页面后续填写的配置不会写入分享包。不提供无服务端支持的在线分享链接。
- 通过创作中心提交审核，发布到企业目录。公司套件遵循企业发布与依赖校验规则。
