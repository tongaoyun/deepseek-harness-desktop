# Skill、专家套件与连接器

发布包及任务执行的验证方式见[扩展与任务验收](extension-acceptance.md)。

技能提供一项可复用的工作方法。专家套件面向岗位或团队，将工作场景、执行流程、交付标准、技能、快捷命令和连接器组织为完整工作方案。两者使用同一个 Agent 执行。

官方 Skill 和专家套件的源码、清单与发布流程由 `xiaoyin-extensions` 维护。连接器由服务端目录或员工本机配置提供，知识库由服务端存储和检索；套件只能声明对它们的依赖，不能把连接器或知识内容作为扩展制品发布。

## 创建与使用

1. 从侧栏「扩展」分组打开「技能」或「专家套件」。
2. 通过「添加 → 通过小胤创建」描述任务，创建套件时补充适用岗位、工作流程和输出要求。
3. 对话完成后点击「保存为技能 / 专家套件」，确认名称、简介和执行说明。套件可以选择已安装技能和连接器；保存时复制技能与辅助资源，生成岗位指南和 `start` 命令。
4. 点击卡片查看详情，选择「使用」或具体快捷命令，补充需求后发送。输入框也支持输入 `/` 搜索能力。

显式调用格式：`/skill:<id>`、`/kit:<id>`、`/kit:<id>:<command>`。套件的 `/` 快捷入口只来自 manifest 的 `commands`，每个命令绑定一个 Skill；套件内 Skill 不再伪装成第二套快捷命令。文本只用于输入框展示和检索；实际执行传递结构化 `CapabilitySelection`，Harness 不反向解析文本。从输入框「＋」或 `/` 菜单可组合选择最多 8 项技能与套件，每项可单独移除；后续对话和从当前任务创建的定时计划保留完整 `CapabilitySnapshot`。

组合执行先解析所选能力的精确版本、可信制品、工具依赖、连接器和知识库范围；任何显式依赖缺失都会在 Harness 启动前阻止任务。同名技能的文档或资源不同会提示冲突，需要先定制并区分 ID。菜单仅展示已安装、已启用的扩展。调整选择保留对话并重建执行会话。允许自动调用的其他能力只进入按需技能目录，不自动取得它声明的连接器、知识库或写权限。

简介应直接说明适用岗位、能完成的工作和交付结果。详情页展示技能、命令、连接器和知识库；依赖未就绪时可以跳转连接器页面继续配置。

## 本地导入

| 入口 | 支持的内容 |
|---|---|
| 添加 → 上传技能 | 单个 `SKILL.md`，或包含 `SKILL.md` 和辅助文件的 ZIP/tar.gz |
| 上传窗口 → 选择本地文件夹 | 技能目录根部含 `SKILL.md`，保留 scripts、references、assets 等资源 |
| 添加 → 上传套件 | 原生 `.xiaoyin-kit/kit.json`，或 Qoder `.qoder-plugin/plugin.json`；也可在窗口内选择文件夹 |

上传窗口支持多选文件、文件夹或批量拖放。确认「安装」后逐个校验并安装，每项显示结果；失败不影响其他包，重试只处理失败和待安装项。重复路径自动合并，安装中禁用重复提交和关闭。

压缩包允许根目录直接包含入口，或用一个顶层文件夹包裹。单独导入 `SKILL.md` 只包含该文件；需要脚本、模板、参考资料时使用目录或压缩包。标准技能无须手写小胤清单，名称和简介从 frontmatter 提取，缺失时补默认元数据。

Qoder 套件 `plugin.json` 必须包含 `name`。支持 `skills`、`commands` 的相对路径或路径数组，默认读取 `skills/`、`commands/`；命令为 Markdown 文件。支持内嵌 `mcpServers`、指向配置文件的路径或根目录 `.mcp.json`，支持 STDIO、HTTP 和 SSE 配置。导入时将 `${QODER_PLUGIN_ROOT}` 转为 `${XIAOYIN_EXTENSION_ROOT}`，生成小胤清单和连接器配置，并移除 Qoder 清单。命令正文中的 `$ARGUMENTS` 使用任务文本。

套件优先使用 `displayName` 和 `descriptionZh`，执行 ID 由 `name` 生成；`category` 按来源分类映射到小胤分类，无法识别或未声明时归入「其他」，导入后可自行调整。套件内技能的执行 ID 优先取 frontmatter `name`，`name` 不是合法标识（例如中文展示名）时改用技能所在目录名，两者都不可用才回退为带哈希的标识——这样套件内互相引用的技能 ID 不会在导入时失效。技能优先使用 `displayName`；`name` 是英文标识时，使用正文一级标题作为展示名称。安装、执行和导出只读取小胤原生清单。

套件安装后逐项保存新的个人连接器；连接器 ID 跨套件共享，已有同 ID 配置（公司目录或个人连接器）不会被覆盖，第二个声明同一连接器的套件直接复用已配置和已授权的那份，定制副本也保留原连接器 ID。连接器保存失败不撤销套件安装，上传列表保留该项及失败原因，可在连接器页面手动导入或配置。

导入支持技能、Markdown 命令、辅助文件和 MCP 配置；包含 Hooks、自定义 Agents、LSP 或 OAuth 连接器声明时拒绝导入。依赖的软件、运行时和登录授权需要在本机准备。企业发布制品使用原生清单格式。

文件最多 32 MiB，展开资源最多 64 MiB、1024 项；文件夹预检限制同样的资源大小和项目数量，不支持符号链接。

对话中安装公开仓库技能时，下载上限为 32 MiB，仅安装选中的技能目录及资源。多个候选需明确选择；不支持私有仓库，复杂分支名使用提交 SHA 地址。

## 对话安装

直接描述需要的技能，或提供公开 GitHub 地址。小胤通过 `skills_search` 查询当前企业目录与本机独立技能，通过 `skills_inspect_github` 列出仓库候选；确认后由 `skills_install` 安装。安装结果包含名称、版本和启用状态，下一轮任务加载。计划模式仅开放技能查询。

## HTML 成果

任务生成的 `.html` / `.htm` 文件可在成果面板交互预览，并切换源码或改动对比。支持 2 MiB 以内的 UTF-8 单文件 HTML、内联 CSS / JavaScript 和内嵌图片。

预览通过独立的本机 HTTP 来源和沙箱运行，不能访问桌面接口、父页面或任意本机文件；不开放 fetch/XHR、外部资源加载、嵌套页面和表单提交。依赖 CDN、独立资源文件或服务端的页面需在相应运行环境打开。

## 已安装扩展管理

- 企业市场安装的技能与套件始终跟随控制中心的最新发布：每次目录同步比对内容摘要，有差异时自动下载安装并清理旧内容，页面不展示版本号或更新确认。本地导入和「通过小胤创建」的副本不会被覆盖；某一项取回失败不影响其他能力，下一次同步重试。
- 「在聊天中启用」独立于安装和卸载；关闭后不再出现在下一轮的能力快照和 `/` 候选中，原生执行层也不加载。正在执行的轮次不热卸载已加载内容；续聊重新检查当前安装与启用状态。
- 设置保存在设备的扩展 ID 目录，更新版本后保留；没有设置记录时默认启用。
- 套件详情展示命令、技能、数据连接、知识库和套件说明预览。安装前后的快捷命令都来自 manifest 与 `commands/` 目录；技能列表只用于查看 Skill 原文和依赖，不重复生成命令。点击说明预览可在弹窗阅读全文；关闭弹窗保留列表位置。
- 套件命令会将套件和绑定的 Skill 一起带入对话草稿；套件停用后不能快捷使用。独立 Skill 仍可通过 `/skill:<id>` 单独调用。
- 独立技能在弹窗展示实际 SKILL.md，支持使用、定制、分享和启停；关闭或按 Esc 返回列表。
- 文件夹按钮打开实际安装目录。浏览器预览不能读写桌面扩展目录，会显示需要桌面端的提示。
- 「本机」展示本地导入技能；「已安装」包含本地与企业目录安装项。目录排序为推荐顺序或名称，不使用未提供的下载统计与发布时间。

## 连接器

在「扩展 → 连接器」添加企业或个人 MCP 服务，支持 Streamable HTTP、SSE 和 STDIO。

企业连接器目录必须提供完整配置：HTTP/SSE 包含 `transport`、`url` 和 `authMode`，STDIO 包含 `transport`、`command` 和所需参数。桌面只使用目录当前下发的配置。

- JSON 导入支持单个服务和 `mcpServers`，接受 `type` / `transport`、`args` / `arguments`、`env` / `environment` 字段。显示名称可以使用中文，内部 ID 可自动生成。运行时只读判断以 MCP `tools/list` 返回的 `annotations.readOnlyHint=true` 为准；`destructiveHint=true` 始终按写操作处理。服务端下发的只读标记仅用于目录审核和诊断，不替代运行时注解。
- HTTP/SSE 支持无认证、自定义请求头、OAuth 和员工 Bearer Token。需要 ERP 数据时使用服务端托管的 `erp-mcp` 连接器，不在桌面端转发 ERP Cookie。
- 导入逐项检查并报告保存结果，已有 ID 不会覆盖；失败项可以调整后重试。
- 「已添加」保留停用的个人服务，可编辑配置或删除。停用保留配置，删除同时移除本机凭据。
- 已启用服务在页面打开或配置变化时检测，区分连接中、待配置、待授权、无访问权限、正常和连接失败；展开工具详情可比较声明与实际发现的工具。
- 待授权时可直接重新扫码或更新本机凭据，回到窗口后重新检测。401 与 403 分别显示登录失效和访问受限，不归类为模型认证失败。
- 工具列表完整读取分页。必需工具不存在、被筛选或缺少写入权限时报告缺失；运行时只允许 `readOnlyHint=true` 且 `destructiveHint` 不为 `true` 的工具免写审批。未声明只读、明确声明非只读或声明具有破坏性的工具需要写审批和操作日志，不能并发。

详情页提示缺失的依赖配置。连接检测必须完成 MCP 握手和工具列表读取，不调用业务工具；结果只代表本次检查。授权失败时不会将声明工具误报为缺失。浏览器预览无法检测本机 MCP。正在执行的轮次保留能力快照，不热切换地址、工具或凭据；下一轮会在启动 Harness 前重检连接器并绑定最新的 `ready` 配置。若连接器被服务端下架、停用、撤销权限或变为待授权 / 不可用，任务会在启动前阻断并保留对话，不使用旧地址继续执行。

OAuth 连接器在详情中连接账户，浏览器授权成功后自动启用并检测工具；可查看已授予权限、重新授权、取消或断开账户。令牌只保存在系统钥匙串，按员工、连接器和服务地址隔离；到期时串行刷新，多任务共享有效授权。服务返回 401 时本次请求不重发，下一次请求刷新令牌。

当前 OAuth 使用 MCP 标准发现、动态客户端注册和 PKCE，服务地址须为 HTTPS（本机回调允许 HTTP）。需要预注册客户端、厂商应用或专有登录流程的服务需单独接入。断开会立即移除本机授权，并尝试服务端撤销；服务不提供撤销接口或撤销失败时会提示。安装套件不代表 Figma、Notion、Linear、1688 等服务已获授权。

## 定制与分享

- 套件顶部「编辑」定制整个套件；技能弹窗右下角「自定义修改」定制当前技能。指定保存目录后生成新 ID 的套件副本，保留关联资源，打开新对话并带入目标文件和工作目录。
- 描述调整要求，让小胤修改副本。完成后通过对应上传窗口的「选择本地文件夹」安装。
- 「我的创作」可编辑基本信息和入口说明，保存时保留原有命令、技能和辅助资源；修改资源结构使用定制目录。
- 点击「分享 → 导出为 ZIP 包」分享已安装版本，同事通过对应上传入口安装。原始附带文件会保留，运行安装记录不会导出；个人连接器页面后续填写的配置不会写入分享包。不提供无服务端支持的在线分享链接。
- 通过创作中心提交审核，发布到企业目录。公司套件遵循企业发布与依赖校验规则。
