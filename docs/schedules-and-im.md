# 定时任务与 IM

## 桌面定时任务

定时任务采用本机调度：到点创建一条独立任务对话，复用普通任务的模型、技能、连接器、文件工具与结果交付。桌面页面和对话工具使用同一份员工隔离 SQLite 计划。

- 页面提供「我的定时任务」「执行记录」。右上角提供刷新、通过小胤创建、新建定时任务；蓝色运行提示条内提供保持系统唤醒开关。
- 「通过小胤创建」打开独立的定时任务草稿，仅当该草稿正文为空时填入模板；重复进入恢复已编辑内容，不追加模板、不自动发送。技能、专家套件和普通新任务各自保存草稿，切换不串用正文、附件或模型。
- 计划使用紧凑卡片展示名称、任务内容摘要和可读时间，支持按创建时间或名称排序。点击卡片编辑，左上角开关启停，右上角更多菜单提供立即执行和删除；删除前确认。执行记录可按天／周／月分组，并按任务与状态筛选；打开结果对话后可继续追问或修改。
- 新建弹窗使用任务名称、计划时间、任务内容的单列表单。目录、附件、Auto／模型选择位于任务内容输入框底部；取消不保存，保存校验必填内容、时间和可用模型。弹出菜单支持键盘选择、点击外部关闭，Esc 优先关闭菜单，再关闭弹窗。
- 计划时间支持不重复、固定分钟间隔、每小时、每天、每周多天、每月和五段 Cron 自定义周期。默认每天 09:00；切换间隔默认 30 分钟，每周默认周一至周五，每月默认第 1 天，不重复默认半小时后。日期使用月历，时分既可输入也可分列选择。
- 普通周期按电脑当前系统时区执行，系统时区变化后重新计算周期时间；自定义周期可填写 IANA 时区并固定使用，编辑其他字段不覆盖时区。每月不存在的日期跳过；五段 Cron 不支持“最后一个工作日”等日历表达式，不把此类需求假装保存成功。
- 下一次执行时间由 Croner 计算，查询范围为未来 366 天，日期与星期须同时满足。夏令时缺失的钟点顺延，重复钟点仅安排一次；预览不启动额外定时器。
- Auto 使用执行时桌面当前默认模型，也可为计划指定实际可用模型。指定模型不可用时记录原因并暂停计划，不静默替换模型、不生成无效任务链接；不展示未接入的第三方模型或计费倍率。
- 一次性任务到期后停用，完成后不会再次自动执行；错过的单次任务记录已错过。重新安排须编辑为未来时间并显式恢复。
- 固定间隔按首次保存的时间锚定，轮询不会逐次累积时间偏差。暂停后恢复从当前时间重新安排。
- 工作目录与附件可选。计划保存附件路径，不复制文件；执行时读取当前文件内容并恢复附件所在目录，文件移走或删除会提示失败。任务内容可使用已有技能／套件调用标记。
- 在普通桌面对话中使用 `schedule_list/create/update/pause/resume/delete` 管理相同计划。创建继承当前对话模型、工作目录、附件和已选技能／连接器／知识库上下文；Prompt 必须描述完整任务，不依赖历史对话。编辑保留启停状态和未修改字段；删除需要确认。
- 工具经 Host 本地回环通道、Tauri Event 到达桌面已有存储，不另建执行引擎。只有属于当前登录账号、仍在运行的桌面对话可管理计划；IM 对话暂不提供这条管理链路。收到真实存储回执后才返回成功；桥接超时需先查询列表，不能直接重复创建。
- 仅在原生桌面、员工已登录、模型及执行服务就绪且有并发空位时启动。电脑休眠、关机或小胤退出时不执行；超过一分钟的错过时间只记为 MISSED，不集中补跑。
- macOS 的「保持系统唤醒」阻止空闲自动睡眠，不阻止用户主动睡眠或合盖；退出小胤后释放，每次重新启动默认关闭。Windows 请使用系统电源设置；网页预览不具备原生唤醒能力。
- 每次触发先生成稳定的 `scheduleId + scheduleRunId`，再关联一个普通任务 `taskId` 和 Harness `sessionId`；这些引用分别写入计划记录和轻量任务索引，完整执行事件只保存在 Harness Session Log。结果进入侧栏普通任务列表，不抢走当前编辑中的对话。主动停止记录为 CANCELED，失败或中断暂停后续计划，保留已有成果和任务链接，不重放可能已经产生的操作。
- 执行前缺少必要目录或能力时记录“未启动”原因，不提供尚未创建的任务链接。暂停／删除只影响后续计划；停止当前执行请打开对应任务点击停止。
- 计划按员工与服务地址隔离保存在本机 SQLite，最多 100 个计划、每个保留最近 30 次记录。调度租约避免多窗口重复执行；存储损坏或写入失败时停止调度，不清空原数据。
- 调度器异常后保留错误并停止自动轮询执行。点击「重新检查并恢复」检查存储与执行状态；未就绪或检查仍失败时保持暂停，成功后才恢复轮询。不会自动恢复用户主动暂停或执行失败后已停用的计划。
- 本机结果暂不自动推送 IM，需要用户确认的操作仍通过普通任务确认机制处理，不保证无人值守完成全部外部应用操作。

## 服务端边界

服务端提供企业能力、知识库和桌面上报记录，不调度桌面计划。计划以“当前员工 + 控制服务命名空间”的 SHA-256 摘要作为 SQLite 隔离键，原生层验证员工归属。调度因执行错误暂停时，刷新不会清除暂停提示，须显式重新检查并恢复。

## 频道配置与配对

钉钉频道配置、配对记录和系统凭据按当前钉钉员工分别保存。原生操作核实当前登录身份；扫码二维码及轮询结果绑定发起时的员工和登录轮次，切换账号不会继承上一员工的配置或未完成的扫码结果。

- 侧栏“频道”显示本机运行时实际返回的最近会话，点击可查看消息和任务进度。初次读取、读取失败和空列表分别展示；可见时每 10 秒以及窗口聚焦时刷新。运行时停止时暂不展示离线会话历史。
- 钉钉卡片提供连接状态、配对管理、编辑/移除菜单与启停开关。关闭频道不删除凭据或配对；移除配置需要确认。
- 桌面配置窗口默认扫码，支持刷新、过期提示、临时读取失败后重试和手动配置。二维码属于钉钉机器人应用注册，不是员工登录二维码。网页预览不运行原生扫码和凭据保存。
- 手动配置展示 Client ID（原 AppKey）、Client Secret（原 AppSecret）和钉钉配置文档入口；“返回扫码”保留未保存草稿。顶部标识悬浮，内容独立滚动，取消/保存固定在底部。准入策略横向展示，结果推送收在“更多设置”中。
- 扫码通过钉钉官方连接器使用的 `app/registration/init → begin → poll` 协议，来源标识为 `XIAOYIN`；实际创建/选择应用需要用户在钉钉中确认。协议参考 [钉钉官方连接器](https://github.com/DingTalk-Real-AI/dingtalk-openclaw-connector)。
- 扫码成功只填充待保存应用；点击“保存”才替换本机配置。刷新或关闭后，旧二维码的迟到授权结果不能覆盖当前表单。当前绑定应用与待保存应用分别显示，密钥始终遮罩。
- 手动编辑同一个 Client ID 时可留空密钥以保留现有凭据；更换应用必须提供新密钥。保存保留当前启停状态，只有显式开启才恢复已关闭的频道。
- 新配置默认配对模式，编辑保留现有策略。配对模式需要逐个允许私聊或群聊；开放模式允许直接对话。配对管理同时显示待处理请求和已配对会话，支持解除配对；解除不取消已开始的任务。开放模式下解除配对不会阻止该会话使用。
- 页面轮询不改写正在编辑的字段；保存、启停和配对操作串行提交，先前发出的状态读取不覆盖操作结果。弹窗支持焦点约束、Esc 关闭和返回原入口；叠加确认框优先处理键盘事件。

## IM 结果通知

### 频道任务交付

- Agent 执行结果与 IM 交付分开：执行成功但文本或文件发送失败时，任务仍为执行完成，频道显示“发送待处理”，不把已生成结果改写为执行失败。
- 文本和每个文件分别保存已确认送达进度。失败仅重试未发送部分，自动尝试最多 3 次；耗尽后保留待发送记录并暂停，不重新调用 Agent。重启不自动恢复耗尽的发送。
- 会话提供“仅重试发送”，要求频道连接可用、配对策略允许。每次恢复一个待处理结果，按原会话串行发送；重复点击不会重复发送同一记录。旧结果补发不会覆盖较新任务的状态、最后回答或会话 ID。
- 回复窗口已明确过期时，使用原会话的主动消息通道；普通网络超时不切换通道补发，避免一次不确定的发送产生双重投递。文件仍受钉钉支持类型、大小和本机文件可用性限制，失败明确保留待处理状态。
- 已确认送达的不重复发送；外部发送成功但响应丢失或本地保存失败仍可能重复，不承诺跨服务恰好一次。

## 桌面与 IM 续聊

IM 可以补充缺失消息，但旧 IM 状态不能将较新的桌面执行覆盖为完成、失败或旧会话。保存 IM 更新期间新建、修改或删除了本地任务时，不用旧列表覆盖界面，下一次轮询重新合并。组件退出后的旧启动和同步错误不通知新页面。

## 验收

- 定时计划：到期只触发一次、错过不补跑、并发租约、员工隔离、存储失败暂停、运行中停止与重启不重跑；原生设备检查休眠与唤醒。
- IM：扫码配对、账号切换、执行与发送阶段分离、部分文件失败补发、超时后的不确定投递、旧状态不覆盖新任务。
- 发布前使用测试机器人和合成文件完成真实钉钉收发；模拟发送器回归不等于外部服务验收。
