# 桌面能力对照

参考：本机 Qoder Work CN 0.9.15 的专家套件、技能、连接器列表与详情界面。此表描述小胤当前实现，不代表完整产品能力等同。

## 专家套件

| 项目 | Qoder Work | 小胤 |
| --- | --- | --- |
| 页面布局 | 居中内容、行业横幅、两列卡片、顶部搜索/刷新/添加 | 同类布局，790px 内容区，144px 横幅 |
| 插画与动画 | 身体/手部动图、背景标签、行业轮播、创建按钮 | 使用原始分层素材；5.5 秒轮播，悬停/聚焦暂停；创建入口统一在顶部「添加」，横幅不重复放置 |
| 目录 | 公共市场、分类、热门/最新 | 企业目录与本地导入；分类、目录推荐顺序/名称排序 |
| 详情 | 作者/版本、命令、知识技能、完整说明 | 显示真实版本、来源、命令、技能原文和 README；同时显示依赖待配置项 |
| 使用 | 命令带入对话、聊天启停 | 命令带入新任务；启停持久化到设备，执行层同步排除停用扩展 |
| 管理 | 打开目录、编辑、链接/ZIP 分享 | 打开目录、生成可编辑副本、ZIP 导出；不提供无后端支持的在线链接 |

套件依然是岗位方案的组织形式，统一由现有 Agent 执行，不增加独立专家运行引擎。

## 技能

| 项目 | Qoder Work | 小胤 |
| --- | --- | --- |
| 横幅 | 淡蓝背景、三个交叠插画卡片 | 原始插画；最多绑定三个真实技能详情入口 |
| 市场 | 三列卡片、精选目录、下载数 | 三列企业技能卡片；不伪造下载量、作者或公共市场内容 |
| 本地列表 | 内置/已安装，单行技能、使用和开关 | 本机/已安装，紧凑单行、使用和持久化开关 |
| 原文详情 | 内置技能的大尺寸说明弹窗 | 独立技能在主区显示完整 SKILL.md；套件内技能、命令用原文弹窗 |
| 创建和导入 | 添加菜单、对话创建、上传确认 | 对话创建；上传窗口选择 SKILL.md、目录或压缩包后点击安装，失败保留选择 |
| 调用 | 自动匹配、显式指定 | 已启用技能参与匹配和 / 候选；停用后不加入新任务 |

「本机」表示本地导入的开发者技能，不冒充随产品预装的办公技能库。目录没有发布时间与下载统计字段，因此不把跨技能的版本号排序标为「最新」，也不把目录顺序标为「热门」。

## 连接器

| 项目 | Qoder Work | 小胤 |
| --- | --- | --- |
| 页面 | 浅灰插画横幅、分类、紧凑两列卡片 | 原始连接插画，简化分类标题，整卡可打开详情 |
| 详情 | 应用说明、安装或断开按钮 | 居中详情、启停、配置入口、实际连接检测与工具列表 |
| 配置 | 应用授权及自定义连接 | 企业目录；独立 MCP 手动表单、JSON 导入/编辑/删除，环境变量、请求头和执行超时配置 |
| 已安装视图 | 已安装应用 | 「已添加」包含已启用目录项与个人配置，个人项停用后仍可管理 |
| 可用性 | 各提供方适配与账号授权 | 已支持的桌面连接器和通用 MCP；启用不等于握手成功 |

Qoder 的公共连接器目录、各应用 OAuth 登录与专用适配不能通过复制界面获得。小胤当前不提供 Notion、Slack 等服务的即开即用授权闭环；可接入符合现有 MCP 协议的服务，但不能据此宣称覆盖这些产品的全部能力。

## 交互和实现边界

IM 频道采用紧凑单行卡片、真实连接状态、配对管理、更多菜单和绿色启停开关。配置窗口支持钉钉应用注册扫码与手动凭据、当前绑定应用、配对/开放策略和固定底部操作；扫码不自动保存。侧栏“频道”展示实际 IM 会话与处理状态。注册完成、真实收发与组织权限仍需用户授权联调，详见 [定时任务与 IM](schedules-and-im.md)。

- 新任务以统一输入框承接岗位工作。「＋」左侧分类、右侧内容级联展示专家套件、技能、连接器和知识库，支持悬停与键盘切换，并保留直接添加文件入口；正文支持 `/` 调用与 `@` 上下文选择。指定能力使用标签展示，不增加固定任务类型切换。
- 工作目录支持最近记录，任务附件支持预览；文件、文件夹可从系统文件管理器复制后粘贴或直接拖入，PNG/JPEG 截图也可粘贴。三种添加方式统一去重、限额与任务切换检查。草稿按员工和任务保存，切换任务与重启后恢复正文和上下文引用。
- 一次显式指定一个套件、技能或命令；已启用技能仍可自动匹配。连接器选择限定本轮装配范围；无选择时按需使用就绪且启用的连接器。能力通过统一 Harness 执行，不止是界面标签。
- 未指定知识库时默认按员工权限检索，套件或手动选择可以限定范围。指定套件时要求读取相关技能的实际工作方法和交付标准，不另外创建专家运行引擎。
- 不提供没有执行支撑的 Auto 模型、思考强度、语音录入或写作/设计模式按钮。模型工具调用质量与端到端交付仍需实际任务验收，不宣称与参考产品完全等同。

- 对话过程按真实工具事件分组，成功步骤默认收起，错误和待确认操作保持可见；运行中可追加文字排队，完成后沿原任务上下文顺序执行。
- 提交后显示轻量处理状态，初始化不作为对话步骤展示；正文增量更新，完成或停止后过程默认收起。停止只中断本轮并清理运行时工具进程，保留对话、部分输出与成果，不被迟到结果改回成功。停止后的下一轮携带可见上下文继续执行。
- 队列支持编辑、删除、暂停和继续，失败、停止及重启恢复后暂停。文件卡片支持点击文件名预览、显示实际路径与大小。详细规则见 [任务执行与结果展示](task-execution.md)。
- Office 产物自动登记，代码、Shell 和应用生成的其他文件可检查后显式登记交付，显示「已就绪」而非虚构创建或修改。桌面和本地 IM 共用执行约定；IM 回传使用实际目录 ID，仅接收成功产物与显式交付文件，不自动发送读过的资料。
- 文件改动卡片支持整轮审核、逐文件路径打开、磁盘刷新与上下文差异展开；带可靠校验记录的普通文件可确认后撤销，冲突项跳过并保留恢复副本。移动/删除、缺失记录及独立 Office 产物行不提供自动撤销；不把这些入口等同于完整 Git 版本管理。

- 搜索、分类、添加、详情返回、真实技能快捷入口可用；首次加载有骨架，刷新保留已有内容。
- 连接器详情和扩展原文支持 Escape 关闭、Tab 焦点约束和关闭后返回入口。
- 本地扩展启停独立于卸载，更新版本保留设置；已启动 Harness 会话不热卸载已加载内容，新会话按当前设置加载。
- 分享使用可实际导入的 ZIP。在线分享、公共市场服务、完整预装技能库和首页 Rive 鼠标跟随仍未实现。
- 桌面实现、导入格式和运行约束分别见 [架构](architecture.md)、[扩展使用](extensions.md)、[视觉规范](brand.md)。
