# 产品能力

小胤是有岗位能力的桌面工作助手。产品组织参考 Qoder Work，任务执行以 Claude、Codex 的完成质量为目标，通过实际任务与交付物评测。

## 工作流程

1. 用户描述目标并提供必要资料；文件默认保存在小胤工作目录，也可选择其他目录。
2. Agent 理解需求，缺少关键条件时澄清。
3. 按需使用 Skills、连接器、知识库和本机工具。
4. 检查文件、数据、测试与业务要求，交付成果和剩余事项。

用户可以直接开始任务，也可以组合选择最多 8 项技能与专家套件。只需方案或分析时，在输入框「＋」菜单中选择“计划模式”。

## 功能

| 入口 | 当前能力 | 使用条件 |
| --- | --- | --- |
| 任务 | 流式回复、停止、继续、队列、搜索、归档、图片与 HTML 成果预览 | 模型可用；访问其他目录需授权 |
| 专家套件 | 岗位工作方法、技能、命令和依赖的组合；同一任务使用多个套件 | 安装并启用，补齐依赖 |
| 技能 | 自动匹配、组合调用、查看、定制、本地上传、对话搜索安装 | 标准 SKILL.md 与辅助文件 |
| 连接器 | Streamable HTTP、STDIO MCP，导入、编辑、OAuth 授权、启停和工具检测 | 服务可达，凭据有效；OAuth 服务支持动态注册 |
| 知识库 | 个人、团队、公司资料的上传、检索和来源回读 | 服务端索引完成与员工权限 |
| Browser | Harness 官方右侧栏 Browser 标签页；Agent 可按任务调用官方 Playwright Browser | HTTP(S) 页面；Agent Browser 需当前能力快照明确授权 |
| 记忆 | 稳定偏好、逐条管理、同步与冲突处理 | 用户明确表达的长期偏好 |
| 定时任务 | 一次性与周期计划，复用模型和任务上下文 | 桌面在线，工作目录可用 |
| IM 频道 | 钉钉配对、会话接管、附件读取和成果回传 | 钉钉应用配置与组织授权 |

## 交付标准

文件卡片对应实际文件；生成、结构检查、视觉检查和业务验证分别记录。代码任务提供真实测试结果，表格金额以重算后的结果为准，知识结论提供可回读来源。

轮次结束与目标完成分开记录。缺资料、待确认、部分完成或受阻时保留成果及剩余事项，并暂停自动续轮。发送成果失败只重试发送，不重复执行已完成任务。

## 支持范围

- 扩展分享使用可导入的 ZIP，企业内容由控制中心审核与分发。
- 通用 MCP 接入需要服务自身的配置和授权；产品专用 OAuth 按连接器逐项建设。
- 本机关闭或休眠时不执行定时任务；保持唤醒由员工配置。
- Office 复杂版面、专有公式、扫描件与外部业务系统按实际场景验收。
- 模型选择、工具配置和界面可用性不代表目标已完成，以验证结果为准。

开发与运行见 [架构](architecture.md)，质量要求见 [发布验收](system-readiness.md)。
