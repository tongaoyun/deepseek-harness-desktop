# 系统检查与验收范围

小胤以统一任务执行为底座，桌面展示任务、技能与专家套件，控制面负责模型、能力目录、设备和运行记录。完善工作按真实数据与执行链路验收，不以新增界面入口代替功能。

## 集成环境

桌面开发环境连接 `192.168.2.67:30081`，管理端为 `192.168.2.67:30084`。67 的控制 API、索引 Worker 和管理端由同一服务端主线版本发布，数据库迁移至 V29，发布前独立备份小胤数据库，不重置业务数据。

远程真实验收覆盖记忆条目与版本冲突、审计、文字与图片反馈及原图读取；管理端确认附图与任务上下文可见。知识库覆盖中文 DOCX、带公式 XLSX、原文定位、重建失效、删除替换、大文件上传与解析失败重试，合成知识库验收后自动清理。反馈验收记录保留为已完成，不代表真实员工问题。

源码检查与服务器上线不等于桌面安装升级完成。macOS 打包门禁还会独立核对架构、内置执行环境、更新签名及 DMG 与更新归档一致性；正式升级与 Intel 实机仍需单独验收。

## 记忆

设置支持分类管理、风格预设、来源任务、逐条编辑删除与本机版本恢复。回归覆盖原任务内主动记忆不丢消息、停止不学习、同账户并发新增不丢条目、过期编辑拒绝覆盖、离线删除不被旧云端数据恢复及按需读取。V28 已在本地 Docker 迁移，隔离测试账户完成条目保存、读取和删除回读；验收条目已清空。自动记忆仅限桌面任务中用户明确表达的稳定偏好，不代表模型自主画像、长期反思或跨电脑并发合并已实现，范围见 [记忆](memory.md)。

V29 已在本地 Docker 迁移。隔离账户通过真实 HTTP 并发提交验证首次创建和后续更新均只有一个成功、另一个返回 409，旧版本重试不能覆盖获胜内容；测试规则已清空。设置添加、未提交输入跨页面恢复、对话候选选择、启动/联网/聚焦同步和冲突通知去重由自动测试覆盖。真实模型使用独立临时记忆验证新任务遵循、当前要求覆盖、更新生效、删除后新任务不再带入四项，期间没有工具调用或修改用户记忆。

本地原生桌面实际验证：在「添加记忆」输入测试草稿，切换设置分类时显示离开提醒，确认保留后返回可恢复未提交输入；放弃草稿后测试文字消失，长期记忆仍为空。验收草稿已清理，没有点击保存或修改原有记忆。

## 任务与文件

- 运行、完成、失败、停止和重启中断有明确区别；部分正文与成果保留，执行中周期保存，保存与删除顺序一致。
- 保存失败持续显示未保存状态，重试只写入最新任务内容，不重跑执行；草稿保存失败阻止切换对话覆盖输入。内存内容仍可能因强制退出丢失。
- 成果不可读区分原路径缺失、目录授权失效和系统权限，提供重读与文件选择入口；重新选择只打开预览，不改写历史路径和撤销基线。
- 文件恢复的原生验收使用合成成果临时改名，确认缺失提示、取消选择后保留状态、归位后重读成功且哈希不变。保存失败与重试最新内容、账号隔离、文件选择迟到结果和不继承审核记录由自动回归覆盖，不主动破坏真实任务数据库制造故障。
- 续轮按实际附件、成果和文件状态恢复上下文；文件登记、内容检查和文件改动分别记录，不把文件存在当作质量验证。
- 附件总数、图片数量、单图大小在桌面与运行时保持一致，超限明确报错，不静默忽略。
- 验收覆盖停止竞争、排队续轮、文件变更与撤销、保存失败、长附件分段读取和 IM 分阶段送达。模型质量与真实外部服务行为仍需单独验收。
- 恢复摘录保留最初需求、历史约束与近期追加；长会话按 60 条分页展示。成果结构检查、单页 PDF 渲染、LibreOffice 导出和公式重算已有真实临时文件测试；复杂 Excel 特性、业务数据、版面与扫描识别质量仍需使用实际样本及图像模型验收。转换依赖缺失时不标记功能已就绪。
- 原生桌面使用真实 DeepSeek 模型完成合成销售资料读取、内置公式表格生成、同任务追加修改、LibreOffice 重算、排版、PDF 导出与文件卡片交付。本机安装官方 LibreOffice 26.8.0.3 和 Noto Sans CJK SC；后台转换独立加载系统与用户字体，不修改全局字体配置。
- 独立读取实际 XLSX 确认两张工作表、5 个公式及缓存结果，数量合计 12、金额合计 287.5；原始 XLSX、CSV 与需求文件的哈希未变。排版副本设置列宽、换行、行高和精确打印范围；最终 PDF 为两页横向 A4，已逐页渲染确认中文、长说明和数值可读，无文本截断及空白尾页。
- 本地原生调试构建重启后，多轮对话、文件改动与成果卡片完整恢复。此验收使用合成数据，当前文本模型只完成内容与结构核验，页面视觉检查由开发验收另行完成；不代表模型可自主检查所有版面或复杂 Excel 特性。
- 原生桌面异常验收使用独立临时目录与真实 DeepSeek 模型：先生成检查点，再前台执行等待命令。点击停止后，Host 与命令子进程均结束，已生成文件及成果卡片保留，后续写入未执行；运行中切换任务不影响后台任务，退出应用后后台进程结束。重启恢复最近保存的进度，追加任务先核对文件，再生成恢复成果，原检查点哈希不变，不重复等待或已完成写入。
- 模型超时、输出中断、自动重试上限、保存顺序与队列暂停通过自动回归覆盖；未主动中断真实模型供应商服务或业务连接器，不将这些测试等同于真实外部服务故障联调。
- 真实模型的工具失败恢复验收：读取指定不存在文件后保留错误步骤，不重复失败调用，继续读取两份有效文件并返回验收标记；目录未发生额外写入。局部工具失败与整轮任务最终结果分别展示。

## 本地长任务与交付闭环

- SQLite 查询测试覆盖 205 个任务、每任务 160 条消息；读取后保留最初需求。加载首批后删除已展示记录、更新未展示记录，后续分页仍返回全部剩余任务，不因位置变化漏项。
- 定时任务链接直接读取未加载的历史记录；读回期间切换到新任务，迟到结果不会覆盖当前草稿。损坏的浏览器历史保留原文并阻止覆盖保存，缺失任务与不可读任务分别报错。
- 原生桌面真实模型使用合成文本完成文件生成、退出重启、同任务追加修改：数量从 12 到 15、金额从 287.50 到 330.00，更新同一个成果文件，源输入哈希不变。
- 原生取消验收确认前台等待进程已启动，点击停止后进程退出、显示已停止，源文件和成果哈希不变。随后只读继续仍返回 15 / 330.00，不再次应用追加规则，不重跑等待命令。
- Office 回归通过实际 LibreOffice 进行公式重算、后续修改和 DOCX／PPTX／XLSX 到 PDF 转换，并读回结果检查；合成样本不替代复杂业务版面和扫描识别的专项验收。

## 控制面与管理端

- 左下角设置和图文反馈的范围见 [桌面设置与反馈](settings-and-feedback.md)。反馈文本与图片经过真实本地 API 上传、数据库保存和图片字节回读核对；管理端展开附图后确认图片正常加载。

- 桌面结果上报区分成功、失败和主动停止；管理端可按员工/任务线索、结果和日期查询、导出桌面记录。
- 管理端「任务记录」只展示桌面上报，没有本机对话全文与本地文件，也不通过记录页远程操作员工电脑。初始化和全局搜索不请求云端执行或服务器计划接口；服务端独立 API、计划和数据仍保留，不因入口收敛被停用或删除。
- 概览显示最近桌面上报与失败记录总量，失败记录不等同于待处理任务数。全局搜索的桌面结果直接定位到任务记录筛选条件，关键词变化或退出登录会丢弃迟到结果。界面统一使用「技能」。
- 本地 Docker 控制 API 与管理端需要一起更新。测试数据与远程环境隔离，服务重启保留数据库和对象存储卷。

管理端收敛回归覆盖启动与全局搜索不请求云端接口、搜索结果定位桌面记录、关键词变化后拒绝迟到结果，以及退出登录时中止刷新。管理端 24 项测试、类型检查、静态检查和构建通过；本地浏览器确认任务页无云端标签、33 条桌面上报正常分页且实际任务 ID 可搜索。任务记录与知识库 API 返回 200，索引 Worker、Temporal 和数据库保持健康；此项没有重新验证文档索引全过程，也没有停用或删除任何服务器计划。

## 配置生效

- 模型配置与能力目录按周期、窗口聚焦刷新，失败可重试；账号切换隔离迟到结果，后台旧清单不覆盖刚安装的本机状态。
- 续聊和排队任务按当前配置重新生成轮次快照，保留任务上下文与人工指定范围。连接器地址、工具声明、扩展版本和启用状态的变化进入下一轮。
- 必填参数缺失的连接器不可进入执行集合；被移除的模型不会被继续请求，无可用模型时提示配置。连接器服务的真实可用性仍以握手和调用结果为准。
- 自动回归覆盖配置刷新失败恢复、模型切换、连接器更新/删除、扩展升级/停用和异步清单竞争；外部 MCP 服务故障及恢复需逐连接器联调。

## 继续核查的系统范围

知识库状态、检索范围、上传失败恢复和删除链路见 [知识库](knowledge-base.md)。本地 Docker 真实验收覆盖中文 DOCX、公式 XLSX、文本型 PDF 的索引、检索与原文重读，以及重建、删除、同名重新上传、无匹配和失败重试；不等同于所有扫描文档和复杂 Office 内容均已验收。

原生桌面使用真实 DeepSeek 模型完成知识检索：从合成 Word 制度返回每日住宿上限 800 元及发票要求，从合成表格读取 C2=5、D2=200，并说明表头信息不足的边界。实际检索回执生成可点击原文卡片；删除测试资料后，旧卡片提示原文失效，后续检索返回空结果，模型明确说明未找到当前依据且不沿用旧金额。验收资料从服务器清理，本地合成文件保留可重新上传，对话保留为历史记录。

桌面定时任务统一使用本机计划，不提供本机／服务器切换，也不调用 Temporal。支持一次性、间隔、小时／日／周／月周期、附件、macOS 保持系统唤醒以及通过对话管理同一计划；执行复用普通任务入口。知识库索引仍依赖 Temporal，详见 [定时任务与 IM](schedules-and-im.md)。真实 IM 送达及外部工具执行期间的取消仍需联调。

定时页面采用紧凑计划卡片与单列创建弹窗，工作目录、附件和模型选择整合在任务内容输入框中。自定义周期支持固定时区；执行记录支持天／周／月分组和任务／状态筛选。模型使用真实可用列表，指定模型失效会暂停计划，不静默换模型。

原生桌面真实模型验证了对话创建本地计划、立即暂停、列表查询及页面显示的一致性；一次性计划到点自动生成任务、返回只读验收标记并停用。macOS 电源断言确认唤醒开关生效与关闭释放。验收计划保留为暂停或已结束，不继续周期执行。

本机主动停止与失败分开记录，App 集成测试核对任务终态与计划记录一致。IM 执行完成与发送待处理分别展示，耗尽的发送保留并支持手动恢复；本地 HTTP 接收器验证实际 XLSX 文件上传、单文件 503 后仅补发未成功文件、不重跑 Agent。真实钉钉账号收发与权限限制仍未联调。

原生本机计划使用真实模型启动纯等待命令，点击停止后验证 Host/子进程退出、任务与计划记录均为已停止、后续计划暂停。执行前缺少所需目录则记录未启动原因，不提供未创建任务的链接。

macOS 原生桌面助手在本机现有系统授权下通过独立 AppKit 窗口实测：真实截图、控件实际文本读取、坐标点击、中文输入、Command+A 全选替换、读取按钮执行结果和提前取消均通过。真实 DeepSeek 模型经生产运行时自主完成打开合成文档、修改数量 12→15 和金额 287.50→330.00、保存与磁盘回读，独立文件检查确认标记保留且数值一致。

真实模型输入完成后触发运行时停止，工具调用停在输入阶段，未执行后续保存，磁盘原文仍为 12 / 287.50。文档不可读时，模型重新观察后说明失败，没有输入或保存。独立双窗口验收确认前台切换后旧观察的输入被拒绝、失败后需要重新观察、另一个窗口未被输入文字。以上使用专用测试应用，不代表所有第三方业务应用或复杂系统弹窗均已验收；没有测试系统锁屏、跨显示器移动及长时间运行中的所有竞争窗口。

同一真实模型会话追加只读核对请求后，通过应用重新读取磁盘，仍返回 15 / 330.00，磁盘内容逐字相同，没有再次应用增加规则。完整流程由真实工具回执中的打开、保存和回读状态，以及模型之外的文件读取共同确认；没有向业务应用写入测试数据。

真实 TextEdit 验收覆盖模型通过系统打开对话框读取临时 txt、修改、保存、关闭后重新打开，以及同会话追加只读核对。磁盘与应用回读均为 15 / 330.00，标记保留，旁边的临时文档保持不变；应用启动由测试准备程序完成，不计为模型自主启动能力。路径弹窗在仅返回 8 个控件时仍包含路径输入框且无重复元素。该验收不覆盖另存为、复杂格式文档和所有第三方应用弹窗。

MCP 检测使用真实本地 HTTP 服务验证握手、503 不可用和恢复后的工具漂移；这不代表全部外部业务连接器已联调。

会话组件在本机内置浏览器以 2000 条合成消息连续切换 100 次，默认渲染 60 条消息，DOM 节点峰值 1513，页面溢出和底部定位误差为 0；该次开发构建的组件同步提交耗时中位数 1.7 ms、P95 为 11.7 ms，不包含真实历史查询、网络和模型响应耗时。截图回归覆盖 100 次切换后的图片 URL 与观察器释放；尚不能据此宣称完整桌面进程长时间运行不存在内存增长。

本机计划已通过原生桌面的真实模型只读验收：暂停计划手动触发、模型返回验收标记、记录完成并打开任务结果。该验收不包含业务文件处理或 IM 投递；样例计划保持暂停。
