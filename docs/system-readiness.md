# 系统检查与验收范围

小胤以桌面任务执行为核心，面向员工提供新任务、专家套件、技能、连接器、知识库、定时任务和钉钉频道。控制中心负责企业模型、能力目录、知识资料、设备、审计、记忆同步和反馈管理。

## 集成环境

| 服务 | 地址 | 验收要求 |
|---|---|---|
| 控制 API | `http://192.168.2.67:30081` | 健康检查、Bootstrap、模型目录、能力目录、知识库、记忆、审计和反馈可用 |
| 管理端 | `http://192.168.2.67:30084` | 概览、任务记录、能力管理、知识库、设备、反馈和审计页面可用 |
| 知识索引 Worker | 67 集群内部服务 | PostgreSQL 队列可领取、续租、重试和恢复，索引结果可检索并读取原文 |

服务端发布使用主线提交对应的不可变镜像。发布验收必须等待控制 API 和知识索引 Worker 的全部副本更新完成，并使用隔离员工与知识库数据执行检查。

## 桌面任务

- 新任务直接接收自然语言需求，不提供 Agent、Plan 或聊天模式切换。
- 每轮执行遵循理解需求、必要澄清、拆解、调用工具、检查结果和交付成果的流程。
- 轮次结束与目标达成分别记录；未完成结果保留剩余事项并暂停消息队列及定时计划。任务报告校验格式与状态一致性，业务正确性仍依赖实际验收。
- 对话支持流式正文、简明进度、工具操作、确认、停止、继续、排队续轮和失败重试。
- 任务、消息、附件、成果、执行状态和文件改动保存在本机 SQLite；侧栏分页读取，搜索覆盖完整持久化记录。
- 对话正文按 60 条分页加载，向上阅读时不会被新输出强制拉回底部。
- 运行中任务周期保存；保存失败持续提示并允许重试，不通过删除旧消息掩盖错误。
- 停止会终止 Harness 及其子进程，保留已经生成的正文和成果；主动停止与执行失败分开记录。
- 文件成果必须实际存在后才能登记。预览、结构检查、视觉检查和业务正确性分别展示，不把“文件存在”当作验收完成。

详细行为见 [任务执行与结果展示](task-execution.md)。

## 文件与办公文档

- 支持拖拽、粘贴和文件选择；附件数量、大小和图片限制在桌面与 Harness 保持一致。
- 本地文件工具只访问员工授权目录，任务恢复时携带目录标识、相对路径和最新文件状态。
- 支持文本、代码、图片、DOCX、XLSX、PPTX 和 PDF 的读取、生成、预览与成果交付。
- Office 结构检查报告工作表、公式、错误单元格、页数或幻灯片数；PDF 页面可渲染为图片进行视觉核对。
- LibreOffice 用于公式重算和 Office 转 PDF。引擎不可用时明确提示，不影响普通文件与表格生成。
- 文件修改提供实际差异、审核和撤销；重新选择文件只用于预览，不改变历史成果路径或撤销基线。

## 专家套件、技能与连接器

- 专家套件组织岗位场景、工作流程、交付标准、技能、命令和连接器；用户无需先选套件即可执行任务。
- 技能支持自动匹配和 `/` 显式调用，使用标准 `SKILL.md` 及辅助文件。
- 套件和技能支持安装、启停、原文查看、定制副本、导入和 ZIP 分享。
- 连接器支持 Streamable HTTP、SSE 和 STDIO MCP，提供手动配置、批量 JSON 导入、启停、编辑、删除、握手诊断和工具清单。
- 每轮任务按当前启用且配置完整的能力生成快照；配置修改在下一轮生效。

详细范围见 [扩展使用](extensions.md)。

## 知识库与记忆

- 知识库支持个人、团队和公司范围，上传后由 PostgreSQL 持久化队列驱动索引 Worker 解析和分块。
- Worker 离线时文档保持排队；租约过期可恢复，临时故障最多尝试 3 次，损坏文件显示明确失败原因并允许重建。
- 检索结果包含文档、片段和原文定位；重建或删除后旧引用失效，未找到依据时不得补造公司规定。
- 验收覆盖中文 DOCX、带公式 XLSX、文本 PDF、原文读取、重建、删除、同名替换、大文件和解析失败。
- 记忆用于跨任务保存明确的稳定偏好，支持分类、来源任务、逐条编辑删除、启停、同步冲突和本机版本恢复。
- 自动记忆只处理用户明确表达的稳定偏好；知识资料、任务历史和一次性指令不写入长期记忆。

详细范围见 [知识库](knowledge-base.md) 和 [记忆](memory.md)。

## 定时任务与钉钉

- 定时任务保存在员工本机，支持一次性、间隔、小时、日、周、月和固定时区计划。
- 计划复用普通任务入口，可携带模型、工作目录、附件、技能、连接器和知识库上下文。
- 页面创建、通过对话创建、编辑、暂停、恢复、删除和执行记录操作同一份本机计划。
- 电脑睡眠或关机期间不执行；macOS 可按计划申请保持系统唤醒。
- 钉钉支持扫码或手动配置、配对与开放模式、会话列表、任务接管、附件读取和成果回传。
- IM 执行与消息送达分阶段记录；发送失败只重试未送达内容，不重复执行已经完成的任务。

详细范围见 [定时任务与 IM](schedules-and-im.md)。

## 控制中心

- 管理模型、专家套件、技能、连接器、知识库、设备、审计、记忆同步和图文反馈。
- 任务记录展示桌面上报的开始、完成、失败和停止事件，不展示员工本机完整对话或本地文件。
- 概览和全局搜索以真实服务数据为准；请求失败可重试，账号切换和新查询会丢弃迟到结果。
- 反馈支持文字和图片，管理端可查看任务上下文、原图和处理状态。
- 控制 API、管理端、PostgreSQL、MinIO 和知识索引 Worker 使用独立健康检查和发布验收。

## 发布门禁

代码进入主线前必须通过 lint、类型检查、前端测试、Harness 测试、生产构建、Rust 格式、Clippy 和 Rust 测试。服务端必须通过 Maven 测试、数据库迁移测试和真实 PostgreSQL 队列并发测试。

发布验收覆盖：

- 控制 API：Bootstrap、模型与能力目录、记忆版本冲突、审计、文字反馈、图片上传和原图读取。
- 知识索引：上传、排队、索引、检索、原文读取、重建、删除、替换和重试。
- 管理端：页面加载、真实数据展示、筛选搜索、反馈图片和知识库操作。
- 桌面安装包：架构、签名、内置 Runtime、安装启动、任务执行、数据保留和卸载。

真实外部业务系统、复杂 Office 版面、扫描文档识别、多显示器和锁屏环境按对应场景单独验收，不能由单元测试或合成样本代替。
