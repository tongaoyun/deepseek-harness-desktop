# 公司内容与 AgentSpec 包

[English](guide.md) | 中文

## 变更

产品桌面端读取公司资源版本索引，不再接收完整文件快照。专家使用包含 `manifest.json` 和 `config/SOUL.md` 的 AgentSpec 目录；专家团引用不可变专家版本。服务端通过 Flyway V73 重建公司内容和审核记录，保留员工、组织、连接器、知识库及原生会话数据。

个人专家转换为按登录员工隔离的本地不可变包，原生 Settings 保存资源引用及展示信息。个人专家团固定成员版本；已删除公司专家的引用需要重新选择。

## 迁移

1. 配套部署控制中心并升级产品桌面端。旧桌面端读取公司内容时会收到明确的更新提示。
2. 使用原个人内容所属的员工账号启动桌面端。首次读取内容时一次性转换该个人库，其他员工账号使用独立的内容库。
3. 打开个人专家和专家团，核对说明与附件；保存团队前重新选择已失效的公司成员。
4. 以标准 `SKILL.md` 包发布公司技能，以 AgentSpec 包发布专家，再发布成员均已发布的专家团。正式公司目录初始为空。
5. 新建会话执行公司内容。已有会话历史可读取，绑定旧公司协议的会话无法继续执行。

包格式及发布操作见[公司内容说明](../../../../apps/product-desktop/docs/company-content.md)。
