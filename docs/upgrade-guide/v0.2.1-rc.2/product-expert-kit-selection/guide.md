# 专家套件选择与技能使用

## 变更

专家套件只保留选择套件后输入需求的入口，目录详情和控制中心不再展示快捷命令。任务准备不再接受 `expertKitTaskId`，产品能力快照不再保存 `expertKitTask`，服务端版本元数据和数据库删除 `commonTasks` 及其存储字段。套件说明在首次执行前加载，内置技能通过 Harness 官方 `skill` 工具按需读取，不再根据快捷命令预先注入技能正文。

新套件清单使用 `schemaVersion: "4"`，不接受旧清单或快捷命令字段。技能清单版本保持不变。官方 Session 历史和知识库内容保留；产品快照遇到已删除字段时明确阻止执行，不静默切换能力。

## 迁移

1. 先部署服务端并执行 `V63__remove_expert_kit_shortcuts.sql`，再更新桌面和控制中心，不混用旧协议。
2. 新建或导入套件使用清单版本 `4`，删除 `commonTasks`，通过对话说明表达工作流程并保留标准内置技能目录。内容变化须发布新版本，不覆盖既有制品。
3. 为使用旧快捷命令配置或旧套件制品的任务创建新对话，选择新版本套件并自行输入需求。旧任务仍可查看历史；不提供旧产品缓存兼容或自动迁移。
4. 验证详情无快捷命令，选择套件不清空草稿；执行日志先记录套件说明，技能经官方工具调用后再进入模型上下文。
