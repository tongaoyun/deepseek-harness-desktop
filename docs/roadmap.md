# 完善计划

优先提升登录可靠性、任务完成质量和企业可运维性。每项完成以可重复的验收结果为准。

| 优先级 | 工作 | 完成条件 |
| --- | --- | --- |
| P0 | 登录与会话稳定 | 区分无会话、钉钉会话到期、身份服务异常；覆盖重启、休眠和断网；诊断不记录凭据 |
| P0 | 正式更新与系统信任 | 验证下载安装、重启和数据保留；配置 Apple 公证与 Windows Authenticode；完成 Intel 和 Windows 设备交互验收 |
| P1 | 任务与扩展契约 | 清单、桌面、服务端对支持字段和工具使用同一契约，发布前拒绝无法执行的能力声明 |
| P1 | 厂商连接器 | 在标准 MCP OAuth 基础上接入预注册客户端及厂商权限流程，逐项实测 Figma、Notion、Linear 和 1688 工具调用 |
| P1 | 代表性任务评测 | 覆盖多文件代码、长任务、复杂表格、PDF/OCR 与真实业务；重复运行并统计成功率、时间、Token 和人工介入 |
| P1 | 横向扩容与告警 | 比较 2、4、6 副本，检查数据库连接和内存，验证节点故障及租约恢复，再启用 HPA |
| P1 | 钉钉完整交付 | 真实验证配对、附件、成果回传、断线恢复和只补发失败内容 |
| P2 | 工程维护 | 持续收敛 App 状态协调，保持单一入口、职责清楚、契约检查及可操作的文档 |

性能报告区分文本、Office 和 OCR；接口速度与任务成功率分别评估。执行与交付要求见 [发布验收](system-readiness.md)。
