# 桌面设置与反馈

左下角账户菜单提供桌面设置、应用更新、问题反馈和退出登录。反馈使用独立全屏遮罩，不受账户菜单裁剪、收起或侧栏布局影响。

## 设置

- 偏好设置：默认／较大／大三档对话字号，默认／宽两档对话宽度，减少动画；立即生效并在本机保存，可恢复默认。
- 个人资料：当前企业身份、部门与岗位。
- 记忆：协作风格、工作手册、用户偏好和长期记忆，支持自动记忆开关及逐条管理，见 [记忆](memory.md)。
- 快捷键：常用操作指引。
- 附件存储：占用统计和未引用缓存清理。
- 更新应用：桌面端检查和安装更新。

保持白色界面与统一任务入口，不提供订阅、实验特性、未实现的语音或模型管理开关。模型由企业配置；本机计划的保持唤醒设置仍在定时任务中。

## 图文反馈

问题描述必填，最多 2000 字；可附最多 4 张 PNG、JPEG 或 WebP 图片，每张不超过 5 MB。支持文件选择、截图粘贴、图片文件粘贴与拖入，以及预览、移除。原生拖入反馈的图片不会加入聊天附件，也不会授权其目录给任务执行。

提交中禁用重复操作；成功后清空内容，失败保留文字和图片，取消后本次应用会话内可重新打开继续填写。未提交草稿不跨重启保存。超时不自动重发，避免重复提交。

仅发送用户填写的文字、所选图片和版本／设备／任务标识，不自动收集对话或本地文件。控制端以同一事务保存文字与图片，管理端显示附图数量，展开后按需读取，可打开原图；折叠或离开页面释放预览资源。

接口：`POST /api/v1/feedback` 接受 multipart 的 `feedback` JSON 部分和重复 `images` 文件部分；管理端通过 `/api/v1/admin/feedback/{id}/images` 查询附图，再以 `/images/{imageId}` 读取图片。控制端与桌面需使用兼容的接口版本。
