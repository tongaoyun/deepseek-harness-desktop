# 桌面形象与视觉规范

## 资源

应用内使用 Qoder Work CN 0.9.15 的参考插画与分层 GIF：薄荷绿圆润身体、黑色卷发和简洁五官。资源位于 `src/assets/qoder/`，由 `XiaoyinMascot` 和 `CapabilityHero` 加载。安装图标仍由 `src-tauri/icons` 单独管理。

- 首页、头像：身体 GIF；专家套件：身体、手部两层 GIF。
- 知识库：`KnowledgeHeroArt` 矢量阅读场景，保留绿色身体、卷发与大眼睛，搭配书本和原文资料卡；包含扫视、眨眼、轻微低头与翻页动作。
- 技能：演示文稿、信息图和研究三张原始插画，重叠排列；存在真实目录条目时可点击打开详情。
- 连接器：应用环绕与连接动作的原始 SVG。
- 系统减少动态效果时，以静态矢量替身代替 GIF，并停用轮播与 CSS 动效。首页不包含 Qoder 的 Rive 鼠标跟随状态机。

资源来源、导入方式及使用范围见 [资源清单](mascot-expressions.md)。这些是上游参考素材，不是小胤原创设计；公开分发前需确认相应素材的使用授权。

## 应用与系统图标

应用图标使用参考应用的绿色圆角底、黑色卷发与大眼睛图案，名称和应用标识仍为小胤。

- `src-tauri/icons/icon.icns`：macOS 原始多分辨率图标，用于应用包、Dock 和 Finder。
- `src-tauri/icons/icon-source.png`：1024px 母版；同目录的 ICO、PNG 和 Windows Logo 文件由 Tauri 图标工具生成。
- `src-tauri/icons/trayTemplate@2x.png`：macOS 单色菜单栏图标，启用系统模板着色；Windows 托盘沿用应用图标。
- `public/favicon.ico`：网页标签图标，与桌面 ICO 同源。

在安装参考应用的 Mac 上运行 `node scripts/import-qoder-app-icon.mjs` 可以重新导入并生成桌面图标。脚本只读取参考应用，不修改其安装内容；构建机使用仓库内生成好的资源，不依赖参考应用。移动端图标不在当前桌面构建范围。

网页刷新后可加载新图标；Dock、Finder 和已安装应用需要重新构建、安装并重新启动小胤才能更新，网页热更新不替换系统应用图标。

## 页面构图

内容最大宽度 790px，横幅高 144px。白色工作区、浅灰侧栏、黑色主按钮，浅绿/浅蓝只用于插画底色和状态反馈。

专家套件使用金融、法律、市场营销三个场景，间隔 5.5 秒切换，支持手动选择；鼠标悬停、键盘焦点进入时暂停。专家套件与技能横幅不放创建按钮，创建入口统一在顶部「添加」。技能横幅采用右侧重叠卡片。连接器使用浅灰横幅和右侧应用插画。

知识库横幅采用浅暖绿渐变、细边框与 12px 圆角，左侧标题和说明垂直居中，下方展示资料归档、知识检索、原文引用三个非交互标签；右侧为阅读场景。窄窗口缩小插画并允许横幅随文案增高，避免截断说明。阅读动画周期 7 秒，系统减少动态效果时完整保留静态阅读姿态。

页面淡入 180ms、菜单淡入 120ms、技能插画卡片悬停过渡 200ms。参考插画以独立文件加载；知识库使用内联 SVG 与 CSS 动画，不增加动画运行时依赖。

## 对话与任务状态

- 主区与窗口外框使用纯白 `#ffffff`，侧栏与辅助面板使用近白 `#fafafa`；悬停 `#f4f4f4`、选中 `#eeeeee`，避免大面积灰绿底。正文深灰，次要说明 `#737373`，细边框使用 `#e6e6e6` / `#efefef`。用户消息使用浅灰 `#f8f8f8` 保持区分。
- 进度说明直接使用透明背景与次要正文色，不添加重复标题；步骤分组与明细采用轻量排版。错误保留独立错误色，不与普通过程混用。
- 运行提示只在当前轮过程区显示，活动文案与耗时分开；不绘制输入框上沿的彩色状态横栏。完成和停止后默认收起过程，保留耗时和展开入口；失败默认展开。仅加载图标持续运动。
- 耗时与最终回复之间使用细灰分隔线。文件改动卡片采用纯白底、浅灰文件图标、细边框与紧凑审核/撤销按钮，红绿仅表示增删行数；不使用渐变行底色、彩色侧条或逐行入场动画。
- 代码块使用近白背景、语言栏与独立复制按钮。审核区白底，代码字号 12px，增删差异保留语义底色；未修改上下文可展开。过程折叠不重复播放入场动画，不新增动画库。
- 助手轮次不做透明度入场动画；工具明细不随运行状态自动开合，整轮结束的收起与回复显示同步完成，避免过程区域闪动。
- 长会话先渲染最近 60 条消息，顶部提供浅灰「加载更早的消息」按钮，加载后保持阅读位置；不以滚动占位模拟历史正文。
- 对话页占满工作区可用高度，仅消息列表滚动，输入框与工作目录留在底部；触底不向外层传递滚动、不显示橡皮筋空白。文件预览沿用工作区高度，不叠加完整窗口高度；新任务与目录页保留各自必要的内容滚动。
- 对话输入框圆角 18px，首页圆角 14px；底色纯白，默认使用细灰边框与轻阴影，聚焦时加深中性灰边框，不出现绿色光晕。发送和停止使用深灰圆形按钮，停止图标为白色方块；加入队列是浅色次要按钮。吉祥物、功能插画和语义状态保留原有颜色。
- 输入框「＋」展开四类能力与文件入口，面板内搜索与空状态保持统一。指定套件/技能、知识库与连接器显示紧凑标签；图片显示缩略图，文件显示名称和类型，均可预览和移除。工作目录在输入框下方独立管理。
- 待处理列表使用浅灰底、12px 圆角和细分隔线，编辑、移除、暂停保持可访问。文件交付为紧凑浅灰行，保留文件名、真实路径、大小、预览和定位入口；文件类型由图标色区分，文件数量保留给辅助技术读取。
- 悬停和折叠过渡为 140–180ms；减少动态效果设置下停用持续动画。

上述配色由 `src/styles.css` 的 `--xy-*` 变量统一管理，浏览器开发页与原生桌面复用同一组组件和样式。

完整能力及与参考产品的差异见 [桌面能力对照](desktop-alignment.md)。
