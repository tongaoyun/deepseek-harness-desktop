# 记忆

记忆位于「设置 → 记忆」，用于跨任务保留工作方式和稳定偏好，不替代知识库或任务历史。

## 内容与管理

- 协作风格：提供简洁直接、细致严谨、耐心易懂三个可编辑起点。
- 工作手册：长期工作规范、术语和业务规则。
- 用户偏好与长期记忆：逐条分类、搜索、编辑和删除，显示来源、更新时间，可打开本机来源任务。
- 「添加记忆」支持直接填写分类和内容，加入草稿后统一保存。相同内容去重；相似文本以及明确的默认币种、语言规则提示替换或独立新增，不自动合并。
- 未保存编辑和未加入条目的输入按账户保留在本机草稿，重新进入页面继续编辑。点击侧栏或设置导航离开时提醒保留草稿；刷新提示未保存。草稿不参与执行、不上传云端；可明确放弃后重新读取。强制退出时不保证系统弹出提醒。
- 所有编辑点击保存后生效。关闭「使用记忆」不删除内容，后续轮次停止注入；已经进入会话的上下文不会被从历史中抹除。
- 单条记忆最多 800 字，最多 100 条；协作风格 8000 字、工作手册 16000 字。

## 对话与自动记忆

桌面对话支持「记住：具体内容」「请记住具体内容」「忘记：关键词」「把记忆……改成……」「把刚才那条改成……」。修改和删除先显示候选原文，再由用户选择确认；「刚才那条」只在当前任务关联条目中选择。没有候选则明确不更改。结果追加到原任务，保留历史消息与任务身份。

自动记忆默认关闭，开启后仅处理正常完成的桌面任务：识别以「我习惯」「我偏好」「我的偏好是」「以后请」「以后都」「今后请」「默认请」开头的简短明确偏好。跳过引用、多行、临时要求、示例、敏感凭据和失败/取消任务。重复内容不再添加，相似或可能矛盾的规则不自动写入，提示用户确认；新增后提示用户，每条关联来源任务。相似判断为轻量规则，并非完整语义冲突识别。

自动记忆不是模型推断画像，不执行每日摘要、定期反思或技能自动改写。排队追加、本机定时任务和钉钉不自动写记忆，避免重复任务指令或群成员偏好污染个人规则；它们复用已有记忆的读取能力。

## 执行与同步

每轮执行读取当前账户的本机记忆文件。协作风格与工作手册常驻；其他内容采用中文双字片段和英文词匹配，偏好允许作为通用背景，最多选取 8 条、合计 4000 字。没有向量数据库或独立记忆执行服务。当前任务明确要求优先于记忆。

本机存储位于应用数据目录的 memory/<账户摘要>/profile.json，保留最近 50 个内容版本。支持 JSON 导入、导出和载入历史版本，载入后仍需保存。读取不上传数据，待同步的本机修改不会被远端旧数据覆盖。

保存先在本机落盘，再同步控制面。请求 10 秒超时；网络失败明确显示「本机已生效、云端未同步」。桌面启动、网络恢复、窗口聚焦以及每分钟进行同步；同一轮未结束不会叠加请求。本机修改串行处理，过期编辑拒绝覆盖并提示重新读取。

跨设备提交携带 expectedVersion，数据库以版本条件原子更新，不匹配返回 409。本机变更保留，停止自动覆盖，设置中确认「保留本机版本」或「使用云端版本」；前者基于刚读取的云端版本提交，再次发生竞争仍返回冲突。请求超时但实际已提交时，通过完整内容比对消除误报。采用整份配置版本选择，不提供逐条多人合并。

控制面使用 `/api/v1/memory-profile` 保存可同步的记忆配置及版本。版本记录和来源任务原文不上传，条目的来源说明与任务标识随配置同步。

## 验收

运行时脚本 harness-host/scripts/acceptance-memory.mjs 使用隔离临时记忆与真实模型验证新任务遵守记忆、本轮要求优先、更新后使用新内容、删除后不再注入。脚本不读取用户记忆、不调用工具。它验证这些具体场景，不代表所有偏好或复杂任务均可稳定遵循。
