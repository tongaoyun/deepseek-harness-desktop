# 知识库

知识库提供任务可检索的公司资料与原文片段。支持个人、团队和公司范围；任务可直接检索，也可在输入框用 `@` 指定资料范围。

点击「新建知识库」，填写名称、可见范围和说明。左侧切换资料库，右侧管理文档和检索内容。

## 上传与状态

- 支持 PDF、DOCX、XLSX、TXT、Markdown；一次最多 20 个文件，单文件上限 25 MiB。超过批次数量时整批不提交，避免静默遗漏。
- 批量文件逐个上传，显示当前文件和进度。失败文件可单独重试，已成功文件不重复提交。
- 文档列表支持按名称和索引状态筛选；显示可检索数量、索引失败原因、重新索引和删除操作。
- 上传存储成功不等于可检索。界面区分等待索引、解析中、可检索和索引失败；桌面与管理端在处理中定期刷新。
- 索引服务不可用时保留原文件和失败状态，可恢复服务后重建。等待和执行中的文档不重复创建重建任务。
- 每轮索引先保存执行标识，再启动 Worker；提交片段前锁定文档并核对执行标识，旧轮次不能覆盖新结果。解析失败包含失败原因，不标记为就绪。

## 检索与引用

- 使用 PostgreSQL 文本检索与相似度匹配，不依赖额外向量数据库或 embedding 模型。
- 结果包含稳定的片段 ID（`sourceId`）、知识库、文档 ID、文件名、页码/工作表/正文定位及原文片段。文档被提到或上传成功不等于存在引用，只有实际检索结果可作为依据。
- 知识库检索结果和任务回答下方提供“检索原文”入口。任务卡片只来自成功的 `knowledge_search` 工具回执，按片段去重；普通回答、失败工具和无法识别的回执不会制造原文卡片。检索到的片段不代表都被答案引用。
- 打开原文时按当前员工身份重新读取服务端索引，不直接显示历史缓存。重建期间、重建后旧片段、删除或不可访问的资料会提示重新检索；失败可重试，关闭弹窗取消读取。未找到证据时应明确说明，不用常识补造公司规定。
- XLSX 索引保留工作表、行号和单元格地址，空列不会造成列错位。支持的公式在读取时计算，无法计算的公式明确标注，不把表达式或虚构金额当作结果；不改写上传的工作簿。
- 指定知识库 ID 与任务允许的引用范围取交集，不扩大到其他库。检索无匹配时明确显示空结果。
- 创建、删除知识库后刷新任务入口中的资料目录。切换知识库、账号或修改检索词时，过期请求不更新当前结果。
- 删除文档同时清除其检索片段；桌面和管理端清除已展示的对应检索结果。已经生成的历史对话仍作为历史记录保留，不自动改写成“从未引用”。
- 上传同名文件不会自动覆盖。更新资料应删除旧文档再上传新版本；重建索引只是重新解析原已上传文件，不会读取本机后来修改的内容。

## 验收边界

自动回归覆盖部分上传失败、数量限制、异步切换、原文回执与弹窗、删除引用、错误与空态，以及索引启动失败、重复重建、旧轮次提交、表格单元格定位和公式结果。真实运行验收使用独立临时资料，不读取用户业务文件。

本地 Docker 验收覆盖中文 DOCX、XLSX 和文本型 PDF 的上传、索引、搜索、原文定位与重读，以及重建后旧引用失效、删除后同名重新上传、无匹配、超过 2 MiB 文件与损坏 DOCX 重试。验收样本由服务端 WeKnora 集成测试维护，桌面端不提供另一套 Office 文件生成器。

PDF/Office 的复杂排版、公式、图表及 OCR 准确度需要按实际资料检查。检索命中不等于整份文档已被模型阅读或结论已得到验证。
