# Agent Note：已安装的企业技能

Status: implemented

[English](2026-10-08-product-installed-skills.md) | 中文

## 问题

选择市场技能会派生任务 Preset，即便技能只提供说明。用户必须逐个选择技能，模型才能发现它们，安装内容也会改变任务配置。

## 决策

产品运行时管理按员工隔离的安装注册表，并为每个 Agent 提供官方技能 Provider。安装改变内容可见性，不选择 Preset 或改变草稿。技能没有启用、停用状态。技能和专家套件提供连接器依赖，可用的已安装技能在 Agent 作用域内挂载其声明的已授权连接器。知识库继续按任务选择，以限制检索范围。

首个模型步骤边界固定 Session 的目录和内容标识。安装新版本不会在任务中途改变说明。任务依赖过滤发现，列出和加载时重新检查服务端权限。已安装说明使用官方技能工具和斜杠调用，不引入第二套执行循环。

官方客户端提供通用的 `uiSkills.refresh(sessionId?)`，让安装 Provider 的客户端使发现缓存失效。产品方法留在产品包。完整客户端补丁已登记用于上游升级。删除按任务手动选择技能，因为它与安装重复且阻止普通模型发现。

## 影响

安装不再调整任务模式、能力或草稿。依赖仍需按任务明确选择。已开始任务保留固定内容，安装或升级技能影响尚未开始的任务。安装内容和 Session 快照保留在磁盘，暂不自动清理。

## 考虑过的替代方案

保留按任务选择技能会继续产生不必要的 Preset 派生，并阻止普通发现。无需安装就暴露全部市场技能会隐式下载说明，使可用内容取决于目录刷新。全局可变目录会让升级改变运行中任务。限定作用域的 Provider 与固定目录保留官方执行路径和稳定的任务输入。

## 验证

真实 Loader 测试覆盖发现、官方技能工具输出、斜杠调用、固定版本、重启恢复、权限、依赖过滤、员工隔离和 Provider 释放。客户端测试确认安装技能不创建或选择 Session，不修改草稿。构建后的浏览器及 Electron 场景覆盖安装状态、四类目录、响应式布局、草稿保留，以及不含产品扩展的官方 profile。

适配器测试确定性地请求技能，不评估真实模型根据自然语言选择技能的决策质量。
